# AI 开发过程总览

> 本目录记录「用 AI 开发本软件」的全过程。**原则:任何人读完本目录,即可照着再开发一个类似的平台。**
> 记录规范见技能 `.dsh/skills/ai-dev-log/SKILL.md`;一天一个文件(YYYY-MM-DD.md),同一天多次会话写在同一文件、用「## 会话 N:主题」二级标题区分。

## 项目目标

**民生综合服务平台(对外品牌「民生甄选」)**:政府牵头、信用驱动的全产业链透明交易与民生服务平台(To G + To C),试点石家庄;覆盖消费端/经营端/监管端;三支柱 = 治理监督 + 透明交易 + 民生服务;含平台账户系统(记账+代付,不沉淀资金)与智能助手(模块 J,大模型对话助手)。
