# 前端设计规范与约束 · 民生甄选

> 本目录是「民生甄选」前端(PC Web / Electron / 移动 H5 / 微信小程序)的**设计与工程约束**,是前端设计、开发、评审、提测、门禁的统一依据。
> 定位与业务口径的权威来源是根目录 `docs/`(需求规格说明书、产品设计文档 PDD、品牌定位);本目录只沉淀「**前端怎么设计、怎么实现**」的规范,不与业务口径重复。

## 规范分级(与全局约束一致)

- **MUST**:强制红线,违反即返工 / 门禁阻断。
- **SHOULD**:默认遵循;偏离须在 PR 描述中说明理由。
- **禁止**:明确不得做,无例外。

## 与其他文档的关系

- 根目录 `DEVELOPMENT_CONSTRAINTS.md`:全仓库开发总约束(技术栈/风格/测试/提交/安全),本目录中「工程与代码」「安全」章节与其对齐,**不重复、不冲突**;冲突时以行为规则(`AGENT_MEMORY.md`)为准。
