# 06 · 安全与合规约束

> 前端安全红线,**不可妥协、不可降级**。与根 `DEVELOPMENT_CONSTRAINTS.md` §6 对齐,并按项目合规红线(PDD §1.1/§7)落地为前端细则。资金/身份/隐私相关场景尤其严格。

## 1. XSS / 注入防护(MUST)

- 所有用户输入、后端返回文案、富文本**默认转义或走安全渲染**,禁止 `dangerouslySetInnerHTML` 直接渲染不可信内容(确需时须过白名单净化并评审)。
- URL 跳转防 `javascript:` 协议;仅允许 http/https 白名单链接。
- 组件库(AntD/uni)自带的输入与渲染组件优先,禁止手写拼接 HTML 拼字符串。

## 2. 数据分级与脱敏展示(MUST)

> 依据 PDD §4.3 数据分级;前端展示遵循「最小展示 + 脱敏」,与后端字段口径一致。

| 数据级 | 示例 | 前端展示规则 |
|---|---|---|
| 高敏 | 身份证号、银行卡、手机号、收款账号、实名信息 | 默认脱敏(如 `138****0000`),查看需授权 + 留痕;禁止明文常驻页面 |
| 中敏 | 交易金额、工资流水、证照图片、投诉证据 | 按角色授权展示;证据图片加水印 + 防滥用 |
| 低敏/公开 | 商户档案、信用分、红黑榜、抽检公示 | 公开页可展示,但公示数据仍按「脱敏口径」去个人化 |

- 脱敏逻辑集中在 `packages/shared` 统一函数,**禁止页面各写一套**(防漏脱敏)。
- 敏感信息**不写进 localStorage/sessionStorage/URL 参数**(MUST);确需暂存用内存或服务端会话。

## 3. 密钥与配置安全(MUST)

- 前端不硬编码密钥/密码/内部地址;用环境变量 + `.env.example` 模板,真实 `.env*` 不入库。
- 前端可公开的第三方 key(如地图)须按平台策略限制域名/配额;任何「能替平台花钱或越权」的 key 一律不下发前端。

## 4. 敏感接口与请求边界(MUST)

- **支付回调、资金代付/分账、大模型对话**等敏感接口:前端不直连,全部走服务端(PDD §2.5「敏感接口走服务端调用」)。
- 资金金额**由服务端计算并回显**,前端只展示与确认,**不本地计算**应付/分账/费率结果作为提交依据。
- 涉及资金/信用/不可逆的提交必须二次确认(见 `03` §7),并展示影响与留痕提示。

## 5. 鉴权与 RBAC 路由守卫(MUST)

- 统一鉴权令牌由 `packages/shared` 管理(获取/刷新/失效处理),页面不各自实现。
- 三端合一靠「角色 + 权限路由」:前端做**展示级**权限控制(隐藏/禁用 + 路由守卫),**后端强制校验**(前端拦截不替代后端授权)。
- 未授权访问显示明确「无权限」态(见 `03` §4),**禁止只靠前端隐藏就认为安全**;越权调用必须被后端拒绝。
- 登录态失效统一处理:跳转登录 + 保留目标页,避免信息丢失;令牌存储遵循 §2(不落明文 localStorage,按团队安全方案)。

## 6. 隐私与合规红线(对应合规红线,MUST)

- **实名**:仅微信/支付宝实名回传,前端不采集、不缓存用户证件照做实名核验(除非合规评审通过)。
- **画像/推荐**:用户画像四权(查询/更正/删除/关闭)在画像管理页可操作;推荐理由透明、非竞价;未成年不建画像(PDD §5.11/J7)。
- **对话/大模型**:对话数据脱敏前置、不出域、日志 ≤30 天;前端展示对话须按脱敏口径,不渲染未脱敏的隐私信息。
- **不沉淀资金/不二清**:前端涉及钱包/代付页面,明确提示「资金由第三方持牌通道处理,平台不沉淀资金」,不做误导性「余额提现到平台」表述。

## 7. 存证与留痕展示(MUST)

- 工资/交易/投诉/溯源等关键环节:前端展示「时间戳 + 存证标识」,让用户感知**可出证**;不伪造、不夸大存证能力。
- 关键操作留痕:谁在何时做了什么,涉及资金/信用的操作页面体现「操作记录/流水」入口。

## 8. 第三方与埋点安全

- 引入第三方脚本/SDK 前评估其数据采集范围,禁止静默采集敏感信息;埋点数据同样脱敏(MUST)。
- 上报日志不携带密码/令牌/身份证号/手机号明文(对齐全局约束 §8)。

## 9. 前端安全自检(提交前核对)

- [ ] 无 `dangerouslySetInnerHTML` 渲染不可信内容(或已白名单净化)
- [ ] 高敏字段全部走统一脱敏函数展示
- [ ] 敏感信息未写入 localStorage/URL
- [ ] 无硬编码密钥/内部地址;`.env*` 未入库
- [ ] 资金金额由服务端计算,前端未本地计算提交
- [ ] 敏感接口未在前端直连
- [ ] 越权场景有明确「无权限」态,且后端已强制校验
- [ ] 画像/对话/实名等合规红线在前端交互上有落点
