## 使用约定

- 顶部「原型演示工具条」为**原型专用层**（含状态切换、自动演示、说明面板开关），产品交付时移除；工具条之外即产品页面本身，评审时可切换四种状态直接对照。
- 视觉严格引用设计令牌（民生蓝 `#2E6BE6` / 暖橙 `#FF7A45`、8pt 栅格、卡片 12px 圆角等）；**禁止在原型里引入未评审的新色值 / 新组件**。
- 文案与四态口径以 `四态设计说明.md` 为准，页面新增四态文案先入该文档 §5 总表。
- 原型中的 Logo、业务图标为演示用占位（以品牌视觉稿与 `packages/ui` 图标集为准）。

## 维护约定

- 新增高保真原型页：文件命名 `<页面名>-<页面ID>-原型.html`（如 `找好店-S01-四态原型.html`），并在本 README 文件表登记；页面来自 IA 98 页清单，优先 M1 正式交付页与 26 项评审重点页。
- 设计令牌 / 文案规则变更时，同步回刷已交付原型与 `四态设计说明.md`。
