### 0.1 范围与口径

- **覆盖对象**：全部业务页面（全局公共区 + 共享能力 + 经营能力 + 监管能力 + 运营能力），覆盖 **94 个功能点**（88 + v1.5 新增 L 组 6 项：L-01 配送下单与地址定位 / L-02 配送订单状态机与全程跟踪 / L-03 商家接单与备货出餐 / L-04 运营调度看板 / L-05 运力管理 / L-06 配送位置轨迹存证与异常预警）与 16 项平台级红线约束（R-01~R-16）中**有页面承载**的部分。
- **分期口径**：M1（MVP）为正式交付页；M2/M3 为「设计先行 / 占位」页（标注后置）。三小/摊贩登记（P3 预留）不列页面。
- **端形态**：PC Web 优先（先 Web 后套壳 Electron 桌面），移动端后置；路由按 Web 路径给出，移动端复用同一业务页面。

### 0.2 关键架构决策（影响本 IA）

1. **多场景合一单 App + 功能域路由（v1.1 调整，v1.5 增运营场景）**：单一 React 应用，页面按**功能域**组织，去端前缀；「消费 / 经营 / 监管 / 运营」从「端」降级为**场景工作台**（聚合首页）。页面可见性由 **RBAC（角色集合 + 数据分级授权）**决定，**一人多角色能力叠加、跨场景零切换**。
2. **低学习难度优先（v1.1 新增）**：面向用户一律**白话标签**，不暴露「端/模块/服务」等系统术语；导航做减法、助手做兜底。
3. **助手为全局常驻入口（v1.1 调整，v1.4 入口形态更新）**：J 模块「民生小助手」全局常驻——**PC Web 桌面端 = 右侧常驻侧边按钮 + 右侧抽屉**，移动端 = 底部中心悬浮球 + 底部抽屉；其页面跳转（J-02）按 **RBAC 动态白名单**过滤。
4. **模块与服务**：业务模块 A~L + P（平台级）为页面归属主口径；后端服务作二次映射（§1.4，本地配送新增 DELIVERY 服务）。
5. **UX 基线（R-11）**：核心信息一屏可查；投诉 ≤3 步；商户入驻/上架录入 ≤1 分钟。

> 注：当前仓库 `apps/` 仍为 `pc` / `mobile` 双端目录，本 IA 依据 PDD「多场景合一单 App（`apps/web`）」目标态编写，落地时需一并实施路由与 RBAC 守卫。

## 1. 信息架构总览

### 1.1 架构原则

| 原则 | 落地 |
|---|---|
| **低学习难度（主线）** | 白话导航标签（找好店/查真伪/投诉/发工资/进货），不暴露系统术语；角色化默认工作台，用户无需理解「端」概念 |
| 场景而非端 | 消费/经营/监管/运营 = 四个「场景工作台」聚合首页；同一人可多角色、跨场景零切换 |
| 功能域路由 | 页面按业务能力域组织（§1.3），路由去端前缀；RBAC 决定可见/可写 |
| 渐进式披露 | 高频能力平铺、低频收进「更多」；新功能红点引导，不做能力海洋 |
| 浅层级 | 导航 ≤3 级（工作台 → 能力分组 → 页面），高频入口（扫码/投诉/发工资）顶栏直达 |
| 权限随角色 | RBAC 路由守卫 + 数据分级（L1 本人 / L2 授权 / L3 脱敏公示）双重控制 |

### 1.2 全局导航框架

```
┌──────────────────────────────────────────────────────────────────────┐
│ 顶部导航（全局）：Logo · 场景切换(多角色) · 搜索 · 扫码验真 · 费率公示 · 消息 · 个人中心 │
├──────────────────────────────────────────────────────────────────────┤
│ 侧边导航（白话能力分组，按角色动态显隐）          │  主内容区          │
│   找好店 · 查真伪 · 投诉 · 热线 · 放心进货 · 发工资 · 招工 · 我的        │
│   （商户/供应商角色额外出现）                    │ （当前能力分组页面）│
│   经营工作台：我的店铺 · 商品上架 · 批次 · 订单 · 结算                    │
│   （监管角色额外出现）                          │                    │
│   监管工作台：档案核验 · 预警 · 工单 · 视觉审核 · 资金审计                │
│   （平台运营角色额外出现）                      │                    │
│   运营工作台：配送订单管理 · 调度看板 · 运力管理（M2）                  │
└──────────────────────────────────────────────────────────────────────┘
        ┌─────────────────────────────────────────┐
        │ 右侧常驻：💬 问一问（民生小助手 · 侧边按钮 → 右侧抽屉） │  ← 桌面端；移动端保留底部悬浮球
        └─────────────────────────────────────────┘
```

- **顶部导航**：Logo、场景切换（仅多角色显示：消费 / 经营 / 监管 / 运营）、全局搜索、扫码验真、费率公示、消息、个人中心。
- **侧边导航**：白话能力分组 + 按角色动态显隐（单角色用户只看到自己场景的菜单，零认知负担）。
- **常驻助手（右侧侧边按钮）**：PC Web 桌面端右侧常驻「问一问」侧边按钮，点击展开右侧抽屉式对话面板（非全屏，主内容可继续阅读）；移动端保留底部中心悬浮球 + 底部抽屉；与「导航做减法」互补——不会用就问。
- **场景工作台**：`/`（消费工作台）、`/workspace`（经营工作台）、`/supervise`（监管工作台）、`/ops`（运营工作台），登录按主角色落入对应工作台。

### 1.3 路由命名规范（v1.1 去端化）

| 前缀/形态 | 含义 | 示例 |
|---|---|---|
| `/auth/*` | 登录与实名认证 | `/auth/login`、`/auth/realname` |
| `/public/*` | 公共公示页 | `/public/fee-disclosure` |
| `/me/*` | 个人中心（跨角色） | `/me/wallet`、`/me/profile`、`/me/payroll` |
| `/shops` `/trace` `/complaints` `/appeals` `/market` `/orders` `/jobs` … | **共享能力域**（有权限即用，跨场景） | `/shops/:id`、`/trace/:code`、`/complaints/new` |
| `/manage/*` | **经营能力域**（商户/供应商角色，自管理） | `/manage/payroll`、`/manage/products`、`/manage/batches` |
| `/supervise/*` | **监管能力域**（监管角色，强 RBAC 隔离） | `/supervise/alerts`、`/supervise/ai-review` |
| `/ops/*` | **运营能力域**（平台运营角色，配送运营） | `/ops`、`/ops/delivery/orders`、`/ops/delivery/dispatch`、`/ops/delivery/riders` |

- 详情页统一 `:id`；列表页复数资源名；动作页 `/new` 或动词段。
- 助手白名单路由 = 本清单标注「**白名单可跳**」页面的路由集合，按当前用户角色 **RBAC 动态过滤**（§4.5）。

### 4.2 侧边导航（白话能力分组 + 角色动态显隐）

- **消费/共享能力**（全员可见）：找好店 · 查真伪 · 投诉 · 热线 · 放心进货（M2）· 招工求职（M2）· 优质小店（M3）
- **经营能力**（商户/供应商角色额外出现）：经营工作台 → 我的店铺 · 商品上架 · 批次溯源 · 采购 · 订单结算 · 发工资 · 物流（M2）
- **监管能力**（监管角色额外出现）：监管工作台 → 档案核验 · 预警 · 工单 · 溯源监控 · 视觉审核 · 资金审计
- **运营能力**（平台运营角色额外出现）：运营工作台 → 配送订单管理 · 调度看板 · 运力管理（M2）

> 单角色用户只看到自己场景的菜单（零认知负担）；多角色用户在各自工作台间轻量切换，共享能力页不重复、不切换。

### 4.3 面包屑与层级

- 统一层级：**工作台 > 能力分组 > 页面**（如：经营工作台 > 用工发薪 > 工资代付）。
- 白话面包屑，不暴露「端/模块/服务」术语。

### 4.5 助手「问一问」与 J-02 白名单（v1.1 调整）

- **位置**：PC Web 桌面端为**右侧常驻侧边按钮**（`G-10`），点击展开**右侧抽屉式对话面板**（宽 360~400px，非全屏，主内容可继续阅读）；移动端保留底部中心悬浮球 + 底部抽屉。
- **语音交互（J-14，v1.2 新增）**：支持**语音输入（ASR 转文字，复用 J 对话链路）** + **语音播报（TTS 读回答）**；服务银发/司机等「语音优先」场景；语音数据同 J 对话合规口径（脱敏前置、不出域、日志 ≤30 天）。
- **避让**：右侧抽屉与右侧内容留出安全边距、不遮挡主操作列；展开态可拖动收起；新用户首次进入一次性提示（呼应 J-01/J-11 引导）。
- **白名单口径（J-02，v1.1 调整）**：白名单从「静态端内页面列表」改为「**当前用户有权限访问的功能页面集合**」= 标注「白名单可跳」页面（S-02、S-06、M-10、R-05、R-12 等）∩ 该用户 RBAC 可见页面，**动态过滤**。
- **规则不变**：仅平台内页、不对外链；跳转前二次确认；越权由 RBAC 守卫拦截（水平越权 2002）。
- **收益**：监管说「看某店预警」→ 直达 `/supervise/alerts`；商户说「发工资」→ 直达 `/manage/payroll`；同一用户跨场景一句话直达，无需先切工作台。
