# 民生甄选 · UI 设计规范（主题方案）

> **状态**：🟡 v1.0 初稿（待评审）
> **版本**：v1.0 · 日期：2026-09-06
> **主题方向**：方案 B · 民生温暖·现代亲民（用户拍板）
> **依据**：《页面清单与信息架构》v1.2（`apps/docs/页面清单与信息架构.md`）、品牌定位（`26-平台命名与品牌定位.md`：主名「民生甄选」、颜色方向「民生蓝 + 暖橙 + 白底」已确认）、用例图已确认功能范围（79 + T-22/J-14）
> **用途**：直接作为 UI 视觉规范与设计师/前端对接输入；设计令牌（Design Tokens）可直接转 CSS 变量。

---

## 0. 范围与原则

- **覆盖范围**：三端（消费/经营/监管）统一主题 + 端内微调；重点覆盖已确认功能——档案信用、全链溯源、投诉直达、热线、选品交易、用工发薪、劳务信用互评、司机信用、争议仲裁、**原材料定期拍照上报与视觉合规核验**、**助手语音输入/播报**等。**不扩展到文档未确认的功能范围。**
- **设计原则**：五词「惠民 · 方便 · 安全 · 透明 · 直达」贯穿每个设计元素（§8 对照表自检）。
- **端形态**：PC Web 优先（≥1280 宽为主，≥1024 可用），移动端后置但组件需响应式预留。

### 2.6 视觉核验置信度（原材料/证照 K 视觉）

| 置信度 | 阈值 | 标签色 | 处置 |
|---|---|---|---|
| 高（疑似异常） | ≥0.9 | 红 `#E5484D` | 「需核查」→ 一键核查单 |
| 中 | 0.7~0.9 | 黄 `#F59E0B` | 「复核队列」 |
| 低 | <0.7 | 灰 `#A9B1BE` | 「已归档」 |

### 2.7 端差异化微调

| 端 | 主色权重 | 气质微调 |
|---|---|---|
| 消费端 | 蓝 500 + 橙 500 均衡 | 圆角更大、卡片更暖、留白更多 |
| 经营端 | 蓝 500 为主、橙作待办/CTA | 工作台高效、数据密度略高 |
| 监管端 | 蓝 700 为主、橙仅作预警 | 数据看板、强调密度与对比 |

### 2.8 对比度与无障碍

- 正文文字对背景对比度 ≥ **4.5:1**（WCAG AA）；大号文字/图标 ≥ 3:1。
- 主蓝 `#2E6BE6` 白字对比度约 4.6:1（用于正文级需谨慎，按钮/链接达标）；深一档 `#2454C7` 作正文链接更稳。
- 红色仅作「错误/危险」，不作为普通装饰色，避免与暖橙语义混淆。

## 3. 字体与排版

### 3.1 字体族

| 场景 | 首选 | 回退 |
|---|---|---|
| 中文 | 阿里巴巴普惠体 3.0（或思源黑体 Source Han Sans SC） | PingFang SC / Microsoft YaHei |
| 西文/数字 | Inter | system-ui / -apple-system |
| 表格数字 | Inter（`font-variant-numeric: tabular-nums` 等宽数字） | — |

> 标题用普惠体加粗体现「圆润亲民」；正文用常规；不使用衬线体（保持现代、接地气）。

### 3.2 字号层级（base 14px，8pt 栅格）

| 层级 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| Display | 24 / 32 | 700 | 工作台大标题、首页主标题 |
| H1 | 20 / 28 | 600 | 页面标题 |
| H2 | 18 / 26 | 600 | 区块标题 |
| H3 | 16 / 24 | 600 | 卡片/弹窗标题 |
| Body | 14 / 22 | 400 | 正文 |
| Body-Small | 13 / 20 | 400 | 次要说明 |
| Caption | 12 / 18 | 400 | 辅助、时间戳、标签内文 |
| 表格 | 14 / 20（密集 13/20） | 400 | 表格内容 |

### 3.3 大字模式（无障碍，重点满足银发用户）

- 全局支持「大字模式」开关（个人中心或顶栏）：整体字号 **×1.25**，关键操作按钮与图标同步放大，不截断、不换行错位。
- 最小可读字号 **12px**，非必要不更小。

### 3.4 数字与数据

- 金额/分数/流水用**等宽数字**（tabular-nums），右对齐；
- 信用分、费率等关键数字放大强调（如 20/28 加粗 + 语义色）；
- 千分位分隔，金额前缀 `¥` 与数字同字重。

## 4. 组件风格

### 4.1 基础规范（形状 / 阴影 / 间距）

| 项 | 规范 |
|---|---|
| 圆角 | 按钮/输入框 8px；卡片 12px；对话框/抽屉 16px；标签/徽标 6px；悬浮球 50%（正圆） |
| 阴影 | e1 `0 1px 3px rgba(17,26,42,.06)`；e2 `0 4px 12px rgba(17,26,42,.10)`；e3 `0 8px 24px rgba(17,26,42,.14)`（仅抽屉/对话框/悬浮层） |
| 间距 | 8pt 栅格：4 / 8 / 12 / 16 / 24 / 32 / 48；卡片内边距 16~24 |
| 边框 | 1px `--gray-200`；分隔线优先用浅边框，少用强分隔 |
| 动效 | 过渡 120~200ms ease-out；重要反馈（语音录制、上传成功）可用 240ms |

### 4.2 核心组件

| 组件 | 规范 |
|---|---|
| **主按钮** | 蓝 `#2E6BE6` 白字，圆角 8px，hover `#2454C7`；高度 40px（紧凑 32px） |
| **强调 CTA 按钮** | 暖橙 `#FF7A45` 白字，用于「发起投诉 / 扫码 / 语音 / 立即举报 / 上传拍照」等关键动作 |
| **次按钮** | 蓝浅底蓝字（`blue-50`/`blue-500`）或描边灰 |
| **危险按钮** | 红 `#E5484D`（删除/拒绝/拦截确认） |
| **卡片** | 白底、圆角 12px、e1 阴影；hover e2 |
| **表格** | 表头 `gray-50` 底 + 600 字重；隔行 `gray-100`；关键列（金额/分数）右对齐；可排序列表头带箭头 |
| **表单** | 标签 14/600；输入框 40px、圆角 8px、focus 蓝描边 + 4px 蓝光晕；必填星号红 |
| **顶部导航** | 白底 56px；Logo（对勾+环链）+ 场景切换（多角色）+ 搜索 + 扫码 + 费率公示 + 消息 + 个人中心 |
| **侧边导航** | 白话能力分组；选中项蓝浅底 + 蓝字 + 左侧 3px 蓝条；图标 20px |
| **标签/徽标** | 圆角 6px；语义色浅底 + 深色文字（成功/警告/危险/信息） |
| **进度条** | 圆角；工单进度（处理中/已解决/已升级/已处罚）分色段显示 |

### 4.3 关键功能专属视觉（对齐已确认范围）

| 功能 | 视觉要点 |
|---|---|
| **原材料定期拍照上报**（`/manage/materials`） | 大点击区「拍照上传」卡（相机图标 + 引导文案，拍照即传）；上传后缩略图 + **产品编号 OCR 回填**字段；每张图带核验状态标签（待核验/合规/异常）；顶部「本次待上报清单 + 截止提醒」 |
| **原材料/证照视觉核验**（`/supervise/materials`、`/supervise/ai-review`） | 置信度三档标签（§2.6）；图片标注框高亮疑似区域；右侧「一键核查单 / 复核队列 / 已归档」三栏；人工复核操作按钮（通过/驳回）留痕 |
| **助手「问一问」+ 语音**（`G-10`） | **桌面端（PC Web）**：屏幕右缘**常驻侧边按钮**（蓝底白「对勾/问号」+ 竖排「问一问」，悬停加宽，暖橙提示点）；点击展开**右侧抽屉**（宽 360~400px，圆角 16px 左，非全屏、主内容可继续阅读）；**移动端保留**底部中心悬浮球 + 底部抽屉；抽屉内含**麦克风按钮**（点击变红脉冲 = 录制中）、回答带 **TTS 播放按钮**（喇叭图标）、快捷操作卡（J-15）；回答末尾固定标注「平台助手生成，请以页面信息为准」 |
| **劳务信用互评**（`/manage/labor-credit`） | 双向信用卡（老板看工作者 / 工作者看老板）；信用分环形仪表 + 四维构成（发薪履约/纠纷/评价/资质）；互评附证据入口；差评申诉入口 |
| **司机信用档案**（`/manage/freight/drivers/:id`） | 司机头像 + 从业资格证 + 履约率环形；接单历史列表；双向信用联动标签 |
| **争议仲裁**（`/manage/disputes/:id`） | 垂直时间轴（订单→验收→争议→结论）；**双方证据左右对比卡**；平台结论卡（蓝描边 + 结果公示标识）；结论计入信用提示 |
| **溯源时间轴**（`/trace/:code`） | 垂直时间轴（批号→检测→温控→终端）；完整环节实线绿点，**断链环节虚线 + 红「缺失/断链」标签**；扫码次数留痕 |
| **防童工拦截**（`/manage/employments/new`） | 年龄 <16 触发**红色警示弹窗**（危险色 + 拦截说明 + 留痕提示），阻断入职 |
| **一店一档**（`/shops/:id`） | 一屏聚合：证照/处罚/抽检/投诉率/好评率/信用分 + 价格公示 + 禁入承诺 + 溯源/后厨入口，核心信息一屏可查 |

## 7. 无障碍与合规视觉

| 项 | 落地 |
|---|---|
| 大字模式 | 全局 ×1.25 缩放开关（§3.3） |
| 语音 | 助手语音输入（麦克风录制态红脉冲）+ TTS 播放按钮；语音数据脱敏合规 |
| 色盲友好 | 状态不单靠颜色——标签同时用图标 + 文字（如「✓ 合规」「✕ 异常」「⚠ 待复核」） |
| 未成年人 | 禁入承诺标注、举报类别、防童工拦截均用清晰图标 + 文字，不做模糊提示 |
| 脱敏公示 | 红黑榜/投诉结果脱敏展示（手机号 138****）；「以页面为准」标注 |
| 键盘可达 | 全组件可 Tab 聚焦，焦点态蓝描边清晰 |
