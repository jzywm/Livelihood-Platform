```

├──────────┬───────────────────────────────────────────────────┤
│ 侧边导航 │                                                 │
│ (白话分组)│                 主内容区                          │
│          │                                                 │

└──────────────────────────────────────────────────────────────┘
```

- **顶部导航**：Logo、场景切换（仅多角色显示：消费/经营/监管）、全局搜索、扫码验真、费率公示、消息、个人中心。
- **侧边导航**（白话分组，按角色动态显隐）：
  - 消费/共享（全员）：`找好店 · 查真伪 · 投诉 · 热线 · 放心进货(M2) · 我的`
  - 经营（商户/供应商额外）：`经营工作台 · 我的店铺 · 用工发薪 · 供应商与溯源 · 采购交易 · 发工资 · 账户`
  - 监管（监管角色额外）：`监管工作台 · 档案核验 · 预警 · 溯源 · 工单 · 资金 · 存证`
- **底部助手**：常驻「问一问」悬浮球（非路由页面，G-10），三端统一，支持语音 ASR/TTS。

## 2. 线框模板约定

每个页面线框由四部分组成，统一口径：

```
### 编号 页面名（`路由` · M1 · 功能点）
> 模块 X ｜ 可见角色：xx ｜ 说明：…（来自 IA §3 清单）
┌─… ASCII 线框 …─┐
· 五词自检：落在「惠民/方便/安全/透明/直达」哪几个词 + 关键交互
```

- **主操作**：每页只一个主色按钮（民生蓝 `--color-primary`），危险操作（拒绝/放款/升级/删除）用 `error` 红 + 二次确认。
- **状态徽章**（统一语义，见 `03-组件与交互规范` §3）：
  - ✅ 成功/通过/已办结（绿） ｜ 🔵 进行中/审核中（蓝） ｜ ⚠ 待处理/临期/预警（橙） ｜ 🔴 失败/拒绝/违规（红） ｜ ⚪ 取消/草稿（灰）
- **四态**：数据区覆盖 加载/空态/错误/无权限。
- **透明表达**：进度用「时间轴 + 状态徽章」，公示用「对照表」，不只用一句话结论。
- **脱敏**：信用分/红黑榜/投诉结果等一律脱敏公示（R-03 分级授权）。
