## 2. 线框模板约定

每个页面线框由四部分组成，统一口径：

```
### 编号 页面名（`路由` · M1 · 功能点）
> 模块 X ｜ 可见角色：xx ｜ 说明：…（来自 IA §3 清单）
┌─… ASCII 线框 …─┐
· 五词自检：落在「惠民/方便/安全/透明/直达」哪几个词 + 关键交互
```

- **主操作**：每页只一个主色按钮（民生蓝 `--color-primary`），危险操作（拒绝/放款/升级/删除）用 `error` 红 + 二次确认。
- **状态徽章**（统一语义，见 `03-组件与交互规范` §3）：
  - ✅ 成功/通过/已办结（绿） ｜ 🔵 进行中/审核中（蓝） ｜ ⚠ 待处理/临期/预警（橙） ｜ 🔴 失败/拒绝/违规（红） ｜ ⚪ 取消/草稿（灰）
- **四态**：数据区覆盖 加载/空态/错误/无权限。
- **透明表达**：进度用「时间轴 + 状态徽章」，公示用「对照表」，不只用一句话结论。
- **脱敏**：信用分/红黑榜/投诉结果等一律脱敏公示（R-03 分级授权）。
