# 06 · 骑手能力域线框图（M2 · 3 页 · 移动优先）

> 模块 L（本地配送）。骑手角色（运力方）。**移动优先**——随 `apps/mobile`（uni-app H5 + 微信小程序）落地，竖屏手机布局。
> **页面简洁原则**：一屏一个主操作、底部单一主按钮、大字大间距（户外骑行/驾车单手可操作）。
> **车型兼容**：车辆类型不限于电动车——E_BIKE 电动车（常规小件）/ CAR 汽车（大件货物），双车型全流程一致（下单货件规格/派单匹配/接单校验/导航模式）。
> **导航**：按车型唤起地图开放平台（高德/百度候选）：电动车=骑行、汽车=驾车；H5 内嵌地图兜底。
> **位置**：配送中后台自动位置心跳（30s~60s★），买家配送中可见、送达即切断（R-03 授权可见级）。

· 五词：**直达**（双导航一键唤起 + 底部单主按钮）/ **安全**（GPS 围栏校验取货/送达）。导航唤起地图开放平台（E_BIKE=骑行 / CAR=驾车）；未到指定地点 → 「请到达指定地点后再操作」；无 GPS 权限 → 引导开启定位。
