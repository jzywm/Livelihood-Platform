# 02 · 设计令牌(色彩 / 字体 / 间距 / 图标)

> 本章是视觉参数的**唯一来源(Design Tokens)**。命名与分层为 MUST,具体色值 / 字阶为**初版基线**,待「民生蓝 + 暖橙」品牌视觉定稿后校准;校准前代码一律引用令牌变量,**禁止散落硬编码色值**。
> 落地:PC Web/Electron 用 CSS 变量(或 `tokens.ts` + CSS 变量);uni-app 用 `uni.scss` 变量,同名对齐。

## 0. 令牌命名约定(MUST)

- 命名用英文小写 + 短横线(kebab-case),禁止拼音、禁止无意义缩写。
- 分层:`--color-<语义>-<档位>`、`--space-<n>`、`--font-size-<n>`、`--radius-<n>`、`--shadow-<n>`。
- 语义层优先于具体色值:代码里写 `var(--color-primary)`,**不写** `var(--color-blue-600)`;新增颜色先加语义令牌,再映射具体值。

## 1. 色彩

### 1.1 品牌色（MUST 方向，✅ 色值已定稿 2026-09-11）

| 令牌 | 说明 | 初版基线值 | 用途 |
|---|---|---|---|
| `--color-primary` | 主色·民生蓝 | `#1B5FDB` | 主按钮、链接、选中、品牌标识 |
| `--color-primary-hover` | 主色悬停 | `#356FE6` | 交互态 |
| `--color-primary-active` | 主色按下 | `#14479F` | 交互态 |
| `--color-primary-bg` | 主色浅底 | `#EAF1FC` | 选中背景、标签底 |
| `--color-accent` | 辅色·暖橙 | `#FF7A1E` | CTA、惠民标签、强调、收藏态 |
| `--color-accent-bg` | 辅色浅底 | `#FFF0E5` | 强调标签底 |

### 1.2 语义色(MUST,用于状态反馈)

| 令牌 | 初版基线值 | 用途 |
|---|---|---|
| `--color-success` | `#16A34A` | 成功、通过、到账、上线 |
| `--color-warning` | `#D97706` | 预警、临期、待处理 |
| `--color-error` | `#DC2626` | 失败、拒绝、欠薪、违规 |
| `--color-info` | `#0EA5E9` | 提示、信息 |

> 语义色仅用于「状态/反馈」,禁止用于品牌装饰(如把整页主色改成绿色)。

### 1.3 中性色(文字 / 边框 / 背景)

| 令牌 | 初版基线值 | 用途 |
|---|---|---|
| `--color-text` | `#1F2329` | 主文字 |
| `--color-text-secondary` | `#4B5563` | 次要文字 |
| `--color-text-tertiary` | `#8B93A1` | 辅助、占位 |
| `--color-text-disabled` | `#C2C7CE` | 禁用文字 |
| `--color-border` | `#E5E7EB` | 常规边框 |
| `--color-divider` | `#EDF0F3` | 分割线 |
| `--color-bg-page` | `#F5F6F8` | 页面底(浅灰,白卡片承载) |
| `--color-bg-container` | `#FFFFFF` | 卡片/容器底 |
| `--color-text-on-primary` | `#FFFFFF` | 主色上的文字 |

### 1.4 使用规则(MUST)

- 页面底色统一 `--color-bg-page`,内容承载统一白色 `--color-bg-container` + 边框 `--color-border`,保持「透明、干净」。
- 文字层级最多三档:`text / secondary / tertiary`,更多层级用字号/字重区分,不新造灰色。
- 状态色与文字色保持**对比度达标**(见 §2.4),禁止浅色底浅色字。

## 2. 字体

### 2.1 字体族(MUST)

- 中文 + 英文统一无衬线,建议栈:
  - PC/Electron:`-apple-system, "PingFang SC", "Microsoft YaHei", "Segoe UI", system-ui, sans-serif`
  - 移动 H5/小程序:系统默认(跟随 `system-ui`),不额外下载字体。
- 金额、编号、时间戳等**数据字段**:使用 `font-variant-numeric: tabular-nums` 等宽数字,避免跳动。

### 2.2 字号阶梯(初版基线)

| 令牌 | 字号 | 用途 |
|---|---|---|
| `--font-size-xs` | 12px | 辅助说明、角标、标签 |
| `--font-size-sm` | 13px | 表格内、次要信息 |
| `--font-size-md` | 14px | 正文默认、表单控件 |
| `--font-size-lg` | 16px | 小标题、关键信息 |
| `--font-size-xl` | 18px | 卡片标题、模块标题 |
| `--font-size-2xl` | 20px | 页面分区标题 |
| `--font-size-3xl` | 24px | 页面主标题 |
| `--font-size-4xl` | 28px | 数字看板、大数字 |
| `--font-size-5xl` | 32px | 少数强调场景 |

### 2.3 字重与行高

- 字重:400 常规 / 500 中 / 600 半粗(标题、强调数字)/ 700 粗(仅品牌/主标题)。
- 行高:正文 `1.6`;标题 `1.3`;表格/紧凑场景 `1.4`。
- **SHOULD**:正文默认 `14px / 1.6`;消费端可整体上调一档字号,照顾银发用户。

### 2.4 可读性(MUST)

- 正文与背景对比度 ≥ 4.5:1(AA),大字/图标 ≥ 3:1;监管看板数据密集处尤其注意。
- 链接色与正文可区分(用主色 + 下划线,不只靠颜色)。

## 3. 间距(8pt 栅格,MUST)

| 令牌 | 值 | 用途 |
|---|---|---|
| `--space-1` | 4px | 图标与文字、紧凑 |
| `--space-2` | 8px | 控件内、标签间距 |
| `--space-3` | 12px | 表单控件间、卡片内边 |
| `--space-4` | 16px | 卡片内边距、区块间距(默认) |
| `--space-5` | 20px | 区块间距 |
| `--space-6` | 24px | 卡片间距、页面边距 |
| `--space-8` | 32px | 大区块、页面留白 |
| `--space-10` | 40px | 页面级留白 |
| `--space-12` | 48px | 首屏留白 |

- 所有间距取 4 的倍数;页面留白、卡片间距、栅格 gutter 均从上述令牌取,**禁止随意 5px/7px**。
- 页面内容区(PC)默认 24px 边距,卡片间 16px。

## 4. 圆角 / 阴影 / 边框

| 令牌 | 值 | 用途 |
|---|---|---|
| `--radius-sm` | 4px | 输入框、小按钮、标签 |
| `--radius-md` | 8px | 按钮、卡片、下拉面板 |
| `--radius-lg` | 12px | 大容器、弹窗、图片卡片 |
| `--radius-full` | 999px | 胶囊、头像、状态点 |

- 阴影三档:`--shadow-sm`(卡片默认,如 `0 1px 2px rgba(0,0,0,.05)`)、`--shadow-md`(浮层/弹窗)、`--shadow-lg`(抽屉/侧边栏)。监管看板、纯白卡片可只用边框 + 极淡阴影,保持「干净」。
- 边框:1px `--color-border`;强调/输入聚焦用 1px `--color-primary`(或 AntD 焦点态)。

## 5. 图标

- 统一**线性图标**:描边 2px、24px 网格、圆角端点;禁止混用实心/拟物。
- 业务图标(溯源一物一码、信用分、结算、工单、热线)风格一致,统一由 `packages/ui` 维护图标集,禁止页面各自内联 SVG 造成风格漂移。
- 图标必须有 `aria-label` 或相邻文字,纯装饰图标 `aria-hidden`(见 `03` 无障碍)。

## 6. 动效(克制,MUST)

- 仅允许:过渡 `150~250ms ease`、骨架屏/加载、列表进出、弹窗淡入;用于「状态变化反馈」,不用于炫技。
- **禁止**:页面级滚动视差、自动播放轮播大动效、无意义的入场动画连发。
- 尊重 `prefers-reduced-motion`:用户系统开启「减弱动态效果」时,禁用非必要动效(SHOULD)。
- 资金/信用/工单类关键操作:交互必须即时、可预期,不因动效延迟。

## 7. 令牌落地方式

- **PC/Electron(React)**:在 `packages/ui`(或 apps/web 的 theme 层)集中定义 CSS 变量 + `tokens.ts`,全端引入;AntD 5 通过 ConfigProvider 的 `token` 映射到上述变量(主色 = `--color-primary` 等),保证 AntD 组件与自定义组件同源。
- **移动 uni-app**:`uni.scss` 定义同名 `$` 变量(如 `$color-primary`),与 CSS 变量值一一对应;两套命名对齐,方便迁移。
- **SHOULD**:设计稿交付时直接标注令牌名(而非写死色值),评审时核对「页面是否只引用令牌」。
