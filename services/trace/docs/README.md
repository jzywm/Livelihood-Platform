# 溯源服务（TRACE · Traceability）

> 微服务说明文档 · 依据《产品需求文档》（PRD v2.0）与《产品设计文档》（PDD v1.3）编写
> 本文档用于明确该微服务的**功能与质量基线**，支持后续扩展开发。功能口径以 PDD §5.6 / §6.4.6 为准，需求口径以 PRD §5.3（B 组）与 §5.10（T 组）为准。

## 1. 服务概述

- **服务标识**：`trace`（溯源服务）
- **服务定位**：供应商入驻核验、供应商信用、批次溯源码与扫码验真，落实「从种子到餐桌，全程透明」。
- **对应模块**：T2 供应商资质核验 / T3 溯源二维码（T-01 / T-05 / T-08 / T-09）；B-04 店铺直播【M2，§5.14】。
- **里程碑**：M1 交付（信任前置：先攒数据与信任）。
- **实现载体 / 技术栈**：Java 17 + Spring Boot 3.5（模块化单体）。
- **三端分布**：消费端（扫码溯源）· 经营端（批次上架 / 环节上报）· 监管端（断链预警）。
- **依赖服务 / 外部依赖**：CRED（供应商信用档案）、OSS（证照 / 图片存储）、存证（哈希链）。
- **核心状态机**：商品（草稿 → 待审核 → 已上架 ⇄ 下架 / 强制下架）；溯源链路（①批号 → ②检测 → ③温控 → ④终端，任一缺失 = 断链标注）；供应商榜单（正常 ⇄ 警告 60~40 ⇄ 黑榜 <40 降权 / 禁新单）。

## 2. 背景条件

- **需求背景（解决什么问题）**：假农资 / 假材料、图文不符、供应商侧信任缺失（好货无人知）（PRD §2.1 问题 1、经营端 #6）。溯源服务让全链透明可查，是「透明交易」的信任底座。
- **前置条件（本服务运行前提）**：
  - 供应商已实名并持有品类资质（农资：执照 + 经营 / 生产许可 + 登记批号；食材：执照 + 许可 + 检验报告）。
- **平台红线约束（本服务需强落地）**：
  - R-09 强监管品类只做信息撮合 + 溯源核验，**不替代行政许可**；
  - R-04 证据存证——各环节记录留痕存证、只增不改；
  - R-15 防刷分——供应商信用分防刷拦截。
- **里程碑边界**：M1 供应商入驻 + 溯源二维码基础；全链溯源农户端接入（B1）为 M3。

## 3. 主要功能

### 3.1 供应商入驻与品类资质核验

供应商实名 + 按品类核验资质后开通上架，只做信息核验不替代行政许可；同步建立供应商信用档案（T-05）。

### 3.2 供应商信用档案与信用分

按「资质合规 30% + 交易履约 30% + 质量口碑 30% + 正向贡献 10%」计算供应商信用分；放心供应商（≥85 且无质量投诉）动态授予 / 撤销；信用分 ≤40 黑榜降权 / 禁新单。

> **与 CRED 的边界（2026-09-08 已决策）**：供应商信用分的 T-05 公式在 TRACE 计算，但信用分与红黑榜的**权威存储与公示在 CRED**（`credit_score`/`redblack`），TRACE 经接口回写；放心供应商标识由 TRACE 动态授予/撤销、CRED 存储公示。详见《微服务边界与职责基准》§3/§4-C02。

### 3.3 溯源批次码生成与环节上报

创建批次即生成唯一溯源码（一物一码 / 一批一码），按批次上报生产检测 / 流通温控 / 终端登记等环节，各环节留痕存证。

### 3.4 扫码验真与全链透明展示

扫码按时间轴展示「批号 → 检测 → 温控 → 终端」全链，缺环显式标注「缺失 / 断链」；扫码次数留痕作防伪旁证。

## 4. 非功能性需求要求

### 4.1 全平台通用基线（所有服务共同遵守）

- **规模**：覆盖 ≈840 万；注册 ≥600 万、MAU ≥200 万、商户/机构 ≥10 万、DAU 峰值 ≈120 万。
- **性能**：核心读首屏 P95 ≤2s；核心写 P95 ≤3s；API P95 ≤500ms / P99 ≤1s。
- **可用性分级 SLO**：L1 ≥99.95% / L2 ≥99.9% / L3 ≥99.5%。
- **容灾**：同城双活 + 异地灾备，RPO ≤15min、RTO ≤30min（L1）。
- **安全**：等保三级 + OWASP ASVS L2；TLS 1.2+；密钥 KMS/HSM。
- **数据**：审计日志 ≥6 个月；存证只增不改。

### 4.2 本服务专项要求

- **可用性等级：L2（≥99.9%）**——溯源属 L2 覆盖对象。
- **热读性能**：扫码验真为集中读场景（监管检查 / 节假日），溯源码按批次号路由、读多写少走只读副本；多级缓存 + 降级出静态快照（PDD §8.1.3）。
- **数据存证**：各环节记录留痕存证、只增不改；断链显式标注、温度超限触发预警。
- **防作弊**：供应商信用分防刷拦截（R-15）；扣分申诉复用 T-07 / D-03。
- **合规边界**：强监管品类仅信息撮合 + 溯源核验，不替代行政许可（R-09）。
