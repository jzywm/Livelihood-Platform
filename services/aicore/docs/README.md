# AI 能力中心服务（AICORE · AI Core）

> 微服务说明文档 · 依据《产品需求文档》（PRD v2.0）与《产品设计文档》（PDD v1.4）编写
> 本文档用于明确该微服务的**功能与质量基线**，支持后续扩展开发。功能口径以 PDD §5.12 / §6.4.13 为准，需求口径以 PRD §5.13（K 组）与 `29-AI能力中心需求.md` 为准。

## 1. 服务概述

- **服务标识**：`aicore`（AI 能力中心服务）
- **服务定位**：**AI 网关底座 + 视觉合规审核 + 证照 OCR + 图像问答 + 风险预测**，AI 只标记不决策（C8）。
- **对应模块**：模块 K（K1~K6，K-01~K-06）。
- **里程碑**：网关 + OCR M1、视觉审核 / 图像问答 M2、风险预测 M3。
- **实现载体 / 技术栈**：**独立 Python 服务**（Python 3.12 + FastAPI + 模型编排），是平台 Agent/AI 侧 Python 承载之一。
- **三端分布**：经营端（K2 证照 OCR）· 监管端（K1 视觉审核 / K4 预警）· 消费端（K3 图像问答）。
- **依赖服务 / 外部依赖**：云视觉 API、OSS（图像存储）、TRACE / CRED（档案回写）、DASH（预警联动）。
- **核心状态机**：视觉合规审核（上传 → 脱敏 → 云视觉分析 → 置信度分级高 / 中 / 低 → 人工复核 / 一键核查单 / 归档）。

## 2. 背景条件

- **需求背景（解决什么问题）**：监管「取证难、人手不足」（监管端 #2/#1）、证照核验慢。AI 能力中心用视觉 / OCR 初筛降人工，用风险预测辅助分级监管，把有限人力聚焦高风险对象。
- **前置条件（本服务运行前提）**：
  - 平台已接入模型服务（DeepSeek / 视觉云，密钥经 KMS）；图像脱敏前置；
  - 视觉云签数据合规协议（不用于训练）。
- **平台红线约束（本服务需强落地）**：
  - R-05 / C8 AI 只标记不决策——任何执法 / 处罚 / 公示动作必须人工确认；图像脱敏 / 加密 / 审计；云视觉不用于训练；复核不回流第三方；
  - R-03 数据分级授权——图像脱敏（去人脸 / 车牌）。
- **里程碑边界**：M1 网关 + 证照 OCR 基础；M2 视觉审核工作台 / 图像问答 / 后厨直播异常识别；M3 风险预测预警。

## 3. 主要功能

### 3.1 AI 网关与治理底座

统一模型路由（文本 / 视觉云 / OCR / 自建预测通道）+ 鉴权限流路由审计 + 任务队列 + 置信度分级 + 全链路审计；模型失败降级（FAQ / 人工复核队列）。

### 3.2 证照 OCR 自动核验

证照上传后自动提取字段、比对有效期 / 类目，减少人工核验量；结果可追溯，仅预审、人工核验兜底。

### 3.3 视觉合规审核工作台【M2】

上传 / 巡检图像经脱敏 + 云视觉分析，疑似标记 + 置信度分级（高 ≥0.9 / 中 0.7~0.9 / 低 <0.7），人工复核留痕；结论写入 A-02 档案与信用分。

### 3.4 图像问答【M2】

拍照提问（包装合规 / 食材新鲜度）由视觉模型辅助回答，仅辅助判断、不作执法 / 鉴定结论。

### 3.5 风险预测预警【M3】

基于信用 / 交易 / 抽检 / 投诉数据预测风险商户（平台自建模型、数据不出域），联动 A-08 预警，AI 输出风险建议、人工决策执行。

### 3.6 后厨直播异常识别【M2/M3】

联动后厨直播做画面级异常标记（未穿工装 / 卫生 / 明火离人），需商户授权；标记进复核流、处置人工确认、不自动处罚。

## 4. 非功能性需求要求

### 4.1 全平台通用基线（所有服务共同遵守）

- **规模**：覆盖 ≈840 万；注册 ≥600 万、MAU ≥200 万、商户/机构 ≥10 万、DAU 峰值 ≈120 万。
- **性能**：API P95 ≤500ms / P99 ≤1s；**AI 类同步 P95 ≤3s**（按异步任务设计）。
- **可用性分级 SLO**：L1 ≥99.95% / L2 ≥99.9% / L3 ≥99.5%。
- **容灾**：同城双活 + 异地灾备，RPO ≤15min、RTO ≤30min（L1）。
- **安全**：等保三级 + OWASP ASVS L2；TLS 1.2+；密钥 KMS/HSM。

### 4.2 本服务专项要求

- **可用性 / 降级**：云视觉 / OCR 不可用 → 任务进人工复核队列原样流转，AI 标记缺席不阻塞；云视觉 API 恢复。
- **性能 / 成本**：全部异步任务化（MQ + 进度回调）；Redis 令牌桶按账号限流；第三方调用超时 / 重试 / 熔断护栏由 Sentinel 网关或自研限速器承接。
- **隔离与舱壁**：Python 侧 asyncio 异步并发 + 独立进程部署，与主站 JVM 资源天然隔离。
- **数据合规（R-05）**：图像脱敏前置（去人脸 / 车牌）；数据不出域；云视觉不用于训练；复核结果只用于平台调优、不回流第三方。
- **决策边界（C8）**：AI 只标记不决策，置信度分级（高 / 中 / 低），人工确认后处置，全链路审计；不自动处罚。
- **可观测**：OCR 通过率、预警准确率作为业务级监控指标；SkyWalking Python agent 或 OTel 导出，traceId 与主站透传一致。
