# 画像服务（PROFILE · Profile）

> 微服务说明文档 · 依据《产品需求文档》（PRD v2.3）与《产品设计文档》（PDD v1.0（基线））编写
> 本文档用于明确该微服务的**功能与质量基线**，支持后续扩展开发。功能口径以 PDD §5.11 / §6.4.11 为准，需求口径以 PRD §5.12（J 组 J7）与 `28-个人画像与个性化推荐需求.md` 为准。

## 1. 服务概述

- **服务标识**：`profile`（画像服务）
- **服务定位**：个人画像构建、画像四权管理、个性化推荐与商铺画像（选择性监管）。
- **对应模块**：J7 个人画像 + 商铺画像（J-07~J-11）。
- **里程碑**：M1 基础版 / M2 完整版。
- **实现载体 / 技术栈**：**业务留 Java**（Java 17 + Spring Boot 3.5，与 ACC / CRED / 行为日志数据域耦合深）；算法 / 推荐子服务按需后置 Python（属 AICORE 扩展位，本期不做）。
- **三端分布**：消费端（画像四权 / 个性化）· 经营端（基础）· 监管端（画像合规审计 / 选择性监管）。
- **未成年人保护环节**：本服务承担「不为未成年人建行为 / 购买画像」；跨服务统一出口见 DASH（A-08 违规入场高频举报聚合）。
- **依赖服务 / 外部依赖（上游）**：ACC（实名）、CRED / EMP（履历 / 信用）、行为日志。
- **被依赖（下游）**：ASSIST（推荐画像输出消费方）、DASH（商铺画像 → 分级监管）。
- **核心状态机**：画像生命周期（构建 → 授权可撤回 → 四权操作 → 关闭个性化回退通用规则 / 删除后衍生数据 30 天清理）。

## 2. 背景条件

- **需求背景（解决什么问题）**：三端共同痛点「不知道挑选哪一个对象」（选择困难）需要个性化排序，但用户同时有「画像失控、被杀熟」的担忧（PRD §4.0、§4.1 US-11）。画像服务在「推荐增强」与「用户可控、不杀熟」之间取平衡。
- **前置条件（本服务运行前提）**：
  - 用户已实名；数据源按授权策略采集（履历 / 行为入画像需授权、可撤回）。
- **平台红线约束（本服务需强落地）**：
  - R-07 画像数据合规——最小化 + 授权可撤回 + 四权 + 不杀熟 + 未成年不建画像 + 加密 / 脱敏 / 审计（AC-C7）；
  - 价格不因画像差异化（C7 不杀熟不变）。
- **里程碑边界**：M1 基础版（画像构建 / 四权 / 推荐基础）；M2 完整版（加购买行为、商铺画像与选择性监管）。

## 3. 主要功能

### 3.1 个人画像构建与数据授权

聚合实名 / 履历 / 行为 / 评论 / 购买 / 主动完善六类数据源构建画像，履历与行为入画像需授权可撤回；未授权字段不入画像；未成年人不建行为 / 购买画像。

### 3.2 画像管理页（用户四权）

查看 / 修改 / 关闭个性化 / 删除画像四权齐全，操作全审计；关闭个性化 → 推荐回退通用规则、停止行为采集；删除 → 衍生数据 30 天清理。

### 3.3 个性化推荐增强

在规则排序上叠加画像权重（职业加权 / 价格敏感 / 适龄过滤），理由标注画像依据、价格不变；叠加不替代、价格与画像无关。

### 3.4 商铺画像与选择性监管【M2】

聚合商铺信息 / 购买者评价 / 卫生 / 信用 / 风险五类特征构建商铺画像，供推荐排序与「画像风险 + 信用」分级监管；商铺画像 = 特征集合，信用分 = CRED 派生的可公示评分，不另立第二套评分。

## 4. 非功能性需求要求

### 4.1 全平台通用基线（所有服务共同遵守）

- **规模**：覆盖 ≈840 万；注册 ≥600 万、MAU ≥200 万、商户/机构 ≥10 万、DAU 峰值 ≈120 万。
- **性能**：核心读首屏 P95 ≤2s；核心写 P95 ≤3s；API P95 ≤500ms / P99 ≤1s。
- **可用性分级 SLO**：L1 ≥99.95% / L2 ≥99.9% / L3 ≥99.5%。
- **容灾**：同城双活 + 异地灾备，RPO ≤15min、RTO ≤30min（L1）。
- **安全**：等保三级 + OWASP ASVS L2；TLS 1.2+；密钥 KMS/HSM。

### 4.2 本服务专项要求

- **可用性等级：L2（≥99.9%）**；推荐 / 画像不可用 → 回退通用规则排序，**不因降级做差异化定价**（C7 不杀熟不变）。
- **数据安全**：画像标签属高敏感，AES-256-GCM 加密存储、脱敏输出、来源可查、全链路审计；删除后衍生数据 30 天内清理。
- **隐私合规（R-07）**：采集告知同意 + 最小化；授权可撤回；四权齐全；未成年人不建行为 / 购买画像；数据不出境。
- **性能**：画像构建与标签计算异步化，避免阻塞主流程。
- **可观测**：画像授权率作为业务级监控指标（PDD §8.5.3）。
