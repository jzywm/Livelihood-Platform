# 助手服务（ASSIST · Assistant）

> 微服务说明文档 · 依据《产品需求文档》（PRD v2.0）与《产品设计文档》（PDD v1.12）编写
> 本文档用于明确该微服务的**功能与质量基线**，支持后续扩展开发。功能口径以 PDD §5.7 / §6.4.12 为准，需求口径以 PRD §5.12（J 组，J-01~J-13）与 `27-智能助手Agent需求.md` 为准。

## 1. 服务概述

- **服务标识**：`assist`（助手服务）
- **服务定位**：三端复用的**智能助手侧边栏**，执行「脱敏 → 意图 → 动作」，平台硬护栏强制。
- **对应模块**：J 智能助手（J1~J6 / J13 / J15，J-01~J-06 / J-13 / J-15）。
- **里程碑**：M1 交付。
- **实现载体 / 技术栈**：**独立 Python 服务**（Python 3.12 + FastAPI + LangChain 编排，httpx / Pydantic / uvicorn/gunicorn），经统一鉴权 / 内部接口取数、**不直连主站数据库**。
- **三端分布**：消费端（深度：指导 / 跳转 / 推荐）· 经营端（基础问答）· 监管端（基础问答）。
- **未成年人保护环节**：本服务承担「内容年龄限制（未成年人场景额外敏感词与年龄限制）」；跨服务统一出口见 DASH（A-08 违规入场高频举报聚合）。
- **依赖服务 / 外部依赖**：ACC / CRED / TRACE（内部接口取数）、PROFILE（推荐画像输出）、LLM（DeepSeek 开放平台）。
- **核心状态机**：智能助手对话（会话 30 分钟 TTL 自动清空；兜底 FAQ → 人工入口 G1；合规脱敏前置、不出域、内容安全、非竞价推荐、理由透明）。

## 2. 背景条件

- **需求背景（解决什么问题）**：三端共同痛点「不会使用这个工具」（使用门槛高、上手成本高、求助无门）与「不知道挑选哪一个对象」（选择困难）（PRD §4.0）。助手用自然语言降低使用门槛，把「翻多级菜单」变成「一句话直达」。
- **前置条件（本服务运行前提）**：
  - 用户已登录，助手侧边栏常驻可见；脱敏前置；
  - 仅依赖平台流程与文档，不编造事实。
- **平台红线约束（本服务需强落地）**：
  - R-06 对话数据合规——脱敏前置、数据不出域、不沉淀原文、日志 ≤30 天、内容安全（AC-C6）；
  - R-05 / C8 AI 只标记不决策——不开放 LangChain 自由工具 / 函数调用；
  - 非竞价推荐、排序不因画像差异化（不杀熟）。
- **里程碑边界**：M1 消费端深度 + 三端基础；ASSIST 与 AICORE 为平台 Agent/AI 侧唯一 Python 承载，独立仓库 + 独立 CI/CD。

## 3. 主要功能

### 3.1 使用指导（分角色 FAQ + 步骤引导）

分角色知识库 + 步骤式引导，答案绑定平台流程与文档、不编造，标注「以页面为准」。

### 3.2 页面跳转（意图导航）

自然语言 → 平台内部页面直达，仅白名单路由、跳转前二次确认、不对接外链、越权页面 2002 拦截。

### 3.3 对话内商品推荐（透明理由）

按规则排序推荐商品（信用 40% + 溯源 30% + 价格 20% + 好评 10%）并输出透明理由，非竞价、不杀熟、无付费置顶。

### 3.4 澄清式导购

模糊意图经模板化追问后输出 ≤5 个带理由对比，不臆断需求、可一键跳选品 / 详情。

### 3.5 会话上下文与人工兜底

会话内指代理解，30 分钟超时清空、不留跨会话记忆；无法识别走 FAQ → 人工入口（G1），不纯 AI 硬答。

### 3.6 内容安全与幻觉管控

输出过内容安全过滤与事实校验，防幻觉、标注「平台助手生成，请以页面信息为准」；未成年人场景额外敏感词与年龄限制。

## 4. 非功能性需求要求

### 4.1 全平台通用基线（所有服务共同遵守）

- **规模**：覆盖 ≈840 万；注册 ≥600 万、MAU ≥200 万、商户/机构 ≥10 万、DAU 峰值 ≈120 万。
- **性能**：API P95 ≤500ms / P99 ≤1s；**AI 类同步 P95 ≤3s**（按异步任务设计）。
- **可用性分级 SLO**：L1 ≥99.95% / L2 ≥99.9% / L3 ≥99.5%。
- **容灾**：同城双活 + 异地灾备，RPO ≤15min、RTO ≤30min（L1）。
- **安全**：等保三级 + OWASP ASVS L2；TLS 1.2+；密钥 KMS/HSM。

### 4.2 本服务专项要求

- **可用性 / 降级**：LLM 不可用 → 回退 FAQ 规则库 + 人工入口（G1），不纯 AI 硬答；LLM 健康检查恢复。
- **性能 / 成本**：全部异步任务化（MQ + 进度回调）；FAQ 规则库命中优先（高频兜底，降时延降成本）；对话流式输出；Redis 令牌桶按账号限流（防滥用）。
- **隔离与舱壁**：Python 侧 asyncio 异步并发 + 独立进程部署，与主站 JVM 资源天然隔离；第三方调用超时 / 重试 / 熔断护栏由 Sentinel 网关或自研限速器承接。
- **数据合规（R-06）**：脱敏前置（正则 + 实体识别）；数据不出域；不沉淀原文；对话日志 ≤30 天脱敏自动清理；内容安全过滤。
- **安全护栏**：LangChain 仅做对话 / 意图 / 流程编排，平台硬约束（脱敏前置 → 白名单路由 → FAQ 规则 → 内容安全 → 非竞价 → 审计日志）在编排之外强制执行，不开放自由工具 / 函数调用；密钥经 KMS/环境变量注入，不入库不入日志。
- **可观测**：业务指标 = 意图命中率 / 跳转成功率 / 推荐采纳率（脱敏）；SkyWalking Python agent 或 OTel 导出，traceId 与主站透传一致。
