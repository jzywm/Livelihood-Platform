# 交易服务（TRADE · Trade）

> 微服务说明文档 · 依据《产品需求文档》（PRD v2.3）与《产品设计文档》（PDD v1.0（基线））编写
> 本文档用于明确该微服务的**功能与质量基线**，支持后续扩展开发。功能口径以 PDD §5.9 / §6.4.8 为准，需求口径以 PRD §5.10（T 组，T4 担保撮合 + B2C）为准。

## 1. 服务概述

- **服务标识**：`trade`（交易服务）
- **服务定位**：担保交易、货款托管、验收退款、争议仲裁与交易互评，实现「透明交易」闭环。
- **对应模块**：T4 担保撮合 + B2C 购买（T-11 / T-12 / T-14 / T-15 / T-13 / T-16 / T-20）；D-04 退货退款、T-23 上门服务、A-09 禁购下单拦截【均 §5.14】；**F-01 货源发布与司机自由接单（C05 已决策归 TRADE，M2 随交付设计接口）**。
- **里程碑**：M2（设计先行，交付后置）。
- **实现载体 / 技术栈**：Java 17 + Spring Boot 3.5（模块化单体；M2 交易 / 结算按域**优先拆分独立部署**）。
- **三端分布**：消费端（担保下单 / 退款）· 经营端（采购 / 收款）· 监管端（交易合规监控 / 资金审计）。
- **未成年人保护环节**：本服务承担「未成年人交易下单拦截（A-09 校验）」；跨服务统一出口见 DASH（A-08 违规入场高频举报聚合）。
- **依赖服务 / 外部依赖**：PROD（商品）、SETTLE（分账）、支付分账通道、CRED（信用联动）。
- **核心状态机**：担保交易（待付款 → 已付款托管 → 已发货在途 → 待验收 48h → 已完成放款 + 互评；分支：拒收退款、争议仲裁、超时自动催发 / 自动确认）。

## 2. 背景条件

- **需求背景（解决什么问题）**：交易信任缺失（货款被骗、图文不符）、资金拖欠（PRD §2.1 问题 1/4）。担保托管让「先钱后货」变得有保障，是 B2B 为主、延伸 B2C 的透明交易核心。
- **前置条件（本服务运行前提）**：
  - 采购方已实名、商品在售、货款可冻结；
  - 分账产品资质已开通（M0 前置，R-14）。
- **平台红线约束（本服务需强落地）**：
  - R-01 不碰货款 = 不二清——货款托管于持牌机构（非平台账户），平台仅收服务费（成交额 0.5%~1% 分品类，费率公开）；
  - R-15 防刷单防作弊——同 IP / 设备高频、价格异常拦截；履约异常处置；
  - R-03 数据分级授权——争议仲裁结果脱敏公示。
- **里程碑边界**：M2 交付；农资 + 食材先行，B2C 购买链路与 B2B 选品采购链路同核设计。

## 3. 主要功能

### 3.1 担保交易与货款托管

下单后货款托管于持牌机构，平台仅收服务费、不碰货款（不二清）；携带幂等键提交，重复下单 3008 幂等返回。

### 3.2 到货验收与拒收退款

收货后 48h 验收期，支持确认 / 部分 / 全额拒收；验收通过放款 + 互评，拒收退款，超期自动确认；生鲜 / 农资验收期可差异化配置。

### 3.3 争议仲裁与结果公示

验收 / 货款争议进入存证仲裁，平台给出结论并脱敏公示，计入双方信用。

### 3.4 交易互评与信用联动

交易完成双方互评，更新供应商 / 商户信用分（T-05 / A-07）；恶意差评走 D-03 申诉。

### 3.5 履约异常处置与防刷单风控

超时未发货自动催发 / 可取消退款，验收超期自动确认；异常交易（同 IP / 设备高频、价格异常）风控拦截留痕。

## 4. 非功能性需求要求

### 4.1 全平台通用基线（所有服务共同遵守）

- **规模**：覆盖 ≈840 万；注册 ≥600 万、MAU ≥200 万、商户/机构 ≥10 万、DAU 峰值 ≈120 万。
- **性能**：核心读首屏 P95 ≤2s；核心写 P95 ≤3s；API P95 ≤500ms / P99 ≤1s。
- **可用性分级 SLO**：L1 ≥99.95% / L2 ≥99.9% / L3 ≥99.5%。
- **容灾**：同城双活 + 异地灾备，RPO ≤15min、RTO ≤30min（L1）。
- **安全**：等保三级 + OWASP ASVS L2；TLS 1.2+；密钥 KMS/HSM。
- **数据**：交易流水按月分表；审计日志 ≥6 个月；存证只增不改。

### 4.2 本服务专项要求

- **可用性等级：L1（≥99.95%）**——担保交易 / 货款托管为核心链路，是 L1 停机预算与容灾覆盖对象。
- **资金一致性红线**：货款托管于持牌机构（非平台账户）；幂等键 + 超时状态机；无重复扣款 / 重复入账；每日对账 JOB 补差（与 SETTLE 联动）。
- **性能**：交易表 / 流水按月分表；M2 交易按域独立库 + 独立部署（写吞吐优先拆分）。
- **安全**：敏感操作（放款 / 退款 / 申诉）强制 MFA；防刷单风控（同 IP / 设备高频、价格异常拦截）。
- **可观测**：履约超时率、对账差异作为业务级监控指标。
