# 商品服务（PROD · Product）

> 微服务说明文档 · 依据《产品需求文档》（PRD v2.0）与《产品设计文档》（PDD v1.12）编写
> 本文档用于明确该微服务的**功能与质量基线**，支持后续扩展开发。功能口径以 PDD §5.8 / §6.4.7 为准，需求口径以 PRD §5.10（T 组，T1 选品广场）为准。

## 1. 服务概述

- **服务标识**：`prod`（商品服务）
- **服务定位**：商品上架审核、选品广场检索与商品透明详情，支撑「全产业选品透明」。
- **对应模块**：T1 选品广场（T-02 / T-03 / T-21 采购决策辅助）。
- **里程碑**：M2（设计先行，交付后置）。
- **实现载体 / 技术栈**：Java 17 + Spring Boot 3.5（模块化单体）。
- **三端分布**：消费端（选品）· 经营端（采购 / 上架）· 监管端（交易合规监控）。
- **依赖服务 / 外部依赖**：TRACE（批次 / 资质关联）、CRED（供应商信用）、AICORE（图像 / OCR）。
- **核心状态机**：商品（草稿 → 待审核 → 已上架 ⇄ 下架；异常强制下架）。

## 2. 背景条件

- **需求背景（解决什么问题）**：采购方「不知道进什么货、选哪家供应商」（经营端 #8），供应商「好货无人知」（经营端 #6）。选品广场把供应商信用 / 溯源 / 价格集中展示，降低选品决策成本。
- **前置条件（本服务运行前提）**：
  - 供应商已入驻，关联批次与检测报告齐全。
- **平台红线约束（本服务需强落地）**：
  - R-08 轻资产原则——只做撮合，**不代下单、不代定价、无包赚承诺**；
  - R-09 强监管品类仅信息撮合，不替代行政许可；
  - R-13 无竞价广告 / 隐性扣费。
- **里程碑边界**：M2 交付；商品资质临期 / 投诉激增强制下架。

## 3. 主要功能

### 3.1 商品上架审核与批次关联

商品关联资质 / 批号 / 检测报告上架，平台校验后审核，全程留痕；资质 / 报告过期拒绝上架（3003），异常强制下架并通知。

### 3.2 跨行业选品广场

按行业 / 品类组织商品浏览，支持信用 / 溯源完整 / 价格 / 距地筛选，衔接担保下单（T-11）。

### 3.3 商品透明详情页与供应商主页

详情页聚合来源 / 批次 / 检测 / 信用 / 价格 / 溯源码；供应商主页聚合资质与信用构成；资质临期展示风险提示，投诉入口关联 D2。

### 3.4 采购决策辅助

采购需求描述 → 候选收敛 → 供应商横向对比 → 收藏 / 询价，只做撮合不代下单、排序非竞价、价格透明。

## 4. 非功能性需求要求

### 4.1 全平台通用基线（所有服务共同遵守）

- **规模**：覆盖 ≈840 万；注册 ≥600 万、MAU ≥200 万、商户/机构 ≥10 万、DAU 峰值 ≈120 万。
- **性能**：核心读首屏 P95 ≤2s；核心写 P95 ≤3s；API P95 ≤500ms / P99 ≤1s。
- **可用性分级 SLO**：L1 ≥99.95% / L2 ≥99.9% / L3 ≥99.5%。
- **容灾**：同城双活 + 异地灾备，RPO ≤15min、RTO ≤30min（L1）。
- **安全**：等保三级 + OWASP ASVS L2；TLS 1.2+；密钥 KMS/HSM。
- **数据**：审计日志 ≥6 个月；存证只增不改。

### 4.2 本服务专项要求

- **可用性等级：L2（≥99.9%）**——选品检索属 L2 覆盖对象。
- **检索性能**：M2 引入 ES 检索，ES 不可用回退 MySQL 近似检索（PDD §8.2.4 依赖降级清单）。
- **UX 基线**：商品上架录入 ≤1 分钟（扫码 / 拍照 + OCR）；商品透明信息一步可查。
- **合规**：强监管品类仅信息撮合；资质临期 / 投诉激增强制下架；排序非竞价、价格透明（R-08/R-09/R-13）。
