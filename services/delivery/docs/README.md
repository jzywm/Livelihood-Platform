# 配送服务（DELIVERY · Delivery）

> 微服务说明文档 · 依据《产品需求文档》（PRD v2.0）与《产品设计文档》（PDD v1.4）编写
> 本文档用于明确该微服务的**功能与质量基线**，支持后续扩展开发。功能口径以 PDD §5.15 为准，需求口径以 PRD §5.14（L 组，L-01~L-06）为准。

## 1. 服务概述

- **服务标识**：`delivery`（配送服务）
- **服务定位**：本地配送（同城即时配送）下单/地址定位、订单状态机与全程跟踪、商家接单备货、运营调度看板、运力管理与位置轨迹存证。
- **对应模块**：L 组（L-01~L-06）。
- **里程碑**：M2 交付；骑手端 App 后置（骑手侧动作暂由运营端人工调度 + 运力档案承载）。
- **实现载体 / 技术栈**：Java 17 + Spring Boot 3.5（模块化单体）。
- **三端分布**：消费端（配送下单 / 订单跟踪）· 经营端（接单 / 备货出餐）· 运营端（调度看板 / 运力管理，`/ops`）。
- **依赖服务 / 外部依赖**：TRADE（订单/结算关联）、CRED（骑手信用档案，复用 A-06/F-03 思路）、SETTLE（分账/退款，复用 I-04 分账反向）、GPS（手机定位，前端直连，同 F-02）。
- **核心状态机**：配送订单（待支付 → 待接单 → 商户备货 → 待取货 → 配送中 → 已送达 → 已完成；分支：取消 / 超时 / 异常）。

## 2. 背景条件

- **需求背景（解决什么问题）**：消费者需「同城即时送达」（外卖/生鲜/商超），缺下单与定位选点能力；配送过程不可见、状态不透明、异常无感知（PRD §5.14 L 组）。
- **前置条件（本服务运行前提）**：
  - 消费者已实名；商品/商家支持配送；
  - 位置数据最小化使用、脱敏存储（R-03/R-07）。
- **平台红线约束（本服务需强落地）**：
  - 复用 SETTLE 结算 + P-02 存证，**不重复建结算/存证体系**（与 TRADE、SETTLE、CRED 关联）；
  - 不做北斗硬件对接——位置/轨迹复用手机 GPS（同 F-02）；
  - R-03 位置/轨迹分级授权（本人可见 → 授权可见 → 脱敏公示）。
- **里程碑边界**：M2 交付；骑手端 App 后置，本次仅运营端运力管理承载骑手档案，不落地骑手 App 页面。

## 3. 主要功能

### 3.1 配送下单与地址定位选点（L-01）

下单选/新增收货地址（GPS 定位 + 地图选点 + 常用地址/地址簿）；校验配送范围（超范围显式提示不可达并禁用提交）；生成配送订单并计算配送费/预计送达。

### 3.2 配送订单状态机与全程跟踪（L-02）

配送订单状态机（待支付→待接单→商户备货→待取货→配送中→已送达→已完成；分支：取消/超时/异常）；消费者实时查看状态、骑手位置与轨迹、预计送达；超时/异常自动提示并可催单/投诉。

### 3.3 商家接单与备货出餐（L-03）

商户接收配送订单（接单/拒单，超时自动处理并预警）；备货/出餐状态上报（备货中→待取货）；请求取货/转运营调度；拒单原因留痕计入信用（A-07）。

### 3.4 运营调度看板（L-04）

运营端订单总览 + 地图看板（订单热力/骑手位置）；自动/人工派单、改派、取消、催单；超时/异常订单预警并人工处置；处置留痕可审计。

### 3.5 运力管理（L-05）

骑手/配送员实名、健康证、背景核验（复用 A-06/F-03 思路）、信用档案（接单履约率/超时/投诉）、在线状态、停用/启用；骑手端 App 本次不建，运力档案供运营端派单使用。

### 3.6 位置轨迹存证与异常预警（L-06）

配送全程位置轨迹存证（时间戳+哈希，复用 P-02）；超时/偏航/异常停留自动预警并推送运营端；轨迹可出证供纠纷仲裁（复用 D-02/T-15 机制）。

## 4. 非功能性需求要求

### 4.1 全平台通用基线（所有服务共同遵守）

- **规模**：覆盖 ≈840 万；注册 ≥600 万、MAU ≥200 万、商户/机构 ≥10 万、DAU 峰值 ≈120 万。
- **性能**：核心读首屏 P95 ≤2s；核心写 P95 ≤3s；API P95 ≤500ms / P99 ≤1s。
- **可用性分级 SLO**：L1 ≥99.95% / L2 ≥99.9% / L3 ≥99.5%。
- **容灾**：同城双活 + 异地灾备，RPO ≤15min、RTO ≤30min（L1）。
- **安全**：等保三级 + OWASP ASVS L2；TLS 1.2+；密钥 KMS/HSM。
- **数据**：审计日志 ≥6 个月；存证只增不改。

### 4.2 本服务专项要求

- **可用性等级：L2（≥99.9%）**——配送属 L2 覆盖对象（非核心资金链路）。
- **实时跟踪**：订单状态/位置实时推送走 SSE（短轮询兜底）；轨迹抽稀（Douglas-Peucker）+ 分段加载，降低带宽。
- **派单一致性**：同一骑手并发派单 → 幂等/乐观锁拦截，提示「已改派，请刷新」。
- **数据合规**：位置/轨迹按 R-03 分级授权；敏感个人信息加密存储（R-07）；轨迹存证只增不改（P-02）。
- **可观测**：履约率 / 超时率作为业务级监控指标。
