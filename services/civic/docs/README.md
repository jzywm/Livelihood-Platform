# 民生互动服务（CIVIC · Civic）

> 微服务说明文档 · 依据《产品需求文档》（PRD v2.0）与《产品设计文档》（PDD v1.3）编写
> 本文档用于明确该微服务的**功能与质量基线**，支持后续扩展开发。功能口径以 PDD §5.13 / §6.4.10 为准，需求口径以 PRD §5.6（E 组）、§5.8（G 组）、§5.9（H 组）为准。

## 1. 服务概述

- **服务标识**：`civic`（民生互动服务）
- **服务定位**：群众建议论坛、民生项目公开与进度、优质小店免费推广与行业圈层论坛，承载「政府牵头、群众监督」。
- **对应模块**：G2 论坛 / H 民生建设监督 / E 社区生态（G-02 / H-01 / H-02 / E-01 / E-02）；E-04 商户动态【§5.14】。
- **里程碑**：M2~M3（占位，仅边界，交付后置）。
- **实现载体 / 技术栈**：Java 17 + Spring Boot 3.5（模块化单体）。
- **三端分布**：消费端（看进度 / 提意见 / 看推荐榜单）· 经营端（免费上榜）· 监管端（建设方回应）。
- **依赖服务 / 外部依赖**：ACC（实名）、OSS（图文存储）、DASH（公示联动）。
- **核心状态机**：群众建议（提交 → 平台审核分派 → 限时答复 → 采纳 / 部分采纳 / 不采纳 + 理由公示）。

## 2. 背景条件

- **需求背景（解决什么问题）**：民生诉求响应难（监管端 #7）、民生建设监督缺抓手（PRD §2.1 问题 2/6）。CIVIC 让群众意见有回音、民生项目进度可监督、优质小店靠信用获免费推广（信用 → 流量 → 守法正循环）。
- **前置条件（本服务运行前提）**：
  - 用户已实名；建议 / 发帖内容合规；
  - 政务接口不可接 → 自建替代（P-04 双轨）。
- **平台红线约束（本服务需强落地）**：
  - 内容治理防谣言——敏感词 + 人工复核；
  - R-03 数据分级授权——匿名建议脱敏、结果公示脱敏；
  - R-13 优质小店推广非竞价、不收费；
  - 与画像边界——不收集无关信息、不用于画像训练。
- **里程碑边界**：M2 群众建议论坛；M3 民生项目公开 / 优质小店推广 / 行业圈层论坛（本节为 M2~M3 占位，仅边界）。

## 3. 主要功能

### 3.1 群众建议论坛【M2】

群众按分类发帖建议（实名 / 匿名可选），平台审核分派、限时答复并公示采纳情况；优秀建议可获积分 / 荣誉。

### 3.2 民生项目公开与进度【M3】

政府发布民生项目（计划 / 资金 / 工期 / 责任部门）并实时同步进度，群众可查、可提意见；建设方限时回应并公示。

### 3.3 优质小店免费推广【M3】

优质小店免费上榜、群众点评、信用加权推荐（非竞价、不收费），形成「信用 → 流量 → 守法」正循环。

### 3.4 行业圈层论坛【M3】

按行业 / 地域分层的行业圈层论坛，敏感词 + 人工复核治理；行业交流互助、内容治理留痕。

## 4. 非功能性需求要求

### 4.1 全平台通用基线（所有服务共同遵守）

- **规模**：覆盖 ≈840 万；注册 ≥600 万、MAU ≥200 万、商户/机构 ≥10 万、DAU 峰值 ≈120 万。
- **性能**：核心读首屏 P95 ≤2s；核心写 P95 ≤3s；API P95 ≤500ms / P99 ≤1s。
- **可用性分级 SLO**：L1 ≥99.95% / L2 ≥99.9% / L3 ≥99.5%。
- **容灾**：同城双活 + 异地灾备，RPO ≤15min、RTO ≤30min（L1）。
- **安全**：等保三级 + OWASP ASVS L2；TLS 1.2+；密钥 KMS/HSM。
- **数据**：审计日志 ≥6 个月；存证只增不改。

### 4.2 本服务专项要求

- **可用性等级：L3（≥99.5%）**——内容 / 资讯 / 非关键链路，允许短暂降级。
- **内容安全**：敏感词 + 人工复核；防谣言；未成年人内容年龄限制。
- **数据合规**：匿名建议脱敏；与画像边界清晰（不收集无关信息、不用于画像训练）；经营者个人信息脱敏（R-03）。
- **推广合规**：优质小店榜非竞价、不收费，信用加权 + 防刷拦截（R-13/R-15）。
