## 决策与发现

- 里程碑决策:网关由「M1 后期独立部署 + 内嵌 Filter 过渡」改为 **M1 初期交付即接管**(网关为平台唯一鉴权点,ACC 内嵌鉴权 Filter 移除,服务内仅保留业务越权校验 2002 与内部回调 Token 鉴权);兜底口径改「**双实例 + 故障快速失败 503**」,作废「网关故障 → Nginx 直连单体降级」(无鉴权直连即安全破口)。
- 令牌时效定档:短 token **15 分钟** + 长 token **7 天**(HttpOnly + Secure + SameSite Cookie,仅换发);PDD 中「JWT 时效」原为【待评审】阈值项,本次落地;**换发(refresh)接口尚未实现**,属接口清单新增,登记不臆造。
- ACC 缺陷处置口径:取「**最小修复(自动提交)+ 登记残余限制**」——长驻会话、跨表写入无原子性、并发串行化风险待 M2 收敛为「按请求会话 + 显式事务边界」,不在交付期重构数据层。
- 装配陷阱(实测):`@ConfigurationProperties` 记录绑定**只允许唯一构造器**(给嵌套记录加第二构造器 → `gateway.auth` 绑定为 `null`、12 个上下文用例同时变红),需要默认值用**静态工厂** `Auth.of(...)`;**test 作用域依赖也会经依赖调解污染运行期 API**(mariaDB4j 传递 javax 时代 `jakarta.annotation-api:1.3.5` → 容器启动 `NoClassDefFoundError`),须显式钉版。
- ACC 事务边界口径落地(2026-09-15,承接上条「M2 收敛」登记):**一个请求 = 一个事务**——成功提交、未捕获异常(含受检)回滚、错误 Envelope 由 `rollbackOnly` 标记驱动回滚、`finally` 关闭会话并清 ThreadLocal;并发请求各持独立会话/连接;失败请求不再留幂等占位(同 `Idempotency-Key` 可立即重试);**不改接口、错误码、Envelope、分表路由与字段加解密**。判据纠偏(评审 F2):MyBatis `openSession()` 只赋字段不取连接,故「6 个 `@MockBean` 控制器测试全绿」**不能**证明惰性开启,真正判据是单测中「未触库时 `openSession` 零调用」的 mock 断言。
