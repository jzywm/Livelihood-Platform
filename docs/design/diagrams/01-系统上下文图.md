# 01 · 系统上下文图

> 来源:概要设计说明书 §2.2 · 民生甄选平台与外部角色/外部系统的关系
> 查看:Typora 打开本文件即可渲染;源码可粘贴 [mermaid.live](https://mermaid.live) 校验

```mermaid
graph LR
    subgraph R1["外部角色"]
        C[消费者/工作者]
        B[商户/老板]
        S[供应商]
        G[监管/政府]
    end
    subgraph R2["民生甄选平台"]
        WEB[PC Web 前端<br/>消费端/经营端/监管端]
        API[平台后端 API 网关<br/>GATEWAY 微服务]
    end
    subgraph R3["外部系统"]
        PAY[微信支付/支付宝/聚合支付<br/>代付/收款/分账]
        LLM[DeepSeek 开放平台 API]
        SMS[短信服务]
        GPS[手机 GPS 定位]
        GOV[政务线下联动<br/>市监/部门工单流转]
    end
    C --> WEB
    B --> WEB
    S --> WEB
    G --> WEB
    WEB --> API
    API --> PAY
    API --> LLM
    API --> SMS
    API --> GPS
    API -. 线下协同 .-> GOV
```

> 说明:四类外部角色经 PC Web 访问平台;平台经网关(GATEWAY 微服务,M1 后期独立部署)对接外部系统(支付通道 / DeepSeek / 短信 / GPS);政务联动为线下协同(石监码/12345 不可接,自建替代)。
