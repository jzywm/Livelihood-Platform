# 13 · AI 视觉合规审核流程（K1 · 监管端）

> 来源:概要设计说明书 §7.9 AI 辅助边界;需求详见 `需求调研/29-AI能力中心需求.md` §3
> 查看:Typora 打开本文件即可渲染;源码可粘贴 [mermaid.live](https://mermaid.live) 校验

```mermaid
graph TD
    A[监管上传/巡检图片<br/>原材料/证照/抽检样品] --> B[图像预处理<br/>压缩 + 脱敏(去人脸/车牌)]
    B --> C[云视觉 API 分析<br/>通义VL/GLM-4V 合规协议]
    C --> D[疑似问题标记<br/>过期/变质/包装违规/资质不符]
    D --> E{置信度分级}
    E -- 高 ≥0.9 --> F[推监管人工确认<br/>一键生成核查单]
    E -- 中 0.7~0.9 --> G[复核队列]
    E -- 低 <0.7 --> H[自动忽略/归档 30 天]
    F --> I[人工复核<br/>留痕:谁/何时/结论]
    G --> I
    I --> J[结论写入商户档案 A1<br/>联动信用分 A3]
    C --> K[全链路审计<br/>调用/标记/复核留痕]
```

> 合规红线(AC-C8):AI 只做辅助筛查与标记,**任何执法/处罚/公示必须人工确认后执行**;图像脱敏+加密+审计;云视觉 API 不用于训练(数据合规协议);复核结果只调平台阈值,不回流第三方模型训练。
