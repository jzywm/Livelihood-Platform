# 06 · 工资保障代付流程（I3）

> 来源:概要设计说明书 §5.2 · 模式丙:代付留痕 + 欠薪预警 + 证据出证
> 查看:Typora 打开本文件即可渲染;源码可粘贴 [mermaid.live](https://mermaid.live) 校验

```mermaid
graph TD
    A[老板发起发薪<br/>选员工/金额/周期] --> B[平台校验用工/考勤记录]
    B --> C{校验通过?}
    C -- 否 --> Z1[退回老板<br/>提示缺记录]
    C -- 是 --> D[调持牌机构代付<br/>微信商家转账/支付宝转账]
    D --> E{通道结果}
    E -- 成功 --> F[工作者收款确认<br/>平台生成流水+存证哈希]
    F --> G[更新劳务信用<br/>老板发薪履约率+]
    E -- 失败/超时 --> H[重试/人工复核]
    H --> D
    JOB[定时任务] -->|应发未发超时| K[欠薪预警<br/>证据打包:流水+用工记录]
    K --> L[平台协助:催办/仲裁/监察出证]
```

> 关键设计:平台**只记账不碰钱**——资金由持牌机构从老板绑定对公/法人账户划转;流水号 + 通道交易号 + 时间戳 + 哈希,即证据链。状态:待校验 → 代付中 → 已到账(完成)/ 预警。
