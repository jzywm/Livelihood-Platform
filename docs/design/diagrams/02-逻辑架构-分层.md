# 02 · 逻辑架构（分层）

> 来源:概要设计说明书 §2.3 · 接入层/应用层/领域服务层/数据层/基础设施分层
> 查看:Typora 打开本文件即可渲染;源码可粘贴 [mermaid.live](https://mermaid.live) 校验

```mermaid
graph TB
    subgraph L0["接入层"]
        NG[API 网关 GATEWAY<br/>鉴权/限流/路由]
    end
    subgraph L1["应用层"]
        WEB2[消费端 BFF/直连]
        OPS[经营端 BFF/直连]
        REG[监管端 BFF/直连]
    end
    subgraph L2["领域服务层"]
        ACC[账户服务<br/>I1 实名+记账簿]
        SETTLE[结算服务<br/>I3 代付/I4 分账/对账]
        CRED[信用档案服务<br/>A1/A2/A3 信用分]
        EMP[用工服务<br/>C2 防童工/I2 劳务信用]
        TICKET[工单服务<br/>D2 投诉/G1 热线]
        TRACE[溯源服务<br/>T2 供应商信用/T3 溯源码]
        ASSIST[助手服务<br/>J1~J6 对话/跳转/推荐]
        PROFILE[画像服务<br/>J7 画像构建/标签/四权]
        AICORE[AI 能力中心<br/>K 视觉审核/OCR/问答/预测]
        PROD[商品服务 M2<br/>T1 选品广场]
        TRADE[交易服务 M2<br/>T4 担保交易/B2C 订单]
        DASH[看板服务<br/>监管数据总览]
    end
    subgraph L3["数据层"]
        DB[(MySQL 主库)]
        REDIS[(Redis 缓存/会话/限流)]
        OSS[(对象存储<br/>证照/单据/证据)]
        LOG[(日志/脱敏对话日志)]
    end
    subgraph L4["基础设施"]
        MQ[消息队列<br/>工单/预警/对账]
        JOB[定时任务<br/>欠薪预警/自动确认/对账]
    end
    NG --> WEB2
    NG --> OPS
    NG --> REG
    WEB2 --> ACC
    WEB2 --> SETTLE
    WEB2 --> CRED
    WEB2 --> TRACE
    WEB2 --> ASSIST
    WEB2 --> PROFILE
    WEB2 --> DASH
    OPS --> ACC
    OPS --> SETTLE
    OPS --> CRED
    OPS --> EMP
    OPS --> TICKET
    OPS --> TRACE
    OPS --> ASSIST
    OPS --> PROFILE
    OPS --> PROD
    OPS --> TRADE
    REG --> ACC
    REG --> CRED
    REG --> TICKET
    REG --> TRACE
    REG --> PROFILE
    REG --> AICORE
    REG --> DASH
    ACC --> DB
    SETTLE --> DB
    CRED --> DB
    EMP --> DB
    TICKET --> DB
    TRACE --> DB
    ASSIST --> DB
    PROFILE --> DB
    AICORE --> DB
    PROD --> DB
    TRADE --> DB
    DASH --> DB
    ACC --> REDIS
    SETTLE --> REDIS
    ASSIST --> REDIS
    PROFILE --> REDIS
    SETTLE --> MQ
    TICKET --> MQ
    TRACE --> MQ
    ASSIST --> MQ
    SETTLE --> JOB
    ASSIST -. 脱敏后调用 .-> LLM
```

> 说明:应用层各端经网关（GATEWAY 微服务，M1 后期独立部署）访问全部领域服务,图中为代表性连线;完整依赖见概要设计 §2.4 模块与服务映射表。
