# 12 · 画像构建与个性化推荐流程（J7）

> 来源:概要设计说明书 §4 画像域 / §7.8 画像合规;需求详见 `需求调研/28-个人画像与个性化推荐需求.md`
> 查看:Typora 打开本文件即可渲染;源码可粘贴 [mermaid.live](https://mermaid.live) 校验

```mermaid
graph TD
    A[数据采集<br/>实名:年龄/性别<br/>履历:学历/工作(授权)<br/>行为:浏览/搜索/会话<br/>购买:M2 起<br/>主动完善] --> B[授权校验<br/>履历/行为需授权,可撤回]
    B --> C{授权通过?}
    C -- 否 --> D[该维度不入画像<br/>跳过]
    C -- 是 --> E[标签计算<br/>年龄带/职业/学历带/品类偏好/价格敏感度]
    E --> F[画像存储<br/>加密/脱敏/审计]
    F --> G{个性化开关?}
    G -- 开 --> H[画像输出<br/>供助手推荐/信息推送/使用引导]
    H --> I[推荐理由标注画像依据<br/>价格不因画像差异化]
    G -- 关/删除 --> J[回退通用规则<br/>30 天内清理衍生数据]
    J --> K[画像管理页<br/>查看/修改/关闭/删除]
```

> 合规红线(AC-C7):最小化收集;授权可撤回;四权(查看/修改/关闭/删除);不杀熟(价格与画像无关);未成年人不建行为/购买画像;操作审计留痕。
