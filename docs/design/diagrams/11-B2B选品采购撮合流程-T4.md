# 11 · B2B 选品采购撮合流程（T4 · M2 交付 · 设计先行）

> 来源:概要设计说明书 §5.8 · 担保交易 + 验收 48h + 分账放款(状态机沿用 `20` 已确认口径)
> 查看:Typora 打开本文件即可渲染;源码可粘贴 [mermaid.live](https://mermaid.live) 校验

```mermaid
graph TD
    A[采购方(商户)下单<br/>选品广场选品] --> B[货款进第三方通道托管]
    B --> C[供应商发货<br/>在途可见]
    C --> D[采购方验收<br/>48h 期(生鲜/农资可差异化)]
    D -- 确认 --> E[分账放款<br/>货款→供应商,服务费→平台]
    E --> F[双方互评<br/>更新 T2 供应商信用/A3 商户信用]
    D -- 拒收 --> G[退款中<br/>证据留痕]
    D -- 超时未确认 --> H[自动确认+提示]
    D -- 争议 --> I[仲裁中<br/>平台存证调处]
    I --> E2[仲裁完成<br/>放款/退款]
```

> 状态机:待付款 → 已付款(托管) → 已发货(在途) → 待验收(48h) → 已完成(放款+互评);分支:拒收→退款中→已完成;争议→仲裁中→仲裁完成;异常:超时未发货→自动催发/可取消退款,验收超期→自动确认。
> 合规:货款托管于持牌机构(非平台账户),平台仅收服务费(成交额 0.5%~1% 分品类,费率公开),不碰货款 = 不二清。
