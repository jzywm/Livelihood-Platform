# 08 · 供应商入驻与溯源流程（T2/T3）

> 来源:概要设计说明书 §5.4 · 品类资质核验 + 一物一码溯源 + 供应商信用
> 查看:Typora 打开本文件即可渲染;源码可粘贴 [mermaid.live](https://mermaid.live) 校验

```mermaid
graph TD
    A[供应商入驻<br/>实名+营业执照] --> B[品类资质核验<br/>农资:经营许可证/登记证<br/>食材:食品经营/生产许可+检测报告]
    B --> C{核验通过?}
    C -- 否 --> Z1[驳回补证]
    C -- 是 --> D[开通上架权限<br/>生成信用档案 初始60分]
    D --> E[创建批次<br/>生成唯一溯源码]
    E --> F[环节上报<br/>①批号②检测③温控④终端]
    F --> G[扫码验真<br/>时间轴展示+断链标注]
    G --> H[信用联动<br/>交易/投诉更新 T2 信用分]
    H --> I{信用分≥85且无质量投诉?}
    I -- 是 --> J[放心供应商标识<br/>动态授予/撤销]
```

> 状态机:商品 草稿→待审核→已上架⇄下架(异常强制下架);溯源链路 ①批号→②检测→③温控→④终端(任一缺失=断链);供应商榜单 正常⇄警告(60~40)⇄黑榜(<40,降权/禁新单)。
