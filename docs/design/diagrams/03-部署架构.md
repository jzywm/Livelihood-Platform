# 03 · 部署架构

> 来源:概要设计说明书 §2.5 · 生产环境(双实例)与开发/测试环境
> 查看:Typora 打开本文件即可渲染;源码可粘贴 [mermaid.live](https://mermaid.live) 校验

```mermaid
graph LR
    subgraph P1["生产环境"]
        CDN[CDN/静态资源]
        LB[Nginx 负载均衡<br/>HTTPS/WAF]
        APP1[后端应用 A 实例]
        APP2[后端应用 B 实例]
        MYSQL[(MySQL 主从)]
        REDIS2[(Redis 哨兵/集群)]
        OSS2[(对象存储)]
        MQ2[消息队列]
    end
    subgraph P2["开发/测试环境"]
        DEV[Docker Compose<br/>应用+MySQL+Redis+MQ]
    end
    USER[浏览器用户] --> CDN
    CDN --> LB
    LB --> APP1
    LB --> APP2
    APP1 --> MYSQL
    APP2 --> MYSQL
    APP1 --> REDIS2
    APP2 --> REDIS2
    APP1 --> OSS2
    APP2 --> OSS2
    APP1 --> MQ2
    APP2 --> MQ2
    APP1 -. HTTPS .-> PAY2[支付通道]
    APP2 -. HTTPS .-> PAY2
    APP1 -. HTTPS .-> LLM2[DeepSeek 云 API]
    APP2 -. HTTPS .-> LLM2
```

> 说明:生产双实例起步;开发/测试用 Docker Compose 一键起;CI/CD 复用 `agent-sdlc-standard/templates`(GitHub Actions);敏感接口(支付回调、大模型)走服务端调用,前端不直连。
