# 10 · B2C 购买流程（M2 交付 · 设计先行）

> 来源:概要设计说明书 §5.7 · 消费者直接购买链路
> 查看:Typora 打开本文件即可渲染;源码可粘贴 [mermaid.live](https://mermaid.live) 校验

```mermaid
graph TD
    A[消费者浏览选品广场<br/>开放品类] --> B[查看商品详情<br/>来源/批次/检测/信用分]
    B --> C[加购/直接下单]
    C --> D[订单生成<br/>金额+服务费明细透明]
    D --> E[第三方通道收款<br/>资金托管持牌机构]
    E --> F[卖方发货]
    F --> G{买方验收}
    G -- 通过 --> H[分账:货款→卖方<br/>服务费0.5%~1%→平台]
    H --> I[完成<br/>流水留痕+交易互评]
    G -- 拒收/问题 --> J[退款原路退回<br/>或部分退款]
    J --> I
    G -- 超时未确认 --> K[自动确认<br/>提示]
```

> 状态:待付款 → 已付款(托管) → 已发货 → 待验收 → 已完成;分支:拒收 → 退款中 → 已完成。合规:买家资金直付持牌通道,平台不碰货款(不二清)。
