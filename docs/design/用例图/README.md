## 3. 编号规则（全局唯一、可追溯）

| 层 | 前缀 | 编号格式 | 示例 | 追溯 |
|---|---|---|---|---|

## 4. include / extend 推导规则（仅从文档显式关系推导，不臆造）

| 关系 | 语义 | 触发来源（32 功能列表原文措辞） | 实例 |
|---|---|---|---|
| `<<include>>` | 必选：被包含用例总被执行 | 「联动 / 复用 / 承担 / 支撑 / 共用 / 预审 / 内含」 | A-02 档案页 include A-04 价格公示；T-13 互评 include T-05 信用更新 |
| `<<extend>>` | 可选：满足条件才扩展执行 | 「未解决则 / 超时则 / 异常则 / 升级 / 触发」 | D-02 投诉 extend 升级市监；A-03 档案维护 extend 异常预警；T-12 验收 extend 拒收退款/争议仲裁 |

**分层落法**：
- **L1 业务用例图**：业务用例之间少量 `<<extend>>`（业务价值流，如「投诉维权 extend 明白消费」），在规约标注为业务层建模关系。
- **L2 系统用例图**：系统用例已聚合跨模块功能（`<<include>>` 被吸收进系统用例内），故跨模块 include 以规约「追溯」字段表达；图中仅画**端内条件** `<<extend>>`（如 UC-SYS-S11 仲裁 extend UC-SYS-S06 验收）与**跨端** extend 注释（如 UC-SYS-C02 投诉 extend UC-SYS-G05 升级市监）。
- **L3 子系统用例图**：仅画**模块内** include/extend（下表）；跨模块关系（A-01→K-01、T-11→I-04、T-16→D-02 等）在 L2 层与规约表达。

**模块内 include/extend 清单（L3 使用）**：
| 关系 | 依据 |
|---|---|
| UC-SUB-A-02 查询一店一档 `<<include>>` UC-SUB-A-04 公示价格 | 32 A-04「一店一档内展示…价目表」 |
| UC-SUB-T-13 互评交易 `<<include>>` UC-SUB-T-05 更新供应商信用 | 32 T-13「更新 T-05 供应商信用」 |
| UC-SUB-T-15 仲裁争议 `<<extend>>` UC-SUB-T-12 到货验收 | 32 T-15「验收争议进入存证仲裁」 |
| UC-SUB-J-09 增强个性化推荐 `<<include>>` UC-SUB-J-03 商品推荐 | 32 J-09「在 J-03 规则排序之上叠加画像权重」 |
| UC-SUB-J-13 澄清式导购 `<<include>>` UC-SUB-J-02 页面跳转 | 32 J-13「复用 J-02 页面跳转」 |
| UC-SUB-A-03 维护档案 `<<extend>>` UC-SUB-A-08 异常预警 | 32 A-03「异常双向推送」+ A-08「自动预警」 |

> 跨模块关系（如 D-02 投诉 `<<extend>>` 升级市监 G-03、A-01 `<<include>>` K-01 OCR、T-11 `<<include>>` I-04 分账、F-04 `<<include>>` I-03 代付、T-16 `<<include>>` D-02 机制）**不在 L3 子系统图内画线**，改由 L2 系统用例图与规约「追溯」字段表达（见 §6.2）。

## 5. 硬约束落法

| 约束 | 落法 |
|---|---|
| 系统边界矩形框 | 每图 `rectangle "边界名" { … }`，用例椭圆在框内 |
| 参与者框外、用例框内 | 参与者（火柴人）在 `rectangle` 之外，`-->` 连入框内用例 |
| 用例名动宾结构 | 全部用例名 = 动词+宾语（表达业务目标，如「查询一店一档」） |
| 每用例 ≥1 参与者 | 全部用例均连 ≥1 参与者；通用基础设施（I-01、J-01/J-02/J-07/J-08）连图中代表参与者 + note 标注「全角色共用」 |
| include/extend 清晰 | `..> <<include>>` / `..> <<extend>>` 显式标注，语义见 §4 |
| 唯一编号 | §3 三层前缀 + 端/模块代码，全局唯一 |
| 单图 5~15 用例 | L1/L2 均 5~11；L3 中 T(21) 拆 3 图，J(13)/A(8) 单图；C(1)/H(2)/B(3)/D(3)/E(3)/G(3) 为小模块，保持「模块级」粒度故用例数 <5，属文档化例外（合并会破坏模块边界） |
