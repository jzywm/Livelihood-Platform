# 子系统用例规约 · E 社区与生态（L3）

> 层：L3 子系统用例 · 标准字段 · 配套图 `E-社区与生态.puml`

### UC-SUB-E-01 参与行业圈层交流
- 参与者：商户、从业人员
- 前置：实名；后置：行业/地域分层交流可用
- 主成功场景：1 进入行业/地域圈层 2 发帖交流 3 内容治理防谣言
- 关键扩展：敏感词+人工复核
- 追溯：功能点 E-01｜UC-SYS-M10

### UC-SUB-E-02 免费推广优质小店
- 参与者：商户（上榜）、消费者（点评）
- 前置：商户信用达标；后置：优质小店上榜、点评回流
- 主成功场景：1 优质小店上榜(免费/信用加权) 2 群众点评 3 信用分→流量正向循环
- 关键扩展：非竞价排名；信用下降→下榜
- 追溯：功能点 E-02｜UC-SYS-M10、C07

### UC-SUB-E-03 发布招工与求职
- 参与者：商户（招工）、从业人员（求职）
- 前置：双方实名；后置：对接达成、互评
- 主成功场景：1 发布岗位/浏览岗位 2 实名履历对接 3 用工评价互评
- 关键扩展：与 I-05 零工结算联动；黑中介治理与 D-02 打通
- 追溯：功能点 E-03｜UC-SYS-M05
