# 子系统用例规约 · B 透明与溯源（L3）

> 层：L3 子系统用例 · 标准字段 · 配套图 `B-透明与溯源.puml`

### UC-SUB-B-01 贯通全链溯源并标注断链
- 参与者：供应商（环节上报）、消费者（查询）、监管人员（监督）
- 前置：溯源数据积累；后置：全链时间轴可见、断链显式标注
- 主成功场景：1 建立「种子到餐桌」全链档案 2 环节缺失显式标注「缺失/断链」 3 与物流 F-02 位置联动
- 关键扩展：农户端 M3 接入（非确认角色）；M1 基础由 T-08/T-09 承担
- 追溯：功能点 B-01｜UC-SYS-C03、S09

### UC-SUB-B-02 公开服务过程
- 参与者：商户（接入）、消费者（查看）
- 前置：商户授权；后置：后厨直播/报价单可见
- 主成功场景：1 商户接入后厨直播/上传报价单 2 消费者查看 3 平台抽查
- 关键扩展：内容合规责任商户承担
- 追溯：功能点 B-02｜UC-SYS-M02、C01

### UC-SUB-B-03 公示抽检结果
- 参与者：监管人员（公示）、消费者（查看）
- 前置：抽检数据积累；后置：抽检统一入口可查
- 主成功场景：1 政府抽检+平台抽检统一公示 2 消费者可查 3 与 A-02 档案联动
- 关键扩展：数据双轨积累（公开数据+商户申报/平台巡检）
- 追溯：功能点 B-03｜UC-SYS-C01、G03
