# 子系统用例规约 · F 物流货运（L3）

> 层：L3 子系统用例 · 标准字段 · 配套图 `F-物流货运.puml`（网约车/出租车不做）

### UC-SUB-F-01 发布货源并自由接单
- 参与者：货主（发布）、货运司机（接单）
- 前置：双方实名、司机资质核验；后置：运单达成留痕
- 主成功场景：1 货主发布(货物/路线/时间/期望运费) 2 司机筛选自由接单 3 全流程留痕
- 关键扩展：不强制派单
- 追溯：功能点 F-01｜UC-SYS-L01

### UC-SUB-F-02 查看在途位置并存证轨迹
- 参与者：货主（查看）、货运司机（轨迹）、监管人员（预警）
- 前置：运单在途；后置：轨迹存证
- 主成功场景：1 司机记录轨迹 2 货主实时查看 3 轨迹自证
- 关键扩展：异常停留/偏航→监管预警；手机 GPS 不做北斗硬件
- 追溯：功能点 F-02｜UC-SYS-L02

### UC-SUB-F-03 核验司机资质并建信用档案
- 参与者：货运司机
- 前置：司机实名；后置：资质核验、信用建档
- 主成功场景：1 核验从业资格证 2 背景审查 3 建信用档案(接单履约率)
- 关键扩展：与 A-07 全域信用联动；双向信用
- 追溯：功能点 F-03｜UC-SYS-L03

### UC-SUB-F-04 托管并结算运费
- 参与者：货主（冻结）、货运司机（收款）
- 前置：运单达成；后置：运费到账留痕
- 主成功场景：1 下单冻结运费(持牌托管) 2 送达确认 3 放款入司机账户
- 关键扩展：货损/迟到→存证仲裁计信用；与 I-03 共用结算体系
- 追溯：功能点 F-04｜UC-SYS-L04

### UC-SUB-F-05 公示货运费率与抽成
- 参与者：货主、货运司机
- 前置：费率口径确定；后置：费率透明
- 主成功场景：1 公示货运抽成与费率 2 查看调整规则
- 关键扩展：与 P-01 同口径页面
- 追溯：功能点 F-05｜UC-SYS-L05
