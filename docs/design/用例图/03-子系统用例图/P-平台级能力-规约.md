# 子系统用例规约 · P 平台级能力（L3）

> 层：L3 子系统用例 · 标准字段（P0 核心补全）· 配套图 `P-平台级能力.puml`

### UC-SUB-P-01 公示平台费率与抽成
- 参与者：平台运营方；次要：商户/供应商/司机
- 前置：费率口径确定；后置：费率公示可查
- 主成功场景：1 公示费率(0.5%~1% 分品类) 2 公示计算方式与调整规则 3 随品类扩展更新
- 关键扩展：调整→提前告知商户
- 追溯：功能点 P-01｜UC-SYS-O01

### UC-SUB-P-02 存证并出证平台证据
- 参与者：平台运营方；次要：监管人员
- 前置：存证能力贯穿；后置：证据可打包调取
- 主成功场景：1 记录时间戳+哈希存证(只增不改) 2 打包出证 3 供仲裁/监管调取
- 关键扩展：记录缺失→提示
- 追溯：功能点 P-02｜UC-SYS-O02、G04

### UC-SUB-P-03 划定试点范围并扩展行业
- 参与者：平台运营方
- 前置：试点方案确定；后置：试点落地可扩展
- 主成功场景：1 划定试点(石家庄/餐饮+零售+家政) 2 按行业映射纳入 3 调研-问卷冻结后扩展
- 关键扩展：未冻结行业→不进入范围
- 追溯：功能点 P-03｜UC-SYS-O03

### UC-SUB-P-04 替代政务对接并双轨切换
- 参与者：平台运营方
- 前置：政务接口不可接；后置：自建通道运行可切换
- 主成功场景：1 自建证照核验/工单/结算 2 先自建录入 3 接口就绪后切换
- 关键扩展：第三方实名不可用→暂停
- 追溯：功能点 P-04｜UC-SYS-O04

### UC-SUB-P-05 承诺平台定位与信任背书
- 参与者：平台运营方
- 前置：定位三角确定；后置：承诺对外交付
- 主成功场景：1 交付信用背书+政府监督+全链溯源+免费推广+投诉直达承诺 2 明确行为边界
- 关键扩展：—
- 追溯：功能点 P-05｜UC-SYS-O05

### UC-SUB-P-06 导入存量商户并冷启动
- 参与者：平台运营方；次要：商户
- 前置：试点范围已定；后置：商户≥200、行业≥3
- 主成功场景：1 低门槛入驻(≤1min) 2 存量数据人工导入 3 政府发文+协会动员
- 关键扩展：数据缺失→人工补录
- 追溯：功能点 P-06｜UC-SYS-O06
