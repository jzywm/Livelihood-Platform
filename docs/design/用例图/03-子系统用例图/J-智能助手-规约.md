# 子系统用例规约 · J 智能助手（L3）

> 层：L3 子系统用例 · 标准字段 · 配套图 `J-智能助手.puml`
> 「民生小助手」为公共服务能力，不单列为参与者；J-01/J-02/J-07/J-08 为通用基础设施（全角色共用）

### UC-SUB-J-01 提供分角色使用指导
- 参与者：通用·全角色共用
- 前置：知识库就绪；后置：分角色 FAQ+步骤引导可用
- 主成功场景：1 分角色知识库(消费者/老板/供应商/从业/监管) 2 步骤式引导 3 侧边栏常驻
- 关键扩展：答案绑定平台流程不编造
- 追溯：功能点 J-01｜UC-SYS-O10

### UC-SUB-J-02 导航到目标页面
- 参与者：通用·全角色共用
- 前置：白名单路由表；后置：意图直达页面
- 主成功场景：1 自然语言→页面直达 2 仅跳白名单路由 3 跳转前二次确认
- 关键扩展：只跳平台内页不对外链
- 追溯：功能点 J-02｜UC-SYS-O10

### UC-SUB-J-03 推荐商品并说明理由
- 参与者：消费者
- 前置：候选在售+信用≥阈值+溯源完整；后置：透明理由推荐
- 主成功场景：1 收敛候选 2 按信用40%+溯源30%+价格20%+好评10%排序 3 模板化输出理由
- 关键扩展：候选不足→如实提示；非竞价不杀熟
- 追溯：功能点 J-03｜UC-SYS-C06

### UC-SUB-J-04 理解多轮对话上下文
- 参与者：平台运营方（模块级治理）
- 前置：会话中；后置：指代理解
- 主成功场景：1 会话内指代理解 2 超时(30 分钟)自动清空
- 关键扩展：不留跨会话记忆
- 追溯：功能点 J-04｜UC-SYS-O10

### UC-SUB-J-05 兜底并转人工反馈
- 参与者：平台运营方（模块级治理）
- 前置：意图无法识别；后置：不卡死
- 主成功场景：1 回退 FAQ 关键词 2 仍不行给人工入口(G-01) 3 用户评价有用性
- 关键扩展：反馈数据不用于训练第三方模型
- 追溯：功能点 J-05｜UC-SYS-O10

### UC-SUB-J-06 管控内容安全与幻觉
- 参与者：平台运营方（模块级治理）
- 前置：输出前；后置：安全合规
- 主成功场景：1 内容安全过滤 2 未成年人额外敏感词 3 事实类绑定平台数据
- 关键扩展：标注「平台助手生成，以页面信息为准」
- 追溯：功能点 J-06｜UC-SYS-O10

### UC-SUB-J-07 构建个人画像中心
- 参与者：通用·全角色共用
- 前置：数据源授权；后置：画像可查可控
- 主成功场景：1 五类数据源接入+授权校验 2 标签计算脱敏加密 3 未成年人画像
- 关键扩展：未授权字段不入画像；未成年人不建行为/购买画像
- 追溯：功能点 J-07｜UC-SYS-O11

### UC-SUB-J-08 管理画像并行使四权
- 参与者：通用·全角色共用
- 前置：画像已构建；后置：四权齐全
- 主成功场景：1 查看(维度/来源/授权) 2 修改完善 3 关闭个性化 4 一键删除(衍生 30 天清理)
- 关键扩展：画像操作审计留痕
- 追溯：功能点 J-08｜UC-SYS-O11

### UC-SUB-J-09 增强个性化推荐
- 参与者：消费者
- 前置：画像授权；后置：叠加画像权重推荐
- 主成功场景：1 在 J-03 排序上叠加画像权重 2 标注画像依据 3 价格不因画像差异化
- 关键扩展：叠加不替代；不杀熟
- 追溯：功能点 J-09｜UC-SYS-C06

### UC-SUB-J-10 推送个性化信息
- 参与者：消费者
- 前置：画像授权；后置：相关推送
- 主成功场景：1 职业类(健康证/培训提醒) 2 年龄类(养老/育儿) 3 行业类(新政/抽检)
- 关键扩展：关闭个性化→停止推送
- 追溯：功能点 J-10｜UC-SYS-C06

### UC-SUB-J-11 提供个性化使用引导
- 参与者：消费者
- 前置：画像；后置：按熟练度引导
- 主成功场景：1 新手步骤引导 2 熟手直达高频 3 异常行为提醒(如欠薪预警)
- 关键扩展：受画像四权约束
- 追溯：功能点 J-11｜UC-SYS-C06

### UC-SUB-J-12 治理助手服务
- 参与者：平台运营方
- 前置：助手运行；后置：可观测可限流
- 主成功场景：1 API 网关限流 2 控量+规则库缓存 3 脱敏日志+指标看板
- 关键扩展：意图命中率/跳转成功率/推荐采纳率
- 追溯：功能点 J-12｜UC-SYS-O07

### UC-SUB-J-13 澄清式导购选品
- 参与者：消费者
- 前置：模糊意图；后置：≤5 个带理由对比
- 主成功场景：1 模板化追问(可跳过) 2 收敛候选 3 输出≤5 个透明对比 4 一键跳选品/详情页
- 关键扩展：复用 J-02 跳转；不臆断用户需求
- 追溯：功能点 J-13｜UC-SYS-C06
