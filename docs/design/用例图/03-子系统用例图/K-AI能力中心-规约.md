# 子系统用例规约 · K AI 能力中心（L3）

> 层：L3 子系统用例 · 标准字段 · 配套图 `K-AI能力中心.puml`

### UC-SUB-K-01 OCR 核验证照
- 参与者：商户、供应商（经营端预审）、监管人员（监管端）
- 前置：证照上传；后置：字段提取、比对留痕
- 主成功场景：1 上传营业执照/许可证/检测报告 2 自动提取字段 3 比对有效期/类目 4 减少人工核验量
- 关键扩展：经 K-02 网关统一接入；核验结果可追溯
- 追溯：功能点 K-01｜UC-SYS-M01、S01

### UC-SUB-K-02 统一 AI 网关与治理
- 参与者：平台运营方
- 前置：多模型接入；后置：调用可控可审计
- 主成功场景：1 统一路由(文本/视觉/OCR/预测) 2 鉴权限流路由审计 3 任务队列+置信度分级
- 关键扩展：视觉云 API 签数据合规协议(不用于训练)
- 追溯：功能点 K-02｜UC-SYS-O08

### UC-SUB-K-03 审核视觉合规图片
- 参与者：监管人员
- 前置：巡检图片上传；后置：审核留痕、结论写档案
- 主成功场景：1 图片脱敏(去人脸/车牌) 2 云视觉分析 3 置信度分级 4 人工复核留痕
- 关键扩展：AI 只标记不决策；高置信→一键核查单
- 追溯：功能点 K-03｜UC-SYS-G03

### UC-SUB-K-04 图像问答答疑
- 参与者：消费者
- 前置：视觉能力就绪；后置：辅助回答
- 主成功场景：1 拍照提问(如包装合规) 2 视觉模型辅助回答 3 提示以页面为准
- 关键扩展：仅辅助、不作执法/鉴定结论
- 追溯：功能点 K-04｜UC-SYS-C10

### UC-SUB-K-05 识别后厨直播异常
- 参与者：商户（授权）、监管人员（人工确认）
- 前置：商户授权；后置：异常标记进复核流
- 主成功场景：1 联动 B-02 画面分析 2 未穿工装/卫生/明火离人标记 3 进复核流人工确认
- 关键扩展：处置人工确认不自动处罚
- 追溯：功能点 K-05｜UC-SYS-O08

### UC-SUB-K-06 预测并预警风险商户
- 参与者：监管人员
- 前置：数据积累；后置：风险被预警
- 主成功场景：1 自建模型预测(欠薪/假货) 2 联动 A-08 预警 3 人工处置
- 关键扩展：平台数据不出域；AI 不决策
- 追溯：功能点 K-06｜UC-SYS-G07
