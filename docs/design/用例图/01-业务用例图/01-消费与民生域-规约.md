## UC-BIZ-01 放心选购商户

| 字段 | 内容 |
|---|---|
| 用例编号 | UC-BIZ-01 |
| 用例名称 | 放心选购商户 |
| 用例概述 | 消费者在消费前查清商户证照、信用、抽检与溯源，选到可信商户 |
| 主要参与者 | 消费者 |
| 次要参与者 | 商户、平台运营方 |
| 涉众与利益 | 消费者：避免踩坑；商户：被看见；平台：信用公信力 |
| 前置条件 | 消费者已实名登录；商户已完成入驻建档 |
| 后置条件 | 消费者获得可信商户/商品信息并可继续下单/消费 |
| 触发条件 | 消费者想「查一查这家店靠不靠谱」 |
| 主成功场景 | 1. 消费者搜索/扫码定位商户；2. 查看一店一档（证照/处罚/抽检/投诉率/信用分）；3. 查看价格公示与溯源信息；4. 获取个性化推荐/图像问答辅助；5. 完成选购决策 |
| 扩展流程 | 2a 商户未建档 → 提示查无档案；4a 无画像数据 → 回退通用推荐 |
| 业务规则 | 核心信息一屏可查；脱敏公示；非竞价推荐；不杀熟 |
| 优先级/里程碑 | P0 / M1 |
| 追溯 | UC-SYS-C01、C03、C06、C09、C10 |

## UC-BIZ-02 透明明白消费

| 字段 | 内容 |
|---|---|
| 用例编号 | UC-BIZ-02 |
| 用例名称 | 透明明白消费 |
| 用例概述 | 消费者消费中/前看清价格、溯源与预付卡风险，明白花钱 |
| 主要参与者 | 消费者 |
| 次要参与者 | 商户、平台运营方 |
| 涉众与利益 | 消费者：不被乱收费/缺斤少两；商户：合规口碑 |
| 前置条件 | 商户已维护价格公示与档案 |
| 后置条件 | 消费者掌握价格/溯源/风险信息 |
| 触发条件 | 消费者下单或办卡前 |
| 主成功场景 | 1. 消费者查看价格公示；2. 扫码查看全链溯源；3. 办卡/充值前接收预付卡风险提示；4. 明白消费 |
| 扩展流程 | 2a 溯源断链 → 显式标注「缺失/断链」 |
| 业务规则 | 价格商户自主维护并留痕；预付卡提示不替代资金托管 |
| 优先级/里程碑 | P0 / M1（预付卡提示 M2） |
| 追溯 | UC-SYS-C01、C03、C08 |

## UC-BIZ-03 投诉维权追进度

| 字段 | 内容 |
|---|---|
| 用例编号 | UC-BIZ-03 |
| 用例名称 | 投诉维权追进度 |
| 用例概述 | 消费者被坑后低成本提交投诉并全程看到处理进度与结果 |
| 主要参与者 | 消费者 |
| 次要参与者 | 商户、监管人员、平台运营方 |
| 涉众与利益 | 消费者：诉求有回音；商户：申诉防单方定性；监管：工单数据 |
| 前置条件 | 存在可投诉的商户/交易 |
| 后置条件 | 投诉办结或升级市监，结果脱敏公示并计入信用 |
| 触发条件 | 消费者消费遇坑（缺斤少两/乱收费/效果不符等） |
| 主成功场景 | 1. 消费者≤3 步提交投诉（选商户→选类别→附证据）；2. 平台分诊；3. 商家 48h 处理；4. 消费者查看进度；5. 结果脱敏公示并计入信用分 |
| 扩展流程 | 3a 商家未解决 → 升级市监办结（延伸至 UC-SYS-G05） |
| 业务规则 | 投诉路径留痕可出证；进度四态可见 |
| 优先级/里程碑 | P0 / M1 |
| 追溯 | UC-SYS-C02 |

## UC-BIZ-04 反映民生诉求

| 字段 | 内容 |
|---|---|
| 用例编号 | UC-BIZ-04 |
| 用例名称 | 反映民生诉求 |
| 用例概述 | 消费者向政府部门提交诉求工单并获得限时办结反馈 |
| 主要参与者 | 消费者 |
| 次要参与者 | 政府、监管人员 |
| 涉众与利益 | 消费者：诉求有回应；政府：响应可考核 |
| 前置条件 | 消费者已实名 |
| 后置条件 | 诉求生成工单、限时办结并公示 |
| 触发条件 | 消费者有民生诉求（选部门/类别、附证据） |
| 主成功场景 | 1. 提交诉求；2. 智能派单；3. 部门限时办结（如 7 天）；4. 进度可见；5. 结果脱敏公示 |
| 扩展流程 | 3a 超时未办 → 预警催办 |
| 业务规则 | 工单体系自建+线下流转（12345 不可接） |
| 优先级/里程碑 | P0 / M1（基础版） |
| 追溯 | UC-SYS-C04 |

## UC-BIZ-05 建言献策

| 字段 | 内容 |
|---|---|
| 用例编号 | UC-BIZ-05 |
| 用例名称 | 建言献策 |
| 用例概述 | 消费者实名或匿名提交建议并获限时答复与采纳公示 |
| 主要参与者 | 消费者 |
| 次要参与者 | 政府 |
| 涉众与利益 | 消费者：建议被采纳；政府：民声线索 |
| 前置条件 | 消费者登录 |
| 后置条件 | 建议被审核、分派、限时答复并公示 |
| 触发条件 | 消费者有建议 |
| 主成功场景 | 1. 按分类发帖（实名/匿名可选）；2. 平台审核；3. 分派部门；4. 限时答复（采纳/部分采纳/不采纳+理由）；5. 采纳公示 |
| 扩展流程 | 2a 内容违规 → 敏感词拦截+人工复核 |
| 业务规则 | 优秀建议可获积分/荣誉 |
| 优先级/里程碑 | P1 / M2 |
| 追溯 | UC-SYS-C04 |

| 扩展流程 | 3a 意见超时未回 → 催办提示 |
| 业务规则 | 进度以图文/视频/数据同步 |
| 优先级/里程碑 | P2 / M3 |
| 追溯 | UC-SYS-C05 |
