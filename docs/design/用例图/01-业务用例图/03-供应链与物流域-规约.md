## UC-BIZ-16 放心供货

| 字段 | 内容 |
|---|---|
| 用例编号 | UC-BIZ-16 |
| 用例名称 | 放心供货 |
| 用例概述 | 供应商资质核验入驻、上架关联溯源、凭信用放心供货 |
| 主要参与者 | 供应商 |
| 次要参与者 | 平台运营方 |
| 涉众与利益 | 供应商：好货被看见；采购方：货真价实 |
| 前置条件 | 供应商持品类资质 |
| 后置条件 | 商品上架、溯源可查、信用分生成 |
| 触发条件 | 供应商入驻/上架 |
| 主成功场景 | 1. 实名+按品类核验资质；2. 上架商品并关联批号/检测报告；3. 生成溯源批次码；4. 评定信用分/放心标识 |
| 扩展流程 | 2a 资质临期 → 强制下架；4a 扣分 → 申诉复核 |
| 业务规则 | 只信息核验留痕、不替代行政许可 |
| 优先级/里程碑 | P0（基础）/M2（完整） |
| 追溯 | UC-SYS-S01、S02、S10 |

## UC-BIZ-17 放心采购

| 字段 | 内容 |
|---|---|
| 用例编号 | UC-BIZ-17 |
| 用例名称 | 放心采购 |
| 用例概述 | 采购方在选品广场比价、决策、担保下单、到货验收 |
| 主要参与者 | 采购方 |
| 次要参与者 | 供应商、平台运营方、商户 |
| 涉众与利益 | 采购方：不选错不被坑；供应商：货款有保障 |
| 前置条件 | 采购方实名；供应商在售 |
| 后置条件 | 货款按验收分账，交易留痕 |
| 触发条件 | 采购方有采购需求 |
| 主成功场景 | 1. 浏览选品广场；2. 查看详情/供应商主页；3. 决策辅助收敛候选；4. 担保下单（货款托管）；5. 到货验收 48h；6. 放款/分账 |
| 扩展流程 | 5a 货不对板 → 拒收退款；5b 验收分歧 → 争议仲裁 |
| 业务规则 | 货款第三方持牌托管、平台不二清；48h 验收 |
| 优先级/里程碑 | P1 / M2 |
| 追溯 | UC-SYS-S03、S04、S05、S06、S11、M08 |

## UC-BIZ-18 假货维权

| 字段 | 内容 |
|---|---|
| 用例编号 | UC-BIZ-18 |
| 用例名称 | 假货维权 |
| 用例概述 | 采购方买到假货一键投诉并闭环处理 |
| 主要参与者 | 采购方 |
| 次要参与者 | 供应商、监管人员、平台运营方 |
| 涉众与利益 | 采购方：维权有门；供应商：防误伤 |
| 前置条件 | 存在订单/溯源码 |
| 后置条件 | 投诉闭环、结果计入供应商信用与批次 |
| 触发条件 | 采购方发现假货/假材料 |
| 主成功场景 | 1. 扫码页/订单页一键投诉（关联溯源码）；2. 分诊；3. 供应商 48h 处理；4. 未解决升级市监；5. 结果公示并计信用 |
| 扩展流程 | 3a 同溯源码多次投诉 → 自动预警 |
| 业务规则 | 复用投诉直达机制，不另起炉灶 |
| 优先级/里程碑 | P1 / M2 |
| 追溯 | UC-SYS-S08 |

## UC-BIZ-19 餐厨合规处置

| 字段 | 内容 |
|---|---|
| 用例编号 | UC-BIZ-19 |
| 用例名称 | 餐厨合规处置 |
| 用例概述 | 产废单位登记餐厨去向、收运企业扫码交接，全链防地沟油回流 |
| 主要参与者 | 产废单位 |
| 次要参与者 | 收运企业、监管人员 |
| 涉众与利益 | 产废单位：合规登记；收运企业：交接留痕；监管：去向可查 |
| 前置条件 | 产废单位/收运企业实名 |
| 后置条件 | 餐厨去向登记闭环、收运信用建档 |
| 触发条件 | 产废单位产废登记 |
| 主成功场景 | 1. 产废单位登记并选白名单收运企业；2. 收运上门双方扫码确认交接；3. 处理厂接收确认；4. 全链留痕可查 |
| 扩展流程 | 2a 超期未收运/去向不明 → 预警联动市监 |
| 业务规则 | 收运企业须平台白名单；收运信用档案延伸信用体系 |
| 优先级/里程碑 | P2 / M3 |
| 追溯 | UC-SYS-M09、M11 |

## UC-BIZ-20 放心运货

| 字段 | 内容 |
|---|---|
| 用例编号 | UC-BIZ-20 |
| 用例名称 | 放心运货 |
| 用例概述 | 货主发布货源、司机自由接单、在途位置可查、轨迹自证 |
| 主要参与者 | 货主 |
| 次要参与者 | 货运司机、监管人员 |
| 涉众与利益 | 货主：掌握在途动态；司机：自由接单 |
| 前置条件 | 双方实名；司机资质核验 |
| 后置条件 | 运单完成、轨迹存证 |
| 触发条件 | 货主发布货运需求 |
| 主成功场景 | 1. 货主发布货源（货物/路线/时间/期望运费）；2. 司机自由接单；3. 在途位置实时可见+轨迹存证 |
| 扩展流程 | 3a 异常停留/偏航 → 监管预警 |
| 业务规则 | 不强制派单；手机 GPS、不做北斗硬件 |
| 优先级/里程碑 | P1 / M2 |
| 追溯 | UC-SYS-L01、L02、L03 |

## UC-BIZ-21 运费保障结算

| 字段 | 内容 |
|---|---|
| 用例编号 | UC-BIZ-21 |
| 用例名称 | 运费保障结算 |
| 用例概述 | 运费第三方托管、送达后放款、费率公开 |
| 主要参与者 | 货主 |
| 次要参与者 | 货运司机、平台运营方 |
| 涉众与利益 | 货主：货损可追责；司机：运费不被拖 |
| 前置条件 | 运单已达成 |
| 后置条件 | 运费放款入司机账户、费率透明 |
| 触发条件 | 下单/结算 |
| 主成功场景 | 1. 下单冻结运费（持牌托管）；2. 送达确认；3. 放款入司机账户；4. 查看费率公开 |
| 扩展流程 | 2a 货损/迟到 → 存证仲裁并计双方信用 |
| 业务规则 | 平台不沉淀资金；费率 0.5%~1% 公开 |
| 优先级/里程碑 | P1 / M2 |
| 追溯 | UC-SYS-L04、L05 |
