## UC-BIZ-09 合规入驻经营

| 字段 | 内容 |
|---|---|
| 用例编号 | UC-BIZ-09 |
| 用例名称 | 合规入驻经营 |
| 用例概述 | 商户低门槛入驻、证照核验建档并持续维护合规经营 |
| 主要参与者 | 商户 |
| 次要参与者 | 平台运营方 |
| 涉众与利益 | 商户：获客与合规减负；消费者：查得到资质 |
| 前置条件 | 商户持有营业执照/许可证 |
| 后置条件 | 商户建档成功、档案可查可维护 |
| 触发条件 | 商户申请入驻 |
| 主成功场景 | 1. 注册+实名；2. 上传证照（≤1 分钟扫码/拍照）；3. OCR 预审+人工核验；4. 建档；5. 后续维护档案与公示 |
| 扩展流程 | 3a 证照临期 → 双向提醒；4a 核验不通过 → 驳回并说明 |
| 业务规则 | 实名仅微信/支付宝回传；强监管品类不替代行政许可 |
| 优先级/里程碑 | P0 / M1 |
| 追溯 | UC-SYS-M01、M02 |

## UC-BIZ-10 透明公示响应维权

| 字段 | 内容 |
|---|---|
| 用例编号 | UC-BIZ-10 |
| 用例名称 | 透明公示响应维权 |
| 用例概述 | 商户公示价格/服务过程并响应投诉、申诉恶意差评 |
| 主要参与者 | 商户 |
| 次要参与者 | 消费者、平台运营方、监管人员 |
| 涉众与利益 | 商户：不被讹、透明获信；消费者：过程可见 |
| 前置条件 | 商户已入驻建档 |
| 后置条件 | 价格/服务公示到位、投诉/申诉闭环 |
| 触发条件 | 商户维护公示或收到投诉/差评 |
| 主成功场景 | 1. 维护价格公示；2. 接入服务过程透明（后厨直播/报价单）；3. 收到投诉限时处理；4. 对恶意差评发起申诉 |
| 扩展流程 | 3a 投诉升级市监 → 配合办结；4a 申诉识别职业索赔 → 人工确认后处置 |
| 业务规则 | 内容合规责任商户承担；AI 识别仅辅助 |
| 优先级/里程碑 | P0（价格）/M2（过程透明） |
| 追溯 | UC-SYS-M02、M04 |

## UC-BIZ-11 诚信获客

| 字段 | 内容 |
|---|---|
| 用例编号 | UC-BIZ-11 |
| 用例名称 | 诚信获客 |
| 用例概述 | 优质小店凭信用免费获推广与群众点评，形成信用换流量 |
| 主要参与者 | 商户 |
| 次要参与者 | 消费者（群众点评）、平台运营方 |
| 涉众与利益 | 商户：免费获客；消费者：可信参考 |
| 前置条件 | 商户信用分达标 |
| 后置条件 | 优质小店上榜，群众点评回流信用 |
| 触发条件 | 商户希望获客/参与推广 |
| 主成功场景 | 1. 参与行业圈层交流；2. 优质小店上榜（免费、信用加权）；3. 群众点评；4. 信用分→流量正向循环 |
| 扩展流程 | 2a 信用分下降 → 下榜 |
| 业务规则 | 免费、非竞价排名 |
| 优先级/里程碑 | P2 / M3 |
| 追溯 | UC-SYS-M10、C07 |

## UC-BIZ-12 合规用工招工

| 字段 | 内容 |
|---|---|
| 用例编号 | UC-BIZ-12 |
| 用例名称 | 合规用工招工 |
| 用例概述 | 商户发布招工、核验年龄防童工、互评劳务信用 |
| 主要参与者 | 商户 |
| 次要参与者 | 从业人员、平台运营方 |
| 涉众与利益 | 商户：招人不靠赌；从业人员：绕开黑中介 |
| 前置条件 | 商户实名入驻 |
| 后置条件 | 招工/求职对接，用工双方信用可查 |
| 触发条件 | 商户发布岗位 |
| 主成功场景 | 1. 发布招工；2. 求职者应聘；3. 入职年龄核验（<16 拦截）；4. 双方互评劳务信用 |
| 扩展流程 | 3a 年龄<16 → 拦截警示并留痕 |
| 业务规则 | 实名+履历授权可见；黑中介治理与投诉打通 |
| 优先级/里程碑 | P0（防童工）/M2（招工） |
| 追溯 | UC-SYS-M05、M07 |

## UC-BIZ-13 证明自我能力

| 字段 | 内容 |
|---|---|
| 用例编号 | UC-BIZ-13 |
| 用例名称 | 证明自我能力 |
| 用例概述 | 从业人员建立实名档案、核验履历/证书并累积信用 |
| 主要参与者 | 从业人员 |
| 次要参与者 | 商户、平台运营方 |
| 涉众与利益 | 从业人员：履历被证明；商户：招到靠谱的人 |
| 前置条件 | 从业人员实名 |
| 后置条件 | 一人一档建立，履历由雇佣关系自动累积 |
| 触发条件 | 从业人员求职/入职 |
| 主成功场景 | 1. 实名认证；2. 上传健康证/技能证核验；3. 建档；4. 入职扫码记录雇佣关系；5. 履历自动累积、信用分生成 |
| 扩展流程 | 2a 证书核验失败 → 提示补充 |
| 业务规则 | 履历仅本人/授权雇主可见（分级授权） |
| 优先级/里程碑 | P0 / M1 |
| 追溯 | UC-SYS-M03 |

## UC-BIZ-14 获得劳动报酬

| 字段 | 内容 |
|---|---|
| 用例编号 | UC-BIZ-14 |
| 用例名称 | 获得劳动报酬 |
| 用例概述 | 从业人员工资代付留痕、欠薪预警、零工灵活结算 |
| 主要参与者 | 从业人员 |
| 次要参与者 | 商户、平台运营方 |
| 涉众与利益 | 从业人员：工资不拖欠；商户：结算留痕 |
| 前置条件 | 存在有效用工关系 |
| 后置条件 | 工资/零工费到账并留痕 |
| 触发条件 | 结算周期到/商户发起 |
| 主成功场景 | 1. 商户发起代付；2. 持牌机构代付；3. 收款确认；4. 流水留痕更新履约率 |
| 扩展流程 | 1a 应发未发超时 → 欠薪预警；4a 纠纷 → 一键出证 |
| 业务规则 | 平台不碰钱、不沉淀资金；日/周/月结可选 |
| 优先级/里程碑 | P0 / M1（零工 M2） |
| 追溯 | UC-SYS-M06 |

## UC-BIZ-15 找好工作

|---|---|

| 用例名称 | 找好工作 |
| 用例概述 | 从业人员通过实名履历对接真雇主真岗位 |
| 主要参与者 | 从业人员 |
| 次要参与者 | 商户 |
| 涉众与利益 | 从业人员：绕开黑中介；商户：真工人 |
| 前置条件 | 从业人员已建一人一档 |
| 后置条件 | 求职对接成功，可查雇主信用 |
| 触发条件 | 从业人员找活 |
| 主成功场景 | 1. 浏览岗位；2. 查看雇主用工信用；3. 应聘；4. 达成对接 |
| 扩展流程 | 2a 雇主失信 → 限制发布岗位 |
| 业务规则 | 双向信用：失信老板限发岗、失信工人限接单 |
| 优先级/里程碑 | P1 / M2 |
| 追溯 | UC-SYS-M05 |
