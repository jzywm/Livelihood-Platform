## UC-BIZ-22 智慧监管商户

| 字段 | 内容 |
|---|---|
| 用例编号 | UC-BIZ-22 |
| 用例名称 | 智慧监管商户 |
| 用例概述 | 监管人员查辖区档案、收异常预警并按信用分级监管 |
| 主要参与者 | 监管人员 |
| 次要参与者 | 商户、平台运营方 |
| 涉众与利益 | 监管：用数据换人力；商户：分级少扰 |
| 前置条件 | 商户已建档、异常可标记 |
| 后置条件 | 预警推送到位、分级监管执行 |
| 触发条件 | 日常巡查/接收预警 |
| 主成功场景 | 1. 查辖区全量档案；2. 接收高频投诉/资质临期/异常经营预警；3. 按信用分级（低分多查、高分少查）；4. 标记异常挂档案 |
| 扩展流程 | 2a 异常触发 → 双向推送商户+监管 |
| 业务规则 | 预警只推线索、不自动执法 |
| 优先级/里程碑 | P0（基础）/M2（完整看板） |
| 追溯 | UC-SYS-G01、G02 |

## UC-BIZ-23 透明执法公示

| 字段 | 内容 |
|---|---|
| 用例编号 | UC-BIZ-23 |
| 用例名称 | 透明执法公示 |
| 用例概述 | 监管公示抽检结果、审核视觉合规、存证出证支撑执法 |
| 主要参与者 | 监管人员 |
| 次要参与者 | 平台运营方、消费者 |
| 涉众与利益 | 监管：取证易出证；群众：抽检可查 |
| 前置条件 | 抽检/巡检数据积累 |
| 后置条件 | 抽检公示、视觉审核留痕、证据可调取 |
| 触发条件 | 抽检完成/巡检上传 |
| 主成功场景 | 1. 公示抽检结果；2. 巡检图片脱敏+视觉分析；3. 置信度分级+人工复核；4. 存证出证供执法 |
| 扩展流程 | 2a 高置信疑似 → 一键核查单 |
| 业务规则 | AI 只标记不决策；存证时间戳+哈希 |
| 优先级/里程碑 | P1 / M2 |
| 追溯 | UC-SYS-G03、G04 |

## UC-BIZ-25 建立平台信任

| 字段 | 内容 |
|---|---|
| 用例编号 | UC-BIZ-25 |
| 用例名称 | 建立平台信任 |
| 用例概述 | 平台公开费率、存证出证、承诺定位与信任背书 |
| 主要参与者 | 平台运营方 |
| 次要参与者 | 商户、消费者、监管人员 |
| 涉众与利益 | 各端：费率透明、证据可信、政府背书 |
| 前置条件 | 平台能力就绪 |
| 后置条件 | 费率公示、存证出证、定位承诺对外交付 |
| 触发条件 | 平台对外承诺 |
| 主成功场景 | 1. 公示费率（0.5%~1% 分品类）；2. 关键记录时间戳+哈希存证；3. 按需打包出证；4. 交付信用背书+政府监督+全链溯源承诺 |
| 扩展流程 | 1a 费率调整 → 提前告知商户 |
| 业务规则 | 不做竞价广告收费；不二清；AI 不代执法 |
| 优先级/里程碑 | P0 / M1 |
| 追溯 | UC-SYS-O01、O02、O05 |

## UC-BIZ-26 稳步扩展试点

| 字段 | 内容 |
|---|---|
| 用例编号 | UC-BIZ-26 |
| 用例名称 | 稳步扩展试点 |
| 用例概述 | 平台划定试点、导入存量商户冷启动、政务双轨切换扩展行业 |
| 主要参与者 | 平台运营方 |
| 次要参与者 | 商户、政府 |
| 涉众与利益 | 平台：冷启动达标；商户：低门槛入驻 |
| 前置条件 | 试点范围已定 |
| 后置条件 | 试点商户≥200、行业≥3、双轨切换 |
| 触发条件 | 平台运营启动 |
| 主成功场景 | 1. 划定试点（石家庄/餐饮+零售+家政）；2. 存量商户数据导入；3. 自建通道+双轨切换；4. 按 SOP 扩展行业 |
| 扩展流程 | 3a 政务接口就绪 → 切换 |
| 业务规则 | 未冻结行业不进入正式范围 |
| 优先级/里程碑 | P0 / M0 起 |
| 追溯 | UC-SYS-O03、O04、O06 |

## UC-BIZ-27 治理 AI 服务

| 字段 | 内容 |
|---|---|
| 用例编号 | UC-BIZ-27 |
| 用例名称 | 治理 AI 服务 |
| 用例概述 | 平台统一 AI 网关、运营信用与交易风控、治理助手服务 |
| 主要参与者 | 平台运营方 |
| 次要参与者 | 监管人员 |
| 涉众与利益 | 平台：成本可控可审计；监管：AI 可观测 |
| 前置条件 | AI 网关就绪 |
| 后置条件 | AI 调用统一路由/限流/审计，信用风控运转 |
| 触发条件 | AI 能力运营 |
| 主成功场景 | 1. 统一模型路由+鉴权限流审计；2. 运营信用分（防刷单）；3. 交易履约异常处置防刷单；4. 助手治理与可观测 |
| 扩展流程 | 2a 异常交易（同 IP/设备高频）→ 自动拦截留证 |
| 业务规则 | 视觉云 API 不用于训练；复核不回流第三方 |
| 优先级/里程碑 | P0（网关）/M2（风控） |
| 追溯 | UC-SYS-O07、O08 |
