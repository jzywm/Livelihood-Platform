# 民生甄选 · 用例图 · Mermaid 版

> 本目录为 `docs/design/用例图/` 下全部 **25 张 PlantUML（`.puml`）用例图** 的 Mermaid 等价转换，共 4 + 6 + 15 = 25 张。
> 语义、参与者、用例编号、`<<include>>` / `<<extend>>` 关系与注释均与原图 **1:1 保持一致**，仅将图形语法由 PlantUML 改为 Mermaid。

## 转换约定（PlantUML → Mermaid）

| PlantUML | Mermaid |
|---|---|
| `actor "消费者" as CONSUMER` | 绿色矩形节点 `CONSUMER["消费者"]:::actor` |
| `usecase "…" as B01` | 椭圆（体育场形）节点 `B01(["…"]):::uc` |
| `rectangle "边界名" { … }` | `subgraph … end`（浅蓝背景 + 蓝边） |
| `A --> B`（关联） | `A --> B` |
| `A ..> B : <<include>>` | `A -.->\|<<include>>\| B` |
| `A ..> B : <<extend>>` | `A -.->\|<<extend>>\| B` |
| `note … of X`（注释） | 黄色虚线框节点 `NOTE["…"]:::note` + `NOTE -.- X` |
| `left to right direction` | `flowchart LR` |
| `skinparam` 配色 | `classDef` + `style`（颜色与原图一致） |

> 说明：Mermaid 无原生「用例图」类型，故采用 `flowchart` 近似表达——参与者用矩形、用例用体育场形（`([…])`）、系统边界用 `subgraph`、include/extend 用带标签虚线箭头。所有参与者、用例、关系与注释均完整保留。

## 使用方式

每个 `.md` 文件内含一个 ` ```mermaid ` 代码块，可直接在以下环境预览渲染：

- GitHub / GitLab / 语雀 / Notion 等支持 Mermaid 的 Markdown 渲染器
- VS Code（安装 Markdown Preview Mermaid Support 插件）
- [Mermaid Live Editor](https://mermaid.live/)（将代码块内容粘贴即可）
