# 核心时序图（独立交付物）

> 归属：`docs/design/产品设计说明书` §5 核心流程的**时序图配套**，独立于文档正文交付。
> 图均用 Mermaid `sequenceDiagram`；参与者为 §2.4 已定稿的 13 模块（ACC/SETTLE/CRED/EMP/TICKET/TRACE/PROD/TRADE/DASH/CIVIC/PROFILE/ASSIST/AICORE）＋ 外部通道/前端。
> 覆盖：M1 全量核心流程 + M2 关键流程（交易/AI 视觉审核）。

---

## 1. 实名认证（I1，硬依赖第三方实名）

```mermaid
sequenceDiagram
    participant U as 用户(前端)
    participant ACC as 账户服务ACC
    participant WX as 微信/支付宝实名
    U->>ACC: POST /acc/register (mobile, idName, idCard)
    ACC->>ACC: 参数校验 + 生成实名申请
    ACC->>WX: 实名回传请求(唯一通道)
    WX-->>ACC: 实名结果回调 callback(验签)
    ACC->>ACC: 验签 + 落实名状态 + 建账户
    ACC-->>U: accountId + realNameStatus
    Note over ACC: 第三方不可用→注册/入职流程暂停(R-02)
```

## 2. 工资保障代付（I3，第三方通道代付留痕）

```mermaid
sequenceDiagram
    participant B as 老板(经营端)
    participant SETTLE as 结算服务SETTLE
    participant ACC as 账户服务ACC
    participant PAY as 第三方支付通道
    participant W as 员工
    B->>SETTLE: POST /settle/payroll/disburse (employmentId, amount, idempotencyKey)
    SETTLE->>ACC: 校验用工关系 + 账户
    ACC-->>SETTLE: 校验通过
    SETTLE->>PAY: 代付(商家转账到零钱)
    PAY-->>SETTLE: 回调(验签 + 幂等)
    SETTLE->>SETTLE: 流水入账 + 时间戳哈希存证
    SETTLE-->>W: 到账提醒(通知)
    SETTLE-->>B: payrollId + status
    Note over SETTLE: 应发未发→每日JOB欠薪预警→一键证据出证
```

## 3. 投诉直达 + 进度可见（D2，复用 G1 工单内核）

```mermaid
sequenceDiagram
    participant C as 消费者
    participant TICKET as 工单服务TICKET
    participant M as 商家(经营端)
    participant DASH as 监管端DASH
    C->>TICKET: POST /ticket/complaint (merchantId, category, evidence) 不超过3步
    TICKET->>TICKET: 分诊 + 生成工单 + 48h时限
    TICKET-->>M: 投诉通知
    M->>TICKET: POST /ticket/{id}/handle (回复/证据)
    alt 商家限时解决
        TICKET->>TICKET: 结果公示(脱敏) + 计入商户信用
    else 超时/未解决
        TICKET->>DASH: 升级市监 + 预警
        DASH-->>TICKET: 办结结果
    end
    TICKET-->>C: 全程进度可见 + 结果公示
    Note over TICKET: 举报类别含「未成年人违规进入」→供A4聚合预警
```

## 4. 供应商入驻与溯源（T2/T3，含 K2 证照 OCR）

```mermaid
sequenceDiagram
    participant S as 供应商(经营端)
    participant TRACE as 溯源服务TRACE
    participant AICORE as AI中心AICORE(OCR)
    participant C as 消费者/采购方扫码
    S->>TRACE: POST /trace/supplier (license, category, permits)
    TRACE->>AICORE: 证照OCR预审(K2)
    AICORE-->>TRACE: 字段提取 + 有效期/类目比对
    TRACE->>TRACE: 资质核验 + 供应商建档
    S->>TRACE: POST /trace/batch (batchNo) 生成溯源码
    S->>TRACE: POST /trace/batch/{code}/event 环节上报(①批号②检测③温控④终端)
    C->>TRACE: GET /trace/scan/{code}
    TRACE-->>C: 全链时间轴 + 缺环显式标注
    Note over TRACE: 环节记录时间戳+哈希存证(P-02)
```

## 5. 智能助手对话（J，脱敏 → 意图 → 动作）

```mermaid
sequenceDiagram
    participant U as 用户(三端)
    participant ASSIST as 助手服务ASSIST(Python)
    participant CRED as 信用/档案CRED
    participant LLM as 大模型(DeepSeek)
    U->>ASSIST: POST /assist/chat (message)
    ASSIST->>ASSIST: 脱敏前置 + 意图分类
    alt FAQ/白名单跳转/规则推荐
        ASSIST->>CRED: 取数(档案/信用/溯源)
        CRED-->>ASSIST: data
    else 需要生成
        ASSIST->>LLM: 脱敏后调用(数据不出域)
        LLM-->>ASSIST: reply
    end
    ASSIST->>ASSIST: 内容安全过滤 + 标注「以页面为准」
    ASSIST-->>U: reply + intent + citations
    Note over ASSIST: 平台硬护栏在LangChain编排外强制,不开放自由工具调用
```

## 6. 画像构建与个性化推荐（J7，四权 + 不杀熟）

```mermaid
sequenceDiagram
    participant U as 用户
    participant PROFILE as 画像服务PROFILE(Java)
    participant ACC as 账户ACC
    participant ASSIST as 助手ASSIST
    U->>PROFILE: PUT /profile/me (授权/主动完善)
    PROFILE->>ACC: 取实名/履历(授权校验,可撤回)
    ACC-->>PROFILE: data
    PROFILE->>PROFILE: 标签计算(脱敏) + 加密存储 + 操作审计
    ASSIST->>PROFILE: POST /profile/recommend (accountId, context)
    PROFILE-->>ASSIST: candidates + 画像依据
    ASSIST-->>U: 个性化推荐(标注画像依据,价格与画像无关)
    Note over PROFILE: 四权：查看、修改、关闭个性化、删除；未成年人不建行为画像（C7）
```

## 7. AI 视觉合规审核（K1，M2，AI 只标记不决策）

```mermaid
sequenceDiagram
    participant G as 监管端
    participant AICORE as AI中心AICORE(Python)
    participant VISION as 云视觉API
    participant CRED as 信用档案CRED
    G->>AICORE: POST /aicore/vision/review (image, bizType)
    AICORE->>AICORE: 图像脱敏(去无关人脸/车牌)
    AICORE->>VISION: 视觉分析
    VISION-->>AICORE: 疑似标记 + 置信度
    AICORE->>AICORE: 置信度分级：高0.9及以上、中0.7至0.9、低0.7以下
    AICORE-->>G: markers + confidence(进入人工复核队列)
    G->>AICORE: 人工复核结论(留痕)
    AICORE->>CRED: 结论写入档案/信用分
    Note over AICORE: AI只输出疑似标记不决策，复核结果不回流第三方模型（C8）
```

## 8. B2B 选品采购撮合（T4，M2，担保托管分账）

```mermaid
sequenceDiagram
    participant P as 采购方
    participant TRADE as 交易服务TRADE
    participant PAY as 第三方持牌通道
    participant S as 供应商
    participant SETTLE as 结算服务SETTLE
    P->>TRADE: POST /trade/order (itemId, qty, idempotencyKey)
    TRADE->>PAY: 货款托管(平台不沉淀)
    PAY-->>TRADE: 托管成功
    S->>TRADE: 发货
    P->>TRADE: POST /trade/order/{id}/accept (验收,48h)
    TRADE->>SETTLE: 触发分账(货款→卖方 / 服务费→平台)
    SETTLE->>PAY: 分账放款
    PAY-->>SETTLE: 分账结果
    SETTLE-->>TRADE: 分账完成
    TRADE-->>P: 订单完成 + 互评入口
    Note over TRADE: 超时未验收自动确认，拒收转退款，争议存证仲裁
```
