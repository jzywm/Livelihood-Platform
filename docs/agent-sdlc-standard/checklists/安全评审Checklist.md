# 安全评审 Checklist

> 用于:高风险变更(见 `docs/03` 第 3 节)评审、重大版本发布前复核、季度安全巡检。
> 对齐:OWASP Top 10 (2021)、OWASP ASVS L2、本仓库 `docs/02-安全基线.md`。

## A. 认证与身份

- [ ] 认证走统一身份方案(SSO/OIDC),无自研密码逻辑
- [ ] JWT/OAuth:算法白名单校验、`iss`/`aud` 校验、密钥经 KMS、过期与刷新策略合理
- [ ] 会话 Cookie:HttpOnly + Secure + SameSite;会话超时与回收
- [ ] 登录限速、失败锁定、MFA(管理功能强制)
- [ ] 密码存储:bcrypt/argon2,禁止明文/弱哈希

## B. 授权与越权

- [ ] 服务端强制鉴权,不依赖前端隐藏
- [ ] 资源级授权(IDOR):对象归属校验,跨用户访问返回 403
- [ ] 水平/垂直越权测试用例存在且通过
- [ ] 管理接口独立鉴权,不与其他角色共用

## C. 注入与输入输出

- [ ] SQL:参数化/预编译,无字符串拼接
- [ ] 命令执行:参数数组,无 shell 拼接;危险函数(exec/eval)已审计
- [ ] XSS:输出按上下文编码;CSP 已配置;富文本白名单清洗
- [ ] SSRF:出站请求目标校验,内网/元数据地址(169.254.169.254)被阻断
- [ ] 反序列化、文件上传、路径穿越已按基线处理

## D. 数据与加密

- [ ] 传输 TLS ≥ 1.2;敏感数据静态加密
- [ ] PII 脱敏:日志、链路追踪、导出文件不含完整敏感字段
- [ ] 密钥/凭证:零硬编码、经密钥系统注入、轮换策略明确
- [ ] 加密算法:使用标准库/成熟库,无自研密码学

## E. 供应链与依赖

- [ ] SCA 扫描通过;新增依赖来源可信、维护活跃、有替代评估
- [ ] 已知漏洞按 SLA 处理(CRITICAL ≤ 24h,HIGH ≤ 7 天)
- [ ] 依赖锁定文件已提交;major 升级经人工评审
- [ ] 容器:非 root、无特权、只读根(如可行)、镜像扫描零高危

## F. 配置与运维

- [ ] 无默认凭证/默认管理员;环境隔离(dev/staging/prod)
- [ ] 管理端口不公网可达;最小开放端口
- [ ] 响应头基线已配置(HSTS/CSP/X-Content-Type-Options/X-Frame-Options)
- [ ] 日志审计:关键事件留痕,无敏感数据入库
- [ ] 错误处理不泄露堆栈/内部路径

## G. 可用性与拒绝服务

- [ ] 公开接口限流、超时、并发上限
- [ ] 重资源操作有配额/队列;无未设上限的循环/递归
- [ ] 失败安全:异常时拒绝而非放宽

## H. 威胁建模与结论

- [ ] 威胁建模(docs/04)已完成,H×H/H×M 威胁均有缓解与验证
- [ ] 安全需求追踪矩阵中所有项已验证
- [ ] 剩余风险已记录并接受(签字)
