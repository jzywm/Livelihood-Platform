## 1. 输入：需求定位与调研关注点（对比的锚点）

### 1.1 一句话定位（规格书 §2.1，用户已确认）

> 政府牵头、信用驱动、群众参与的**城市民生综合服务平台**：跨行业全产业链的选品交易（农资/食材/医美材料等）在平台透明进行，用胖东来的透明理念贯穿全产业。

三位一体（规格书 §2.2 / 市场报告 §1.1）：

| 支柱 | 内容 | 对应模块 |
|---|---|---|
| 治理监督 | 一店一档、一人一档、信用分、投诉直达、预付卡监管 | A / C / D |
| 透明交易 | 全产业链选品采购、一物一码溯源、担保交易撮合、物流货运 | T / B / F |
| 民生服务 | 群众热线、建议论坛、民生建设监督、优质小店免费推广 | G / H / E |
| 支撑底座 | 实名账户与结算（第三方持牌通道、平台不沉淀资金）、智能助手、AI 能力中心 | I / J / K |

核心理念五词（设计原则）：**惠民 · 方便 · 安全 · 透明 · 直达**；主口号「从种子到餐桌，全程透明」。

### 1.2 三端核心诉求与痛点（25 号清单 v1.1，一句话总结）

- **消费端**：「看得见、投诉有回音」——食品安全/价格/资质不可见，投诉无门无反馈（9/9 全行业共性）。
- **经营端**：「低门槛、有获得感、不被讹、货款有保障」——平台抽成高获客贵、被职业差评索赔讹诈、招工靠赌、货款拖欠。
- **监管端**：「看得见、管得动、取证易、有数据预警」——人手不足事后监管、取证难、数据不互通、民生诉求响应难。

### 3.1 美团 / 大众点评

> 核验日见文末来源。本节为压缩版，逐条来源 URL 与「未核验项」详见调研过程文件：`市场分析/民生甄选-竞品核验调研_美团大众点评_天鹅到家.md`。

#### (1) 产品概况

- **主体与模式**：美团（港交所 03690.HK），核心运营主体北京三快在线科技；大众点评 2015 年并入美团，为到店内容/评价品牌。模式为「到店+到家」综合生活服务（外卖、到店团购/酒旅、即时零售）+ 评价内容（[调研记录文件](市场分析/民生甄选-竞品核验调研_美团大众点评_天鹅到家.md)）。
- **规模（财报口径）**：2024 年营收 **3,376 亿元（+22%）**、年交易用户破 **7.7 亿**、研发投入 211 亿元、到店订单量 +65%（[美团官方新闻稿](https://www.meituan.com/zh-HK/news/NN250321082001991)）；2023 年营收 2,767 亿元、即时配送 219 亿笔（[美团官方](https://www.meituan.com/zh-HK/news/NN240322064007784)）。
- **监管史**：2021 年因「二选一」垄断被罚 **34.42 亿元**（[央广网](https://news.cnr.cn/dj/20211008/t20211008_525627020.shtml)）。
- 全平台 GTV / 商户总数近两年财报未单独披露 [未核验]。

#### (2) 功能清单（分端）

**消费端**
- **评价与星级**：星级评分是大众点评/美团核心；推行「星级新规」，2025 年处置违规评价超 **2,557 万条**（含 AIGC 类 1,161 万条）、引入 AI 智能体审核、高强度促评商户数 -42%（[新华网](https://www.news.cn/tech/20260323/b1ebc84e186b4b52bbba15059b229cbf/c.html)、[央广网](https://travel.cnr.cn/hydt/20260324/t20260324_527560856.shtml)）。
- **榜单体系**：必吃榜 2024 年覆盖 119 城 2,797 家餐厅（[美团官网](https://www.meituan.com/zh-HK/news/NN240627060010337)）；黑珍珠餐厅指南 2018 年首发（[中新网](https://www.chinanews.com.cn/m/sh/2018/01-25/8432596.shtml)）。
- **明厨亮灶/后厨直播（用户可见）**：外卖 App「亮厨直播」、堂食后厨可见已向用户开放（[南方网](https://news.southcn.com/node_810c33d731/9d518db7cf.shtml)）。
- **信用支付**：美团月付（2020-05 上线，先消费后还款，[东方财富](https://finance.eastmoney.com/a/202005311503804186.html)）。
- **投诉/举报入口**：规则中心公开「到店商家违规评价投诉步骤」「小美评审团（评价争议）」公约（[美团规则中心](https://rules-center.meituan.com/rule-detail/1364/1)）。

**商户端**
- **经营工具**：「开店宝」升级为「美团经营宝」（订单管理到门店营销，鸿蒙版覆盖，[应用宝](https://sj.qq.com/appdetail/com.sankuai.meituan.merchant)）。
- **评价回复与差评申诉**：争议评价可投诉/评审；2025-03 起「全面打击恶意差评」（[美团官网](https://www.meituan.com/zh-HK/news/NN250303073007724)）。
- **付费推广/广告**：平台主要商业化模式之一（费率透明化与到店佣金竞争报道佐证），具体推广产品名未核验到官方页 [未核验]。

**监管协同（食安政企产品——竞争威胁重点）**

- 区域共建案例：贵阳「平台筛查+执法核查」、厦门思明区首个县区级合作备忘录、山东烟台政企整治网络餐饮（[中国质量报](https://www.cqn.com.cn/zgzlb/content/2026-06/25/content_9162280.htm)）；2025-11 市场监管总局指导 8 家平台发起食安自律公约（美团是否在列未核验，[央视网](http://big5.cctv.com/gate/big5/news.cctv.com/2025/11/07/ARTIlJopSxkjWodgecqUqxjW251107.shtml)）。

#### (3) 信用 · 透明 · 保障与费率机制

- **评分/星级**：用户评价聚合生成，算法细节未公开 [未核验]。
- **差评申诉**：平台内（商家投诉/小美评审团）+ 平台外（12315/黑猫）双路径。
- **商家处罚与资质展示**：平台自有权责体系（下线/清退）+ 监管联动；但证照/处罚/信用**集中式档案对消费者可见的产品形态未核验到**（法规层面外卖须展示证照为行业通行要求）。
- **费率（动态、非承诺制）**：2021-05 外卖费率透明化拆分「技术服务费+配送服务费」（[经济参考报](http://www.jjckb.cn/2021-05/12/c_139941026.htm)）；2023-07 到店佣金因抖音竞争部分下调（[第一财经](https://www.yicai.com/news/101809328.html)）；2024-12 官方发文回应「真实佣金比例」（[美团](https://www.meituan.com/news/NN241225051008799)）。
- **食安保险**：「放心吃」责任险存在（2018 报道），黑猫投诉存在拒赔争议（[示例](https://tousu.sina.com.cn/complaint/view/17397677633)）。

#### (4) 产品特点分析

**优势**：用户/评价/数据规模巨大，榜单成消费决策基础设施；主动治理评价真实性（AI 审核 + AIGC 处置）以维护公信力资产。
**局限（对照政府信用档案）**：①「既做裁判又做运动员」——星级/榜单与广告抽成同体，利益冲突结构不可消除（2557 万条违规评价处置即军备竞赛旁证）；② **过程透明弱**——强在「结果评价」、弱在供应链溯源/全产业链过程透明（未检索到面向消费者的溯源档案机制）；③ 费率随监管与竞争**动态调整**，非「公开承诺制」；④ 证照/处罚/信用档案式集中公示未见产品化。

#### (5) 对民生甄选的启示与威胁

| 民生甄选关注点 | 借鉴点 | 威胁点 |
|---|---|---|
| D2/D3 投诉与差评申诉 | 评价真实性治理方法论（AI 审核 + 评审团争议仲裁）可映射 | 平台已有成熟「恶意差评打击」，商户心智被占 |
| B2 明厨亮灶 | 「后厨直播用户可见」产品形态作体验参照 | — |
| A1 一店一档 / 监管协同 | 「天网天眼」「数字食安服务站」的政企数据打通样式作设计输入 | **商业平台加速政企共治（2026 数字食安服务站），正稀释「政府平台才有的监管协同」稀缺性**；须以「政府牵头+数据权威+非营利治理」形成位差 |

**优点**：政务「一店一码」证照公示入口，扫码即验照面+信用+监管/投诉记录；监管扫码执法显著提效减负（商户贴码动因）；服务聚合（年报/信用修复/政策/金融）提升活跃与数据实时性；投诉看板+高频被诉预警实现监管端预警闭环；接入电子执照后具全国互认效力。
**局限**：消费端偏「查+信任」，**无交易/下单/支付闭环**；无消费者在线投诉跟踪、评价打分；无结构化好评率与跨商户可比榜单（宣传「一码识信用、一图知风险」，分级细则消费端不可见）；处罚/抽检以「监管记录」聚合展示、逐条明细公开面未证实。

**与民生甄选 A1「一店一档」的差距**（分析）：石监码已覆盖「证照+许可+信用+监管检查+投诉记录展示+内部预警」，接近 A1 的档案底座；差距在：① A1 是**消费者可见的全量档案 + 可比较可决策呈现（评分/榜单）**，石监码消费端无评分比较工具；② A1 与 D2 投诉闭环实时联动（投诉率/处理时效反写档案），石监码投诉记录与消费端流程割裂；③ 抽检/处罚明细逐条公开与预警联动需 A1 自建接入。

## 5. 竞争结论与对民生甄选的启示

### 5.1 模式级差异结论（六大竞品逐一对照）

民生甄选不存在功能上一对一的直接竞品（市场报告 §3.1 结论成立），六个产品各自只解决了「三位一体」中的一个环节，与民生甄选的差异是**模式级**的：

| 竞品 | 他们只有 | 民生甄选有 | 差异本质 |
|---|---|---|---|
| 美团/点评 | 平台自治评分 + 流量与竞价广告 | 政府信用档案（一店一档）+ 免费信用加权流量（E2） | 从「买流量」到「信用换流量」 |
| 天鹅到家 | 履历自证 + 高抽成（约 30% 口径）撮合 | 政府核验一人一档 + 劳务双向信用 + 工资保障 | 从「平台单方背书」到「可核验可流动的信用」 |
| 满帮 | 封闭货主信用 + 平台自有担保 + 费率不透明 | 监管数据注入的司机/货主信用 + 第三方持牌结算 + 费率公开承诺（F5） | 从「约谈整改式透明」到「制度性公开」 |
| 1688 | 付费会员认证（诚信通等）+ 无商品溯源 | 监管抽检/处罚数据注入的供应商信用 + 一物一码溯源 + 担保验收（T2/T3/T4） | 从「平台自证」到「政府监督背书」 |
| 全国 12315 | 个案受理 + 调解 + 公示（明示非信用信息） | 全量档案 + 信用分联动 + 评价闭环 + 结果回写档案（A1/D2） | 从「受理渠道」到「决策依据」 |
| 石监码 | 政务查档入口 + 监管执法工具（无消费闭环） | 消费端交易/评价/维权闭环，为石监码补「群众入口」 | 从「一店一码查询」到「一店一档生态」 |

### 5.2 空白机会点（按矩阵读出，M1 起即有差异）

1. **一店一档全量聚合 + 可比评分**：把证照/处罚/抽检/投诉率/好评率聚合为消费者可比较、可决策的档案页——12315 只公示投诉单维且「非信用」，石监码无评分比较，商业平台无政务数据。→ A1（P0，M1）
2. **全链一物一码溯源**：六大竞品公开检索**均无**商品级溯源产品。→ T3 基础版（P0，M1）
3. **工资/运费/货款保障闭环（第三方持牌 + 平台不沉淀）**：满帮是平台自有担保、1688 靠支付宝、其余全无；「政府监督下的持牌通道结算 + 费率公开」是全新信任结构。→ C1/I3/F4/T4（P0/P1）
4. **费率公开承诺 + 免费信用加权推广**：商业平台费率随市场动态浮动且不透明；民生甄选「0.5%~1% 公开 + 免费推广」直接回应经营端最大痛点（抽成高、获客贵）。→ §8.1 承诺 + E2（P2）
5. **投诉闭环反写档案 + 满意度二次评价**：12315 有法定时限与公示、但无消费者二次评价、结果不写回信用档案；民生甄选 D2「处理→公示→档案联动」无人做全。→ D2（P0，M1）
6. **一人一档 + 劳务双向信用**：天鹅到家等无双向信用、无档案随身与跨平台流动。→ A2/C3/I2（P0，M1 家政）

### 5.3 主要威胁与速度竞赛

- **商业平台政企共治下沉**：美团 2026-05「数字食安服务站」已与监管数据打通（§3.1），但范围止于食安线索协查级，未延伸到一店一档、政府背书交易与工资保障闭环——**先发窗口 2~3 年**（市场报告 §0 结论仍需重视）。
- **12315 全国标杆的「重复建设」质疑**：民生甄选若只做同类投诉受理必被质疑；差异化必须锚定其明确不做的「全量档案+信用联动+评价闭环」。
- **石监码本地强品牌的「第二个码」风险**：131 万户赋码、重点场所亮码率 100%、扫码习惯已养成（§3.6）。**建议协同策略**：共用赋码与扫码入口互跳、档案数据回流、谈判姿态 =「民生甄选为石监码补上消费端闭环，石监码为民生甄选提供官方数据与入口」；避免正面竞争与重复建设。
- **兄弟城市模式复制**：福州「放心码」、鹰潭「鹰诚有信」、夏津「智监宝」等单功能试点在扩展（市场报告 §3.2），须抢建石家庄心智与数据占位。
- **合规与舆论风险（反面教材）**：满帮信贷利率争议与「抽佣+放贷」批评（§3.3）、天鹅到家高抽成+亏损+五险一金争议（§3.2）——提醒民生甄选守住「平台不沉淀资金、费率公开、不向用户放贷收割」的边界。
