### (d) 产品特点分析

- **平台自治评价模式的优点**:用户/评价/数据规模巨大(2024 年交易用户 7.7 亿),评价实时海量,榜单(必吃榜/黑珍珠)已成为餐饮消费决策基础设施;近年主动治理评价真实性(AI 审核、AIGC 处置),说明其在尽力维护公信力资产。
- **局限(与政府信用档案对照)**:
  1. "既做裁判又做运动员":星级/榜单与广告、抽成同处一个商业体内,利益冲突结构上不可消除(促评、刷单治理是持续性军备竞赛,2025 年仍处置超 2557 万条违规评价即是旁证);
  2. **过程透明不足**:平台强在"结果评价"(消费后评分),弱在"过程透明"(供应链溯源、全产业链选品并非其主业,未检索到美团向消费者开放供应链溯源档案的机制);
  3. **费率不具公开承诺稳定性**:佣金水平随监管与市场竞争动态调整(2021 改革、2023 下调),非政府式"费率公开承诺";
  4. 对消费者可见的**证照/处罚/信用档案式集中公示**未见明确产品化(未核验到权威说明)。

### (e) 对「民生甄选」的可借鉴点与竞争威胁点

- **可借鉴点**:
  1. 评价真实性治理方法论(AI 审核 + AIGC 识别 + 评审团争议仲裁)可直接映射到民生甄选 D2/D3(投诉真实性、差评申诉);
  2. "明厨亮灶后厨直播、用户端可见"的产品形态是 B2 模块体验参照(民生甄选需叠加政府背书与溯源链才构成差异);
  3. "天网+天眼"/数字食安服务站展示了政企数据打通的可行落地样式,可作为一店一档(A1)+监管端数据联动的设计输入;
  4. 费率透明化"技术服务费+配送服务费"的拆分表达,可作为民生甄选费率公开页面的信息架构参照;
  5. 美团月付证明"平台内先享后付/信用支付"可行,但它是商业信用而非政府信用——民生甄选"担保交易+信用分"的可借鉴点在于把消费侧信用体验做轻。
- **竞争威胁点**:
  1. 商业平台正加速"监管合作抢身位":数字食安服务站、政企数据打通、自律公约等,可能稀释"政府平台才有的监管协同"稀缺性(民生甄选须以**政府牵头、数据权威、非营利治理**形成位差);
  2. 本地生活流量入口地位 + 补贴能力,会对政府平台"优质小店免费推广"(E2)形成获客压制;
  3. 若其进一步公开商户处罚档案与食安过程信息,将与"一店一档/处罚公示"正面竞争——目前尚未做到,窗口期在政府侧。
- 竞争威胁点 2 综合自:上述各来源 + [凤凰网财经:本地生活竞争复盘类报道](https://finance.sina.com.cn/jjxw/2023-07-15/doc-imzauqqi7031198.shtml)。

### (c) 信任机制

- **履历与身份核验**:平台宣称有实名/资质审核,但公开权威披露有限;检索命中的多为华声在线等"某地天鹅到家靠谱吗"类推广向长文(流程、凭证、售后拆解),**权威性弱,未作为事实依据** → 具体核验项目(犯罪记录背调、健康证、技能证核查范围)列入未核验项。
- **保险**:存在平台关联保险理赔通道——黑猫投诉多起案例显示理赔实际发生(如"师傅洗坏空调,太平洋保险只赔 1100 元"、"保洁损坏石材,保险仅赔付部分"),即**有保险合作但额度与理赔体验存在大量争议**。
  - 来源:[黑猫投诉:洗坏空调保险只赔 1100](https://tousu.sina.com.cn/complaint/view/17401325005)、[黑猫投诉:家政纠纷处理不公](https://tousu.sina.com.cn/complaint/view/17399371489/)、[黑猫投诉:拒不退剩余服务费](https://tousu.sina.com.cn/complaint/view/17400500740/)、[黑猫投诉:保洁损坏石材保险部分赔付](https://tousu.sina.com.cn/complaint/view/17400374312/)
- **服务质量处理(差评/投诉/退单)**:平台有客服与投诉渠道(黑猫案例均经由投诉渠道产生),但从投诉集中度看体验不稳定;是否形成"雇主可查的阿姨差评档案"未核验到公开说明。
- **双向评价与信用记录**:雇主对阿姨、阿姨对雇主的双向评价与信用记录**未查到公开资料** → 未核验项(很可能不存在公开的跨平台信用,见 (d))。
- **政府侧参照(与一人一档最相关)**:商务部自 2019 年起建设**家政服务信用信息平台**(2020-07 发布会:建立"家政服务员信用记录 + 家政服务企业信用记录"两类记录,配"家政信用查");2024 年商务部答复人大建议继续强调信用核查与等级明码标价;2026 年 7 月家政服务新政策出台(新华社报道"如何破解找阿姨难"),并有"19 条举措力促家政服务业发展"类新政报道。即:**国家级"一人一档/一企一档"框架存在,落地依赖企业上报,跨平台流动与互认不足**。

### (d) 产品特点分析

- **中介抽成水平**:媒体解读口径约 30%(对象为订单或劳动者收入,口径待核);同时平台自身三年亏损近 20 亿——"高抽成 + 不盈利"并存,反映家政撮合履约成本高、规模不经济。
- **"履历自证"模式局限**:
  1. 从业者信用由平台单方管理,雇主无法核实"履历是否真实",平台间**黑名单与信用不互认、不可跨平台流动**(行业公开空白,本次未检索到天鹅到家黑名单共享机制);
  2. 无雇主-阿姨**双向公开信用**记录(未查到公开资料);
  3. 劳动报酬与工资保障弱:平台为撮合方,招股书报道曾指其未足额缴纳员工五险一金;工资拖欠类保障闭环未见公开机制;
  4. 信息不对称下"高客单价服务(月嫂 1.35 万/30 天)+ 有限核验"的组合放大了信任风险。
- 覆盖度对照民生甄选维度:**A2 一人一档(未做,仅平台会员信息)、C3 履历核验(平台自证式,无政府背书)、I2 劳务信用(无双向信用/无跨平台流动)、工资保障(弱)**——四项几乎均为空白。

### (e) 对民生甄选家政场景(A2 一人一档 / C3 履历核验 / I2 劳务信用)的可借鉴点与空白点

- **可借鉴点**:
  1. 阿姨端"接单 App"(阿姨一点通)+ 经纪人匹配的从业端交互形态,可作为一人一档中"从业者自助认领、更新档案"的 UX 参照;
  2. "保险 + 平台"售后通道的存在证明家政保险可落地,民生甄选可做政府侧统筹的标准化家政险;
  3. 招股书暴露的"高抽成、亏损、履约重"反证了**政府平台做撮合+信用背书而非自营雇佣**的路线合理性。
- **空白点(即机会点)**:
  1. 对接商务部家政服务信用信息平台与 2026 新政,在石家庄落地**政府背书的 A2 一人一档**(身份+健康+技能+无犯罪记录+处罚/好评记录集中可见、可查);
  2. C3 履历核验用政府数据源替代"履历自证",并支持从业者**档案随身跨平台流动**;
  3. I2 劳务信用做成**雇主-从业者双向评价 + 行业黑名单互认 + 工资支付保障**(对比天鹅到家三项皆无);
  4. 费率/抽成公开承诺(对比商业中介约 30% 且不透明的口径)直接呼应"惠民"理念。
- **威胁点**:天鹅到家自身威胁有限(亏损、上市搁浅、战略转向养老与机器人),但家政赛道 2026 年出现京东、美团等银发家政新进入者,竞争将转向"平台+重服务+保险"组合,政府平台须以信用权威与本地治理闭环卡位。
  - 来源:[界面新闻:京东美团杀入银发家政市场](https://www.jiemian.com/article/14746060.html)、[蓝鲸财经](https://www.lanjinger.com/d/1783784865418825037)、[虎嗅](https://www.huxiu.com/article/4874268.html)
