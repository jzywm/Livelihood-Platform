# 阶段 2:痛点验证(Agent 主战场 · 联网搜索)

> 目标:从海量网络信息中挖掘**用户真实痛点**,并对每条痛点做"反伪需求"验证。
> 预计耗时:半天~1 天 · 负责人:Agent 搜索并整理,人类审阅拍板
> **这是全 SOP 最核心的阶段 —— 产品做不做得成,取决于这里挖到的痛点真不真。**

---

## 2.1 痛点来源渠道(按优先级)

| 渠道 | 能找到什么 | 搜索 query 技巧 |
| --- | --- | --- |
| 知乎 | 深度长文吐槽、行业从业者爆料 | `领域 + 后悔/踩坑/避雷/真实感受` |
| 小红书 | 普通用户日常抱怨、消费决策纠结 | `领域 + 吐槽/劝退/后悔/分享` |

| 海外 Reddit/Quora | 成熟市场对标痛点 | `domain + problem/frustration/rant` |

## 2.2 痛点挖掘提示词模板(直接复制给 Agent)

### 模板 A:用户原话挖掘
```
请帮我搜索【领域】用户真实吐槽和抱怨。要求:
1. 渠道优先:知乎、小红书、贴吧、应用商店评论
2. 收集 10~20 条"用户原话"(必须是真实用户发言,注明出处链接)
3. 每条标注:用户身份线索(如"备考学生""店老板")、场景、抱怨的具体点
4. 不要给我总结观点,先给我原话和出处
```

### 模板 B:竞品差评挖掘
```
请搜索【竞品名/领域头部产品】的用户差评。要求:
1. 找到应用商店/社交媒体上对它的负面评价 10~15 条
2. 逐条列出:不满的点、用户场景、原话
3. 聚类:哪些不满反复出现?(重复出现 = 真痛点)
4. 特别注意"用户因此流失/转投别家"的评论
```

### 模板 C:从业者痛点
```
请搜索【领域】从业者(店主/运营/服务提供方)的吐槽。要求:
1. 渠道:知乎、行业论坛、行业社群讨论截图、访谈报道
2. 找出从业者经营中 5~10 个具体麻烦(成本、获客、管理、合规…)
3. 每条标注证据出处
4. 判断哪些麻烦"用软件能解决"、哪些是物理世界问题
```

### 模板 D:付费意愿探测
```
请搜索【领域】用户愿意为什么付费的证据。要求:
1. 关键词:会员/付费/价格/涨价/值不值
2. 找出"用户愿意掏钱"或"用户拒绝付费"的具体案例各 3~5 个
3. 判断:这个需求的付费意愿强还是弱?证据是什么?
```

## 2.3 反伪需求检查表(每条候选痛点必须过 3 关)

| 关卡 | 检查问题 | 通过标准 | 伪需求特征 |
| --- | --- | --- | --- |
| 关 1:真实性 | 是否有 ≥3 条独立用户原话/差评提到? | 是(有出处) | 只有行业报告/媒体说,没有用户原话 |
| 关 2:频次与强度 | 是否高频(周级)或单次强度极大(损失大/情绪强)? | 至少占一条 | 低频且无关痛痒("有了更好,没有也行") |
| 关 3:付费意愿 | 用户是否已为"替代方案"花钱,或明确表达愿意付费? | 是 | 用户只抱怨,但拒绝为任何方案付钱 |

> 📌 判断口诀:**"真痛"= 用户已经花钱在解决(哪怕是用笨办法);"伪痛"= 用户只是嘴上抱怨,一毛不拔。**

### 伪需求典型画像(遇到请警惕)
- 🔴 **媒体需求**:只有行业报告/自媒体在喊,找不到一个真实用户原话
- 🔴 **极客需求**:只有"懂行的人"想要,大众无感(如:给程序员做的 AI 插件通常很小众)
- 🔴 **一次性需求**:半年才痛一次,用户记不住你(如:搬家、办证)
- 🔴 **"有更好"需求**:用户说"如果有的话我会用",但从不为替代品付钱
- 🔴 **解决方案倒推需求**:先想好了方案再编需求(典型自欺:我有 AI 技术 → 硬找场景)

## 2.5 置信度标注(Agent 自评,供人类参考)

| 置信度 | 含义 | 依据 |
| --- | --- | --- |
| 🟢 高 | 痛点几乎确定 | ≥5 条独立原话 + 付费证据 + 竞品差评佐证 |
| 🟡 中 | 痛点存在但强度存疑 | 3~4 条原话,付费证据弱 |
| 🔴 低 | 只是线索 | <3 条原话,来源单一 |

> 🟡/🔴 项不要直接丢,留到阶段 3 让真实用户去验证 —— 这正是访谈提纲里要问的问题。

## 2.6 决策门 G2

| 问题 | 通过标准 |
| --- | --- |
| 是否有 ≥1 个 🟢 高置信度核心痛点? | 有 |
| 该痛点是否"足够痛"(高频 or 强损失 or 强情绪)? | 是 |
| 是否有付费意愿证据? | 有(哪怕是"已在为替代方案花钱") |
| 你(人类)看了原话是否觉得"这确实烦"? | 是(直觉交叉验证) |

- ✅ 通过 → 锁定 1~2 个核心痛点,进入 [阶段3-用户调研](阶段3-用户调研.md)
- ⚠️ 只有 🟡/🔴 → 回到 2.1 换渠道补搜 1 轮;仍无 → 换细分方向
- ❌ 全是伪需求 → **果断放弃该方向,回阶段 0 换想法**(这是本 SOP 最有价值的止损点)
