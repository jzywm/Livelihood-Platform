# 阶段 1:市场扫描(Agent 主战场 · 联网搜索)

> 目标:建立宏观认知 —— 市场有多大、在涨还是在跌、有哪些玩家、有什么政策风向。
> 预计耗时:2~4 小时 · 负责人:Agent 执行搜索并出报告,人类审阅
> **本阶段不找需求,只找"地形"。需求是阶段 2 的事。**

---

## 1.1 本阶段要回答的 4 个问题

| # | 问题 | 搜索方向 |
| --- | --- | --- |
| M1 | 市场规模与增速 | 市场规模、行业报告、增长率、渗透率 |
| M2 | 市场趋势(涨/跌/变) | 行业趋势、新兴模式、政策、技术变化 |
| M3 | 竞争格局 | 头部玩家、融资、产品形态、市场份额 |
| M4 | 进场门槛与风险 | 监管、资质、成本结构、巨头威胁 |

---

## 1.2 联网搜索提示词模板(直接复制给 Agent)

### 模板 A:市场规模
```
请帮我搜索【领域】的市场规模数据。要求:
1. 找到最近 2 年内的行业报告或券商研报引用数据
2. 列出:市场规模(亿元/亿美元)、年增速、主要数据来源、发布时间
3. 如果不同来源数据差异大,并列给出并说明原因
4. 给出"市场处于什么阶段"的判断(萌芽期/成长期/成熟期/衰退期)
```

### 模板 B:趋势与政策
```
请搜索【领域】最近 1 年的行业趋势和重要新闻。要求:
1. 找出 3~5 个关键趋势(技术/消费习惯/政策变化)
2. 标注每个趋势的证据来源和日期
3. 特别注意:监管政策变化、大厂动向、融资事件
4. 总结:这个市场是在扩张、收缩还是转型?
```

### 模板 C:竞争格局
```
请搜索【领域】的主要玩家和竞争格局。要求:
1. 列出 3~5 个代表性产品或公司(含背景:大厂/创业公司/海外)
2. 每个玩家用 2~3 句话概括:做什么、主打人群、差异化点
3. 搜索各家的融资情况或市场声量(如 App 下载量/门店数/用户数)
4. 指出竞争空白区(没人做好/没人做的细分)
```

### 模板 D:风险扫描
```
请搜索【领域】的监管、资质和进入壁垒。要求:
1. 是否需牌照/资质/合规要求
2. 主要成本结构(重资产 or 轻资产)
3. 行业负面新闻或暴雷案例
4. 巨头/大厂是否已布局,威胁程度如何
```

## 1.3 Query 范例库(以"共享自习室"为例,换成你的领域即可)

| 目的 | 范例 query |
| --- | --- |
| 市场规模 | `自习室 市场规模 报告` / `共享自习室 行业报告 2024` |
| 趋势 | `自习室 行业 趋势 2024` / `自习室 倒闭 关店 原因` |
| 竞争 | `自习室 品牌 加盟 对比` / `自习室 App 产品 排名` |
| 监管/风险 | `自习室 监管 政策` / `自习室 创业 失败 案例` |
| 海外参照 | `study cafe market size` / `silent study space japan trend` |

> 💡 搜索技巧:任何 query 先搜中文,再搜英文(海外常有更成熟的市场报告);用"领域 + 报告/研报/数据"组合找权威信源。

---

## 1.4 信源分级(判断数据可信度)

| 级别 | 类型 | 可信度 | 用法 |
| --- | --- | --- | --- |
| S1 | 券商研报、国家统计局、行业协会白皮书 | ★★★★★ | 市场规模/增速以此为准 |
| S2 | 头部媒体(36氪/虎嗅/晚点)、投资机构官网 | ★★★★ | 趋势、融资信息 |
| S3 | 行业垂直媒体、公司官网、招聘信息 | ★★★ | 竞品动态、产品细节 |
| S4 | 知乎/小红书/贴吧/评论区 | ★★ | **只用来找"用户原话",不用来定市场规模** |
| S5 | 无出处的营销软文、百度百科旧词条 | ★ | 仅作线索,不能引用 |

> ⚠️ 铁律:**规模数字只用 S1~S2 信源;用户感受只用 S4 信源。** 混用是报告造假的第一步。

## 1.6 决策门 G1

| 问题 | 通过标准 |
| --- | --- |
| 市场是否真实存在? | 有 S1/S2 信源支撑的规模数据(而非只有 S4 讨论) |
| 趋势是涨还是跌? | 多数信号指向增长/转型,而非明显衰退 |
| 是否有可进入的空白/细分? | 能找到"没人做好"或"巨头看不上"的缝隙 |
| 风险是否可承受? | 无致命监管/资金门槛 |

- ✅ 通过 → 进入 [阶段2-痛点验证](阶段2-痛点验证.md)
- ⚠️ 存疑 → 补搜 1 轮再判
- ❌ 不通过 → **建议换方向,止损在此时**

> 📌 记忆点:G1 是"要不要打这场仗",G2 是"打哪个山头"。别在 G1 就陷进需求细节。
