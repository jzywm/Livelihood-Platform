# 阶段 3:用户调研(Agent 辅助 · 真实用户介入)

> 目标:用真实用户的一手反馈,验证阶段 2 挖到的核心痛点,并收集他们期望的解决方案。
> 预计耗时:2~3 天(招募+访谈+整理) · 负责人:**人类主导**(访谈必须真人进行),Agent 负责设计提纲、整理记录、聚类分析
> ⚠️ 本阶段无法被 Agent 替代 —— 联网搜索再强,也替代不了和 5 个真实用户各聊 30 分钟。

---

## 3.1 调研设计(Agent 起草)

### 样本设计
| 项 | 建议 |
| --- | --- |
| 访谈人数 | 5~10 人(第 5 人后若没有新信息 → 饱和,可停) |
| 问卷投放 | 100+ 份(用于定量验证,访谈用于定性深挖) |
| 招募渠道 | 目标用户聚集地:社群、小红书、贴吧、朋友转介绍 |
| 筛选条件 | 必须"正在经历该痛点"的人,而不是"觉得这想法不错"的人 |
| 甄别题 | "你现在怎么解决这个问题?"——答不出 = 不是目标用户 |

> 🔑 黄金筛选题:**"这个问题你现在是怎么解决的?"**
> 答"忍着/用笨办法/花钱请人" → 真用户;答"没想过/有的话会试试" → 伪用户。

### 访谈提纲模板(Agent 生成,人类可改)

```
# 访谈提纲:【领域】用户调研
访谈对象:____(编号) · 日期:____ · 方式:____

## 破冰(5 分钟)
1. 简单介绍你自己和最近的生活/工作状态?
2. 【领域】相关:你最近一次接触【场景】是什么时候?讲讲过程。

## 现状挖掘(15 分钟)← 核心,占一半时间
3. 你现在是怎么处理【痛点场景】的?能具体讲讲最近一次吗?(要故事,不要观点)
4. 这个过程里,最让你烦/花时间/花钱的是什么?
5. 为了这件事,你花过多少钱?用过哪些工具/服务?结果如何?
6. 有没有哪次你特别生气/无奈?发生了什么?

## 理想方案(10 分钟)
7. 如果有个东西能帮你解决这个问题,你希望它长什么样?
8. 你愿意为它花多少钱?什么情况下你会毫不犹豫买?
9. 什么东西是你绝对不会要的?(反向问题挖出边界)

## 收尾(5 分钟)
10. 还有什么我没想到的问题吗?
11. 你能帮我介绍 1~2 个和你有类似经历的朋友吗?(滚雪球招募)
```

### Agent 访谈辅助技巧(给访谈者的提示)
- 问"**最近一次**",不问"一般怎么样" —— 具体故事才有真实细节
- 用户说"还行吧" → 追问"**具体哪里还行,哪里不行?**"
- 用户说"我想要 X 功能" → 追问"**现在没有 X 时你是怎么做的?**"(挖真实行为,不采信口头需求)
- 前 5 分钟别推销你的想法 —— 先让用户讲完自己的世界

## 3.2 问卷框架模板(定量验证用)

```
# 问卷:【领域】需求验证
1. 甄别题:你最近 3 个月是否经历过【场景】? (是→继续 / 否→结束)
2. 你目前如何解决? (单选:忍着 / 用工具 / 花钱找人 / 其他)
3. 这件事让你多烦? (1~5 分)
4. 你每月为它花多少钱? (选项区间)
5. 如果有一个产品帮你解决,你愿意月付? (拒绝/0-10/10-30/30-50/50+)
6. 你最希望解决的是哪个环节? (多选:____/____/____)
7. 你会在什么渠道寻找解决方案? (多选)
8. 开放题:讲讲你最惨的一次经历
```

> 问卷分析要点:看"第 3 题 ≥4 分 + 第 4 题 >0 元"的交叉人群占比 —— 这才是可货币化的真实需求。

## 3.4 决策门 G3

| 问题 | 通过标准 |
| --- | --- |
| 核心痛点是否被 ≥60% 访谈对象确认? | 是 |
| 用户是否已在为替代方案花钱? | ≥半数有付费行为或明确付费意愿 |
| 是否有阶段 2 没发现的新洞察? | 已记录并纳入 |
| 你(人类)听完访谈后信心如何? | 比阶段 2 更强(或找到明确修正方向) |

- ✅ 通过 → 进入 [阶段4-需求输出](阶段4-需求输出.md)
- 🔄 部分证伪 → 修正核心痛点定义,必要时补 2~3 个访谈
- ❌ 大面积证伪 → **回到阶段 0/2,换方向或换细分人群**(此时止损仍便宜)

> 📌 本阶段最常见的结局:不是"确认",而是"修正"。原以为的痛点 A,访谈后变成痛点 B —— 这是正常且宝贵的收获。
