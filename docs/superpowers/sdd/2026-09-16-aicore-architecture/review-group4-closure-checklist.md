## 已在本会话固化、**复核时请一并使用**的判据纪律

1. **接受标准 = 一条今天就能红的用例**（"请给出自证"不作为验收依据）；
2. **内存变异**：`pytest -p <plugin>` 在运行期替换模块属性 —— 不碰仓库文件、无"改 src + finally 还原"的注入风险；
3. **判据要键"出处"，不能键"看起来相关的表面特征"** —— 本会话该教训出现**五次**
   （栅栏位置、异常类型 vs 出处、`"skipped" in stdout`、pytest 打印正则的引号风格、
   以及验证脚本被 here-string 吃掉嵌套引号）；**探针本身也是判据**；
4. **MUST NOT 依赖被测对象自己的常量做期望值**（本仓已有判例：把常量改成自洽但错误的 35，验收脚本仍全绿）。
