# P0 功能细化 · 用户故事 + 关键流程（设计前准备）

> 目的：把《需求规格说明书》P0 模块细化为可开发的用户故事，供下一阶段（原型/设计）直接使用
> 状态：v1.1 对齐（2026-09-01）——本文件为早期调研细化，**其中 P0-4 两种模式、P0-8 工资专户托管已被 `24-平台账户系统需求.md` 的「模式丙：代付留痕+证据链」取代（银行专户不可接）**；其余模块仍有效。最终口径以《需求规格说明书》v1.1 与 `24` 为准。

## P0-1 一店一档（商户档案）

### 用户故事
- 作为**消费者**，我想查看任意一家商户的证照、处罚记录、抽检结果、投诉率和好评率，以便决定是否消费
- 作为**监管人员**，我想看到辖区商户档案总览与异常标记，以便精准执法
- 作为**商户**，我想维护自己的档案信息（上传证照、回应投诉），以便展示诚信

### 关键流程
1. 商户注册 → 实名认证（对公/法人）→ 上传营业执照、许可证 → 平台/市监核验 → 生成「一店一档」页面
2. 消费者扫码或搜索进入档案页 → 查看证照、处罚、抽检、投诉、评价
3. 异常（证照临期/投诉激增）→ 自动标记 → 监管端预警

### 数据字段
店名、统一社会信用代码、法人、地址、经营范围、证照（含有效期）、处罚记录、抽检记录、投诉率、好评率、信用分、后厨直播入口、溯源入口

## P0-2 一人一档（从业人员档案）

### 用户故事
- 作为**从业人员**，我想拥有可查证的身份与履历档案（健康证、技能证、工作经历），以便求职时证明自己
- 作为**雇主**，我想核验应聘者的证件与经历真实性，以便放心雇佣
- 作为**监管人员**，我想核查从业人员年龄（防童工）与证件有效期

### 关键流程
1. 从业人员实名认证（身份证+人脸）→ 核验健康证/技能证（联网）→ 生成「一人一档」
2. 入职时雇主扫码核验 → 平台记录雇佣关系
3. 离职/在职经历由雇佣关系自动累积成履历

## P0-3 信用分体系（红黑榜）

### 用户故事
- 作为**消费者**，我想看到商户信用分和红黑榜，以便快速筛选
- 作为**商户**，我想了解自己的信用分构成并申诉扣分项，以便提升
- 作为**监管人员**，我想按信用分分级监管（低分多查、高分少查），以便节约人力

### 信用分构成（建议权重，待确认）
- 基础合规 40%：证照齐全有效、抽检合格
- 经营行为 30%：投诉率、投诉处理及时率
- 员工权益 20%：工资发放及时、社保/合同（对接 C1）
- 社区贡献 10%：评价互信、公益行为

## P0-4 工资监管

### 用户故事
- 作为**员工**，我想确认工资按时足额到账，发现欠薪能一键举报直达劳动监察
- 作为**商户**，我想规范用工记录（打卡、合同），避免劳动纠纷
- 作为**监管人员**，我想看到欠薪预警（工资发放异常），以便提前干预

### 两种落地模式（待用户选）
- 模式甲：**工资专户托管** —— 工资经平台/银行专户发放，先发工资后结算（防欠薪最硬，但对小商户门槛高）
- 模式乙：**打卡+举报直达** —— 打卡留痕 + 欠薪举报直达劳动监察（门槛低，防欠薪是事后补救）

### 关键流程（模式乙）
1. 员工上下班打卡（位置+时间）→ 生成考勤记录
2. 商户在平台确认发薪 → 员工确认到账
3. 超过应发日未发 → 自动生成欠薪预警 → 员工可一键举报 → 直达劳动监察 → 进度可见

## P0-5 防童工

### 用户故事
- 作为**监管人员**，我想在入职环节自动核验年龄，以便杜绝童工
- 作为**商户**，我想在招聘时一键核验年龄，避免误招

### 流程
入职登记 → 身份证+人脸核验 → 年龄 <16 自动拦截并警示 → 记录留痕

## P0-6 投诉直达 + 进度可见

### 用户故事
- 作为**消费者**，我想一键投诉并实时看到处理进度，避免投诉无门
- 作为**商户**，我想收到投诉通知并申诉，避免被单方面定性
- 作为**监管人员**，我想看到投诉全流程数据，以便监管

### 关键流程
1. 消费者提交投诉（选商户、类别、证据照片/视频）
2. 平台智能分诊 → 商家先处理（限时 48h）→ 未解决升级市监
3. 全程进度可视化：处理中/已解决/已升级/已处罚
4. 结果公示（脱敏）→ 计入商户信用分

## P0-7 群众热线基础版（G1，用户新增）

### 用户故事
- 作为**群众**，我想通过热线平台投诉/求助并直达政府部门，看到办结进度，避免「打了电话没人管」
- 作为**政府部门**，我想接收工单、限时办结、结果公示，接受群众监督
- 作为**监管人员**，我想看到群众诉求热点分布，辅助治理决策

### 关键流程
1. 群众提交诉求（选部门/类别，可附证据）→ 生成工单
2. 平台智能派单至对应部门（自建工单，12345 不可接）→ 限时办结（如 7 天）
3. 进度可见：已受理/处理中/已办结/已评价
4. 办结结果公示（脱敏）→ 优秀建议/高频诉求进入建议论坛（G2）

## P0-8 工资保障（C1，已被模式丙「代付留痕+证据链」取代，见 `24`）

### 用户故事
- 作为**员工**，我想工资由专户按时足额发放，杜绝老板拖欠
- 作为**商户**，我想所有成本（原材料、工资）在平台统一结算，账目清晰、信用加分
- 作为**监管人员**，我想看到工资发放异常预警，提前干预欠薪

### 关键流程
1. 商户在平台开通结算账户（对接银行专户）
2. 员工入职绑定收款账户 → 考勤打卡留痕
3. 每月结算：原材料款 + 工资 → 专户托管 → 先发工资后结货款
4. 应发未发自动预警 → 劳动监察介入 → 进度可见
5. 发放记录计入商户信用分（C1 与 A3 联动）

## 非功能要求（P0 相关）
- 商户端优先小程序，录入门槛 ≤1 分钟
- 实名认证仅微信/支付宝实名回传（不接受人工降级）
- 证据存证（时间戳+哈希）供执法调取
- 数据分级授权：个人履历仅本人/授权雇主可见
- 资金结算走第三方持牌支付通道（银行专户不可接），金融合规
