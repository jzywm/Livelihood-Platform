# 模块 K · AI 能力中心需求（全场景 AI 平台化）

> 状态：v1.0（2026-09-01 需求变更 · 用户方案 C 选定 + 视觉模型选型确认 = **云视觉 API**）
> 定位：平台级 **AI 能力中心**，向三端（监管/经营/消费）提供**文本 + 视觉 + 预测**三类 AI 能力，大幅降低人工成本（如监管端原材料合规视觉审核）
> 归属：《需求规格说明书》**模块 K**（新增），分期实施：M1 基础 / M2 审核工作台 / M3 全场景
> 技术基调：文本走 **DeepSeek**（已拍板）;视觉走 **云视觉 API**（通义千问-VL / 智谱 GLM-4V 等，签数据合规协议）;**AI 只做辅助筛查，监管执法决策必须人工做出**

---

## 1. 一句话需求

> 平台建设统一 **AI 能力中心**：监管端上传原材料/证照/抽检图像即可 AI 智能筛查合规问题（疑似过期/变质/包装违规/资质不符），自动标记+置信度分级+人工复核留痕，**把人工逐张审核变为 AI 初筛+人工复核**，节省大量人工成本；并逐步扩展到证照 OCR、图像问答、风险预测、后厨直播异常识别等全场景。

## 2. 能力清单（K1~K5，分期）

| 编号 | 能力 | 场景 | 端 | 里程碑 |
|---|---|---|---|---|
| K1 | **视觉合规审核** | 原材料/证照/抽检图像智能筛查：疑似过期、变质、包装不规范、资质不符 → 置信度分级 → **人工复核流** → 审计留痕 | 监管端（核心） | M2 |
| K2 | **证照 OCR 自动核验** | 营业执照/许可证/检测报告上传后自动提取字段、比对有效期/类目，减少 A1 人工核验量 | 经营端（上传预审）+ 监管端 | **M1（基础，降人工立竿见影）** |
| K3 | **图像问答（多模态）** | 助手 J 扩展：用户拍照问「这袋化肥包装合规吗」「这个食材新鲜吗」，助手结合视觉模型回答 | 消费/经营端（助手） | M2 |
| K4 | **风险预测预警** | 基于信用/交易/抽检/投诉数据预测风险商户，联动 A4 监管预警（如欠薪风险、假货风险） | 监管端 | M3 |
| K5 | **后厨直播画面异常识别** | 联动 B2 后厨直播：画面级异常（未穿工装、卫生问题、明火离人等）自动标记 | 监管端 | M2（随 B2） |
| K6 | **AI 网关与治理** | 统一模型路由（文本 DeepSeek / 视觉云 API）、任务队列、置信度阈值、结果回执、**全链路审计** | 平台底座 | M1 起 |

## 3. 关键流程：监管端视觉合规审核（K1，核心场景）

```
监管上传/巡检图片（原材料、证照、抽检样品）
  → 图像预处理（压缩/脱敏：去除人脸/车牌等无关信息）
  → 云视觉 API 分析（签数据合规协议：不用于训练、图像数据不出域/短期留存）
  → 产出疑似问题标记 + 置信度（高/中/低）
  → 分级处理：
      高置信 → 推送给监管人工确认（一键生成核查单）
      中置信 → 进入复核队列
      低置信 → 自动忽略/归档
  → 人工复核结果留痕（谁核、何时、结论）
  → 复核结论写入商户档案（A1）与信用分（A3 联动）
```

## 4. 合规与决策边界（红线，评审口径）

1. **AI 只辅助、不决策**：AI 输出「疑似问题标记」，**任何执法/处罚/公示动作必须人工确认后执行**；AI 不直接生成处罚决定
2. **图像数据合规**：监管图像属敏感数据 —— 上传脱敏（去除无关人脸/车牌）、加密存储、访问审计、留存周期受控;**云视觉 API 签数据合规协议（图像不用于训练、数据不出域或按协议留存）**,与 DeepSeek 对话数据口径一致
3. **误判治理**：置信度阈值可调;人工复核结果**只用于平台自建评估集调优阈值,不回流第三方模型训练**;定期抽检 AI 标记准确率并公示（内部）
4. **授权**：商户入驻/监管协议中明确图像采集与 AI 审核授权;后厨直播（B2）画面分析需商户授权
5. **未成年人/隐私**：图像中若含无关个人信息,一律脱敏后处理
6. **审计**：AI 调用、标记、复核全链路留痕,可追溯（谁调用/谁复核/依据什么模型）

## 5. 技术架构（概要）

```
AI 网关（统一入口:鉴权/限流/路由/审计）
  ├─ 文本通道 → DeepSeek（助手 J 对话/意图）
  ├─ 视觉通道 → 云视觉 API（通义千问-VL / GLM-4V;签合规协议）
  ├─ OCR 通道 → 轻量 OCR（PaddleOCR 或云 OCR）→ 结构化字段
  └─ 预测通道 → 平台自建风险模型（基于平台数据,不出域）
任务队列（图片审核异步化）+ 结果回执 + 置信度分级 + 复核工作台（监管端 UI）
```

## 6. 里程碑与依赖

| 里程碑 | 交付 | 依赖 |
|---|---|---|
| M1 | **K2 证照 OCR 基础**（A1 上传自动预审）+ **K6 AI 网关底座**（文本 DeepSeek 已就绪,预留视觉通道） | A1 一店一档、DeepSeek |
| M2 | **K1 视觉审核工作台**（监管端）+ K3 图像问答 + K5 后厨异常识别（随 B2） | A1/A3、云视觉 API 签约、B2（M2） |
| M3 | K4 风险预测预警（联动 A4）+ 全场景扩展 | 数据积累、A4 预警 |

## 7. 与五词设计原则自检

| 理念词 | 落点 |
|---|---|
| 惠民 | 减少人工成本,监管覆盖更广、更及时 |
| 方便 | 上传即审,AI 初筛+人工复核,大幅提效 |
| 安全 | 图像脱敏/加密/审计;AI 不决策,人工兜底 |
| 透明 | AI 标记可见、置信度可见、复核结论留痕可查 |
| 直达 | 疑似问题直达复核工作台与商户档案 |

## 8. 风险与缓解

| 风险 | 缓解 |
|---|---|
| AI 误判导致错罚 | AI 只标记不决策,人工复核兜底;置信度阈值可调;复核留痕 |
| 图像数据出域（云视觉 API） | 合规协议（不训练/不出域或短期留存）+ 脱敏前置;备选 DeepSeek-VL 私有化（完全不出域） |
| 视觉模型选型不确定 | 通义VL/GLM-4V 双备选,先小样测试准确率再定 |
| 成本（API 按量） | 图片压缩/抽帧降量;OCR 本地化（PaddleOCR）;限额+审计 |
| 监管责任边界 | AI 辅助定位写入监管工作规程,处罚决定人工做出 |

## 9. 待确认项（默认建议，可调）

| 项 | 建议默认 |
|---|---|
| 视觉 API 厂商 | 通义千问-VL / GLM-4V 先小样测评后定;备选 DeepSeek-VL 私有化 |
| 置信度阈值 | 初始 高≥0.9 / 中 0.7~0.9 / 低 <0.7,上线后按复核数据调整 |
| 图像留存周期 | 复核完成归档 180 天（可调）;失败/忽略样本 30 天 |
| K2 证照 OCR 入 M1 | 建议入（降人工立竿见影,依赖轻） |
| 复核结果反哺 | 只调平台阈值/自建小模型,不回流第三方模型训练 |
