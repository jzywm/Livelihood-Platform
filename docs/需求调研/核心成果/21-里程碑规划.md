## 2. M1 MVP 范围明细（最重要，需拍板）

### 2.1 纳入 MVP（建议）
- **I1 实名账户 + 钱包记账**：全员实名（微信/支付宝实名回传优先）、账户流水记账
- **I2 劳务信用（工作者↔老板双向）**：发薪履约率 + 双向互评 + 红黑榜联动
- **I3 工资保障代付**：第三方通道代付 + 欠薪预警 + 证据出证（替代原银行专户）
- **A1 一店一档**：证照上传 + 人工核验（石监码不可接）、处罚/抽检/投诉/评价档案页；**含价格公示基础版（商户自主维护价目表，消费者可见）**；**娱乐场所/网吧标注「未成年人禁入承诺」**（2026-09-01 拍板轻量纳入）；**K2 证照 OCR 自动预审（上传证照自动提取比对，降人工核验）**
- **A2 一人一档**：实名 + 健康证/技能证核验（先试点餐饮/家政）
- **A3 信用分**：基础合规 + 经营行为两维度起步（员工权益/社区贡献后置）
- **C2 防童工**：入职年龄核验
- **D2 投诉直达 + 进度可见**：商户限时处理 → 升级市监 → 结果公示；**举报类别含「未成年人违规进入」（娱乐场所/网吧）**
- **G1 群众热线基础版**：自建工单 + 线下流转（12345 不可接）
- **T2 供应商资质核验（基础版）**：实名 + 证照核验 + 信用档案
- **T3 溯源二维码（基础版）**：批次码 + 扫码看基础信息（先农资/食材两个品类）
- **J 智能助手（新增 2026-09-01，P0）**：PC Web 侧边栏对话助手 —— 使用指导（FAQ+步骤引导）/ 页面跳转（白名单）/ 商品推荐（透明理由）；M1 以「使用指导 + 跳转」为主、推荐为辅（数据积累期）；详见 `27-智能助手Agent需求.md`
- **J7 画像基础版**：实名/履历（授权）/行为/主动完善入画像 + 个性化推荐 + 画像管理页四权（查看/修改/关闭/删除）
- **K6 AI 网关底座（M1 起）**：统一模型路由 / 任务队列 / 全链路审计

### 2.2 明确不做（MVP 范围外）
- F 物流货运、G2 论坛、H 民生监督、E 社区生态（全部 P1/P2，二期/三期）
- B1 全链条农户端接入、T4 交易撮合 / I4 商品购买 / I5 零工结算（先攒数据与信任，二期再上交易）
- B2 后厨直播、D1 预付卡监管（需额外硬件/银行合作，二期）
- **三小/摊贩（小餐饮/小作坊/小摊贩）流动经营者登记**（2026-09-01 拍板裁剪声明；P3 预留扩展位，是否纳入按评估结果定）

### 2.3 MVP 关键约束
- **PC 端优先**：先 Web 应用（浏览器访问），后续套壳 Windows 桌面程序；移动端后置（用户决策 2026-09-01）
- **资金合规**：工资代付、货款分账走第三方持牌通道（微信/支付宝/聚合支付），平台不沉淀资金、不做二清
- 实名认证：**仅微信/支付宝实名回传（已确认不接受人工证件核验降级）**
- 试点行业建议首期 3 个：**餐饮（食材溯源+工资代付）+ 零售（一店一档+溯源）+ 家政（一人一档+履历核验+劳务信用）**，验证后复制到其他行业

## 3. 时间预期假设与风险

### 假设
- 需求评审通过后进入设计；设计 1~1.5 月，编码每期 2~3 月，联调/试运行 1 月
- **支付通道（微信/支付宝商户号或聚合支付）以 M0 申请成功为前提**，接口文档齐备
- 团队规模 10~20 人（含政府侧协调人）

### 主要风险
1. **支付通道申请失败/审核慢**：微信/支付宝商户号、分账产品资质审核是最大不确定项 → 风险缓解：M0 即启动申请，备选聚合支付服务商（通联/汇付/拉卡拉），双轨并行；**⚠️ 运营主体目前未定（2026-09-01 确认），申请主体缺失 = M0 阻塞项，需尽快确定国企/混合所有制公司**
2. **实名强依赖第三方**：实名仅走微信/支付宝回传（已确认不接受人工降级），第三方实名不可用 = 注册/入职流程暂停 → 缓解：优先确保支付通道/实名服务开通，作为 M0 前置条件；流程设计上实名放在注册第一步，尽早暴露问题
3. **商户冷启动**：200 家商户入驻需要政策引导 → 缓解：政府发文推荐 + 行业协会动员 + 存量商户数据人工导入
4. **数据来源**：处罚/抽检数据无政务接口 → 缓解：商户自主申报 + 群众举报 + 平台巡检，逐步积累
5. **金融合规**：平台不沉淀资金、不做二清 → 缓解：M0 锁定支付通道方案（分账产品），法律顾问审合规方案
6. **大模型助手成本与合规（模块 J，新增 2026-09-01）**：API 按量计费成本不可控 + 对话数据合规 → 缓解：M0 完成服务商合规评估（脱敏前置、数据不出域协议、日志 ≤30 天脱敏留存）；M1 试点限流 + 高频 FAQ 规则库兜底降 API 调用；双服务商备选；幻觉管控（事实类回答绑定平台数据、标注「以页面为准」）
