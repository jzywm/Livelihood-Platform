## 1. 命名决策

### 1.1 主推名：**民生甄选**

| 维度 | 分析 |
|---|---|
| 含义 | 民生 = 平台本质（政府牵头、群众参与）；甄选 = 替用户把好货好店挑出来（信用背书 + 品质把关） |
| 与定位契合 | 直指「全产业链透明交易」核心定位：平台不是货架，是**替消费者/商户甄选**的信用平台 |
| 发音与记忆 | 四字顺口、无生僻字、朗朗上口 |
| 视觉延展 | 「选」字可做对勾/筛选意象；「甄」字带"瓦"旁，可联想"甄别、去伪存真" |
| 商标风险 | ⚠️ 中高：「甄选」系近年电商/零售常用（严选/甄选类），注册前必须查重（重点：第 35 类广告销售、第 9 类 APP、第 42 类软件服务、第 43 类餐饮等） |

### 1.2 备选名：**全链民生**

| 维度 | 分析 |
|---|---|
| 含义 | 全链 = 全产业链（种子到餐桌全链条）；民生 = 平台本质 |
| 与定位契合 | 定位感最强：一眼看出"全产业链透明"（对应 B1/T3 全链溯源） |
| 发音与记忆 | 四字、直白，但「链」字偏冷硬，口语传播弱于「甄选」 |
| 商标风险 | ⚠️ 中：「全链」为行业常用词（全链路），查重后可用性中等 |

### 1.3 第三候选（补充，供组合）
- **民生链**（民生+链，比"全链民生"顺口但更抽象）
- **甄选民生**（倒装，弱于主推）
- **透明甄选**（若未来想强调"透明"可用副品牌）

### 1.4 命名建议
> 主推 **民生甄选**，商标查重通过则启用；查重冲突则降级 **全链民生**。注册类别建议覆盖：35（广告销售/电商）、9（软件/APP）、42（平台服务）、43/44/45（本地生活服务）。

## 2. 品牌定位

### 2.1 一句话定位（对外）
> **政府牵头、信用驱动的全产业链透明交易与民生服务平台 —— 把胖东来"一家店的全链条可控"，普惠给石家庄每一家小店。**

### 2.2 定位三角（与竞品差异）
| 对比对象 | 他们只有 | 我们有 |
|---|---|---|
| 1688 类交易平台 | 交易、价格 | 信用背书 + 政府监督 + 全链溯源 |
| 外卖/流量平台 | 流量、抽成 | 免费推广 + 信用加权（不靠竞价广告） |
| 政务 App | 办事、查询 | 透明交易 + 劳务信用 + 群众监督闭环 |

### 2.3 品牌价值观（四句话）
1. **透明即信任**：价格、过程、结果三透明（胖东来理念平台化）
2. **信用是通行证**：好店好人靠信用分被看见（劳务信用 + 商户信用 + 供应商信用）
3. **群众看得见**：监督公示、投诉直达、结果公开（脱敏）
4. **商户有获得感**：免费推广、费率公开、货款/工资有保障

### 2.4 品牌调性
| 维度 | 方向 |
|---|---|
| 关键词 | 可信、透明、温暖、现代、接地气 |
| 语气 | 政府亲民 + 品质生活（不说教、不冰冷） |
| 颜色方向 | 主色「民生蓝」（政务信任）+ 辅色「暖橙」（胖东来式热忱/民生温度）+ 白底（透明感） |
| Logo 意象 | 「选」字对勾 / 环链 + 对勾（甄选 + 全链） |

## 2.5 核心理念五词（设计原则，用户确认 2026-09-01）

> **惠民 · 方便 · 安全 · 透明 · 直达** —— 既是品牌理念，也是**贯穿需求/设计/开发的设计原则**：任何功能设计都要能回答"它落在哪个词上"。

| 理念 | 释义 | 平台落点（模块） |
|---|---|---|
| **惠民** | 政府牵头、普惠民生，商户与群众都受益 | 免费推广优质小店(E2)、民生服务(G/H)、费率公开 |
| **方便** | 操作轻量、一步完成、PC Web 优先 | 非功能需求「轻量」、录入 ≤1 分钟、扫码即查 |
| **安全** | 资金有保障、实名可信、食安可溯 | 资金第三方托管(I)、强实名(I1)、溯源(B1/T3)、数据加密 |
| **透明** | 价格、过程、结果三透明，胖东来理念 | 全链溯源(T3)、红黑榜公示(A3)、抽检公示(B3)、存证 |
| **直达** | 诉求一键直达政府/商家，进度可见 | 投诉直达(D2)、群众热线(G1)、部门限时办结(G3) |

**使用方式**：设计阶段每个模块/页面评审时对照五词自检（如：这个页面是否"方便"？这条流程是否"透明"？资金是否"安全"？诉求是否"直达"？最终是否"惠民"？）

## 4. 品牌架构与扩展性

### 4.1 主副品牌架构
```
民生甄选（主品牌）
├── 甄选广场（透明交易）     ← 全产业链选品
├── 甄选信用（信用内核）     ← 商户/劳务/供应商信用
├── 甄选溯源（一物一码）     ← 全链溯源
├── 甄选结算（账户体系）     ← 工资代付/货款分账
├── 甄选民声（政民互动）     ← 热线/建议论坛/民生监督
└── 甄选·石家庄（试点城市版）
```

### 4.2 城市扩展
- 试点期：**民生甄选·石家庄**
- 复制期：石家庄验证后，品牌可平移其他城市（主品牌不变，城市做后缀）
- 域名/端名建议：`minshengzhenxuan.com`（或 `mszx` 拼音缩写备用）；PC Web 应用名 = 民生甄选

### 4.3 与「民生综合服务平台」的关系
- 「民生综合服务平台」= 项目/立项名（政府口径）
- 「民生甄选」= 对外的品牌/产品名（用户可感知）
- 两者并存：立项文件用全称，对外传播用品牌名
