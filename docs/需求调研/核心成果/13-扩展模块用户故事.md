# 扩展模块用户故事 · F 物流 / G2 建议论坛 / H 民生监督

> 用户问卷新增模块的细化（优先级：F=P1, G2=P1, H=P2）

## F 物流货运平台（用户新增，P1）

### F1 大货车司机自由接单
- 作为**货主**，我想发布货运需求（货物、路线、时间、期望运费），以便找到合适的司机
- 作为**司机**，我想按路线/货物类型筛选抢单，自由选择，避免被平台强制派单
- 作为**监管人员**，我想看到货运交易全流程留痕，以便处理纠纷

### F2 实时动态物流位置
- 作为**货主**，我想实时查看货物在途位置（手机 GPS，不做北斗硬件对接），以便掌握运输动态
- 作为**司机**，我想记录行驶轨迹，以便证明按时按路线送达
- 作为**监管人员**，我想看到异常停留/偏航预警，以便发现甩货、盗窃风险

### F3 司机资质与信用
- 作为**货主**，我想核验司机的从业资格证、背景审查、信用分，以便放心托运
- 作为**司机**，我想维护自己的信用档案（接单履约率），以便接到优质订单
- 信用分与平台 A3 体系联动

### F4 运费托管结算
- 作为**司机**，我想运费由平台托管、送达确认后到账，杜绝货主拖欠
- 作为**货主**，我想确认货物完好后再放款，避免货损纠纷
- 与 I3 工资代付共用结算体系（第三方持牌通道，银行专户不可接），金融合规

### F5 费率/抽成公开
- 作为**货主/司机**，我想看到平台抽成与费率公开透明，避免被暗扣
- 费率/抽成公开公示，对齐 A1 费率公开承诺

### 关键流程
1. 货主发单 → 司机抢单/接单 → 平台冻结运费（托管）
2. 装货 → 运输（位置实时上报）→ 送达确认 → 运费解冻入司机账户
3. 纠纷（货损/迟到）→ 平台存证仲裁 → 计入双方信用分

## G2 群众建议论坛（用户新增，P1）

### 用户故事
- 作为**群众**，我想对政府工作提建议，看到是否被采纳，参与城市治理
- 作为**政府**，我想收集群众建议、公示采纳情况，提升治理透明度
- 作为**人大代表/政协委员**，我想从论坛发现民声线索，履职发声

### 关键流程
1. 群众发帖建议（分类：民生/营商/监管/其他）→ 实名或匿名可选
2. 平台审核 → 分派对应部门 → 限时答复（采纳/部分采纳/不采纳+理由）
3. 采纳建议公示 → 优秀建议者获积分/荣誉（参照大庆积分奖励机制）

## H 民生建设监督（用户新增，P2）

### 用户故事
- 作为**群众**，我想实时查看城市民生工程进度、资金、计划，监督政府花钱
- 作为**政府建设部门**，我想公开项目进度、回应群众疑问，展示工作实效
- 作为**监管人员**，我想看到群众对民生项目的反馈集中点，辅助决策

### 关键流程
1. 政府发布民生项目（计划、资金、工期、责任部门）→ 公开
2. 项目进度实时同步（图文/视频/数据）→ 群众可查看
3. 群众提意见 → 部门限时回应 → 回应记录公示

## 非功能要求（扩展模块）
- 物流位置数据用手机 GPS，轨迹存证
- 运费/工资共用第三方持牌通道结算体系
- 政民互动工单自建（12345 不可接）
- 论坛内容审核（防谣言、防攻击），敏感词+人工复核
