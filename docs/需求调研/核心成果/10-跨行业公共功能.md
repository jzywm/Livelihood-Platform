# 跨行业交叉分析 · 公共功能骨架

> 由 9 个行业的桌面调研交叉提炼 —— 多个行业反复出现的痛点 = 平台核心功能
> ⚠️ 本文为早期初稿：模块子编号（A1/A2/A3…）与 C1「工资专户」等为调研期口径，最终以《需求规格说明书》v1.7 为准（A1 一店一档 / A2 一人一档 / A3 信用分 / A4 监管预警；C1 = 第三方通道代付留痕，银行专户不可接）。

## 平台公共功能模块（初稿）

### A. 信用与监管内核
- A1. **一店一档 / 一人一档**：证照、处罚、抽检、投诉、好评率全量档案
- A2. **信用分体系**：商户信用分 + 从业人员信用分（胖东来式红黑榜）
- A3. **监管预警**：高频投诉、异常经营、资质临期自动预警推送给监管端

### B. 透明与溯源
- B1. **供应链溯源**：「种子到餐桌」—— 进货批次扫码录入
- B2. **服务过程透明**：后厨直播、维修报价单、价格公示
- B3. **抽检结果公示**：政府抽检 + 平台抽检统一入口

### C. 用工与保障
- C1. **工资监管**：代付留痕 + 欠薪预警 + 证据出证（第三方持牌通道，银行专户不可接）
- C2. **防童工**：入职年龄/身份证核验
- C3. **从业履历**：实名 + 健康证/技能证核验 + 工作经历背书

### D. 交易与维权
- D1. **预付卡资金监管**：风险提示 + 资金托管（对接已有监管体系）
- D2. **投诉直达 + 进度可见**：消费者提交 → 平台/市监限时处理 → 结果公示
- D3. **恶意差评申诉**：商户证据留存、职业索赔识别

### E. 社区与生态
- E1. **行业圈层论坛**：按行业/地域分层
- E2. **优质小店推广**：信用加权推荐，非竞价排名
- E3. **招工求职**：实名 + 履历 + 用工评价互评

## 设计原则（胖东来理念落地）
1. 信用可视化：好店好人的「好」要让所有人看见
2. 员工权益前置：善待员工 → 员工善待顾客
3. 透明即信任：价格、过程、结果三透明
4. 自建替代 + 双轨并行：石监码/12345/银行专户已确认不可接，全部自建替代（证照人工核验 / 自建工单 / 第三方通道），政务接口就绪后再切换
5. 中小商户可负担：录入成本极简（扫码/拍照），不做重型改造
