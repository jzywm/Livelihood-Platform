# 模块 J7 · 个人画像与个性化推荐需求（画像中心）

> 状态：v1.0（2026-09-01 需求变更 · 用户方案 B 选定 + 数据源 5 项全确认）
> 定位：建立**标准画像中心（画像服务）**，整合平台内多源数据构建用户画像，驱动 **J 助手个性化推荐 / 个性化信息推送 / 个性化使用引导**
> 归属：《需求规格说明书》**模块 J7**（J 助手扩展），随 J 助手 **P0/M1（基础版）**；**M2 购买数据接入后完整版**
> 合规基调：画像含**个人信息（学历/工作/购买习惯属敏感）**，全部按《个保法》最小化、授权、可删除执行；**透明不杀熟**

---

## 1. 一句话需求

> 平台为每个实名用户建立**可查看、可修改、可关闭、可删除**的个人画像，智能助手与推荐系统据此提供**个性化**的商品/信息推荐与使用引导，推荐理由标注画像依据，**价格不因画像差异化（透明定价）**。

## 2. 画像数据源与授权（用户已确认 5 项全选）

| 数据源 | 字段 | 来源 | 授权方式 | 里程碑 |
|---|---|---|---|---|
| 实名信息 | 年龄/性别 | 微信/支付宝实名回传（已确认唯一实名通道） | 注册协议 | M1 |
| 履历信息 | 学历/工作/技能 | A2 一人一档 / C3 履历（`24`/`25`） | **本人授权**才可入画像（可撤回） | M1 |
| 平台行为 | 浏览/搜索/会话行为 | 平台行为日志 | 隐私协议；行为数据脱敏后入画像 | **M1（购买习惯的近似替代）** |
| 购买/交易记录 | 品类/客单价/频次 | 交易服务（T4/B2C，M2 上线） | 交易协议 | M2 |
| 主动完善 | 兴趣/偏好自述 | 「我的画像」页用户自填 | 自愿、可随时修改 | M1 |

> ⚠️ M1 期无交易数据：「购买习惯」用**浏览/搜索/会话行为**近似；真实购买画像 M2 接入。

## 3. 画像标签体系（初版，上线前评审确认）

| 维度 | 标签示例 | 来源 |
|---|---|---|
| 基础 | 年龄段（<25 / 25~35 / 36~50 / >50）、性别（可选）、城市 | 实名 |
| 职业 | 行业类别（餐饮/家政/运输/教育等）、角色（老板/工作者/消费者） | 履历 + 用工 |
| 学历 | 学历带（初中及以下/高中/大专/本科及以上） | 履历（授权） |
| 品类偏好 | 农资/食材/家政/培训/维修…（权重） | 行为 + 购买(M2) |
| 价格敏感度 | 价格带分布（低/中/高） | 浏览 + 购买(M2) |
| 行为活跃 | 访问时段/频次/常用功能 | 行为 |

## 4. 画像用途（J7 三件事）

### 4.1 个性化商品/服务推荐（增强 J3）
- 规则排序（信用40/溯源30/价格20/好评10）之上叠加**画像权重**：如职业相关品类加权、价格敏感度调整排序、年龄带适龄过滤（未成年人内容保护）
- 推荐理由标注画像依据：「根据你的职业（餐饮）推荐食材类目」「根据你的历史偏好推荐」

### 4.2 个性化信息推荐
- 职业类：招工/培训/政策信息（如餐饮从业者 → 健康证/技能培训提醒）
- 年龄类：养老/育儿/适龄服务
- 行业类：与所在行业相关的监管新政、抽检结果

### 4.3 个性化使用引导
- 新手：按角色给使用步骤引导（复用 J1 FAQ，按画像排序）
- 熟手：直达高频功能；异常行为（如老板连续欠薪预警）主动提醒

## 5. 画像中心关键流程（M1 基础版）

```
数据采集（实名/履历/行为/主动完善）
  → 授权校验（履历需本人授权；未授权字段不入画像）
  → 标签计算（脱敏、加密存储）
  → 画像输出（供 J 助手/推荐系统调用）
  → 用户控制（管理页：查看/修改/关闭个性化/删除）
  → 删除后：推荐回退通用规则，30 天内清理画像衍生数据
```

## 6. 用户控制（画像管理页）

| 能力 | 说明 |
|---|---|
| 查看 | 展示各维度标签与数据来源、授权状态 |
| 修改/完善 | 主动修改兴趣偏好；修正错误标签 |
| 关闭个性化 | 关闭后推荐回退**通用规则**（J3 基础排序），不收集行为画像 |
| 删除画像 | 一键删除；画像衍生数据 30 天内清理；不影响基本功能 |

## 7. 合规红线（C7，评审口径）

1. **最小化**：只收集画像所需字段，不收集无关个人信息；行为画像不包含对话原文
2. **授权**：履历/行为入画像需授权，可撤回；撤回即停止使用该维度
3. **用户控制**：查看/修改/关闭/删除 四权齐全（§6）
4. **透明不杀熟**：推荐理由标注画像依据；**价格不因画像差异化**（同一商品对所有人同价，透明定价）
5. **未成年人**：未成年人不建行为/购买画像（仅必要实名），内容适龄过滤
6. **数据安全**：画像数据加密存储、脱敏输出、不对外共享；画像操作审计留痕
7. **留存**：画像标签随账号生命周期；关闭/删除后按 §6 清理

## 9. 与五词设计原则自检

| 理念词 | 落点 |
|---|---|
| 惠民 | 推荐更精准，帮助更到位 |
| 方便 | 主动完善入口 + 个性化直达 |
| 安全 | 授权/加密/可删除/未成年人保护 |
| 透明 | 理由标注画像依据、不杀熟、四权可见 |
| 直达 | 按画像直达所需功能与信息 |

## 10. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 画像合规审查（敏感个人信息） | 最小化 + 授权 + 四权 + 审计；上线前隐私影响评估 |
| 杀熟争议 | **透明定价硬约束**：价格与画像无关，仅排序与信息相关 |
| M1 无购买数据画像偏差 | 行为近似 + 用户主动完善纠偏；标注画像置信度 |
| 画像标签错误 | 用户可修改/关闭；标签计算可解释（来源可查） |
