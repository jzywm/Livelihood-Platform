## 2. 关键替代方案说明（已并入规格书 v1.7）

### 2.1 工资保障（原 C1 银行专户 → 第三方代付留痕）
- **方案**：工资由第三方持牌通道代付（微信「商家转账到零钱」/ 支付宝转账），平台全量记账留痕 + 欠薪预警 + 证据出证（流水+用工记录可打包供劳动仲裁）
- **合规**：平台不沉淀资金，资金在持牌机构账户内划转，不做二清
- **验证**：微信支付官方产品「商家转账到零钱」需企业商户号+营业执照+对公账户（[官方文档](https://pay.wechatpay.cn/doc/v3/merchant/4012064660)）

### 2.2 商品购买结算（货款托管 → 持牌机构分账）
- **方案**：买方付款入第三方通道 → 验收通过 → 触发分账（货款→卖方、服务费→平台），平台不碰货款
- **合规**：分账由持牌机构执行，规避二清（[分账系统规避二清风险](https://www.eshutong.com/archives/24140.html)、[银行存管结合](https://www.eshutong.com/archives/13274.html)）

### 2.3 群众热线（12345 → 自建工单）
- **方案**：平台生成工单 → 人工分派对应部门 → 线下办理 → 结果回填公示；内部时限约束（G3）

### 2.4 一店一档证照（石监码 → 自主上传核验）
- **方案**：商户上传证照（原件拍照）→ 平台人工核验（对照公开信息）→ 有效期巡检提醒 → 异常标记
