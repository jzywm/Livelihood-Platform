# 模板③ · 问卷模板（阶段2-A 标准化）

> 用法：行业多、问题杂时使用。**硬性规则：≤15 题**，选项化，每题附「你查/后定」逃生口。
> 参考范例：`../12-用户问卷.md`（42 题版——教训：太长，新版必须精简）

## 一、方向决策（先问最关键的，≤3 题）
1. **优先级**：这个行业放 P0（首期）/ P1（二期）/ P2（三期）？建议：
2. **本地数据源**：本地有无既有系统/名单可对接？（如黑白名单/备案平台）您了解吗？
3. **特殊规则**：这个行业有什么本地特有的监管要求或乱象？（没有就写「无」）

## 二、角色痛点（每角色 ≤3 题，共 ≤12 题）
### 消费者
- 最怕被坑的一件事？（选项：A 跑路 B 虚假宣传 C 效果不符 D 卫生安全 E 其他）
- 维权顺畅吗？（A 顺畅 B 一般 C 投诉无门）
### 商户/供应商
- 最痛的一件事？（A 招工难 B 获客难 C 合规成本 D 被讹 E 资金）
- 最想要平台帮什么？（A 信用背书 B 低成本获客 C 资金保障 D 供应链采购）
### 员工/从业人员
- 最容易被欺负的是？（A 欠薪 B 无社保 C 超时 D 随意辞退 E 履历无法证明）
- 工资拖欠常见吗？（A 常见 B 偶尔 C 罕见）
### 监管/政府
- 您觉得监管部门最头疼的是？（A 看不见 B 取证难 C 人手少 D 数据不互通 E 新业态无标准）

## 三、功能确认（≤2 题）
- 下列功能按优先级排序（可多选）：A 机构档案 B 资质核验 C 预收费/资金监管 D 投诉直达 E 过程透明 F 信用分
- 有没有我们没想到的本地需求？（没有就写「无」）
