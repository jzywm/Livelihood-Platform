## 1. 行业现状与政策框架

### 1.1 政策主线：「双减」后强监管
- 「双减」后学科类培训转入地下，「课后托管」为名的**隐形变异培训**问题突出（[民进中央倪闽景](https://www.mj.org.cn/mjfc/mtjj/202603/t20260313_305210.htm)）
- 教育部 2025 年出台《全国校外教育培训监管与服务综合平台应用管理办法》：**机构须接入全国平台、预收费全额纳入监管**（[教育部](http://m.jyt.henan.gov.cn/2025/03-26/3141307.html)、[河南政府](https://m.henan.gov.cn/2025/03-26/3141276.html)）
- 各地常态化治理：暑期专项治理、隐形变异查处通报（[延边州](http://edu.yanbian.gov.cn/gzdt/tzgg/202602/t20260204_566961.html)、[达州](http://www.dazhou.gov.cn/xxgk-show-38664.html)）
- 检察日报呼吁完善校外培训监管（[检察日报](http://newspaper.jcrb.com/2026/20260311/20260311_008/20260311_008_1.htm)）

### 1.2 石家庄本地动态
- **石家庄教育局公布校外培训机构黑白名单**（[石家庄教育局](http://sjzjyj.sjz.gov.cn/a/2025/01/02/1735809575733.html)）—— 黑白名单制度已落地
- 河北查处违规机构：停课、全部退款（[网易](https://www.163.com/dy/article/K7L2JCTG0534CHJI.html)）
- 石家庄「只收尖子生、学费近两万」违规办高中先修班被查（[新黄河](https://www.jinantimes.com.cn/news-216-5125448.html)）
- 河北文课教育涉嫌违法广告被查（[新华区市监](http://www.xhqsjz.gov.cn/columns/65ba42a9-4403-4e9b-9137-03745b478944/202605/20/741c87b6-0298-49a8-bbc2-b276302cc397.html)）
- ⇒ 平台可对接石家庄教育局黑白名单数据

## 2. 四方角色痛点（结构化）

### 2.1 家长/学生（消费者）
| 痛点 | 实证 |
|---|---|
| 预收费跑路、退费难 | 只上五节课难退费还背上「消费贷」（[公安部新闻传媒](https://news.cpd.com.cn/n3569/325/t_1176959.html)） |
| 虚假宣传「名师」「包过」 | 沪江教育「4大名师」2 人无教资被罚 20 万（[杭州网](https://news.hangzhou.com.cn/shxw/content/2022-07/01/content_8296250.htm)）；扬州机构宣称「国家级评审教师」被查（[中国质量新闻网](https://www.cqn.com.cn/zj/content/2025-04/10/content_9100799.htm)） |
| 教师资质存疑 | 无教师资格证授课频发 |
| 隐形变异培训难辨别 | 课后托管名义违规补课（[民进中央](https://www.mj.org.cn/mjfc/mtjj/202603/t20260313_305210.htm)） |
| 效果无保障 | 「定制就业」「不过包退」虚假承诺（[澎湃-恒企教育](https://thirdpage.thepaper.cn/h5/jrtt/31823121)） |

### 2.2 机构（商户）
| 痛点 | 说明 |
|---|---|
| 证照审批复杂 | 学科类/非学科类分类审批、办学许可+营业执照双证 |
| 预收费监管合规成本 | 须接入全国平台、资金全额托管（[银行托管服务](https://www.lsbankchina.com/lsbankchina/myjr/whzj2/sycdhprz/xwpxzjjgzhfw/index.html)） |
| 获客难、口碑难沉淀 | 无政府背书的评价体系 |
| 被「隐形变异」连累 | 合规机构被地下机构恶性竞争 |

### 2.3 教师/从业人员
| 痛点 | 实证 |
|---|---|
| 欠薪、社保缺失 | 特教老师集体被拖欠 5 个月工资社保（[洛阳网](https://people.lyd.com.cn/wenti/20250727072259404/)）；机构教练被拖欠 3 个月工资、无社保（[听讼网](https://www.tingsonglaw.com/ask/detail/2729823)） |
| 劳动关系不稳定 | 仲裁案件频发（佛山多起教培仲裁[1](https://hrss.foshan.gov.cn/ztzl/ldgxytjzc/zcwsgk/nhqzcws/content/post_5850225.html)[2](https://hrss.foshan.gov.cn/ztzl/ldgxytjzc/zcwsgk/nhqzcws/content/post_6903268.html)） |
| 资质证明难 | 教资证、专业技能证书核验无统一入口 |
| 职业履历无背书 | 换机构后过往经历难证明 |

## 5. 平台新增功能点（教育培训专项）

### E1-EDU 教育机构档案
- 证照（办学许可证/营业执照/消防）、黑白名单状态、教师资质公示、投诉率、退费率
- 家长扫码即查（复用一店一档）

### E2-EDU 课程透明交易
- 课程详情 + 教师资质 + 课时价目 + 合同模板公示
- 学费走「一课一消」托管：上完一节课消一节课的钱（复用 T4 撮合 + C1 结算）

### E3-EDU 教师权益与履历
- 教师实名 + 教资证/技能证核验 + 任职履历 + 工资发放记录（复用一人一档）

### E4-EDU 监管协同
- 对接教育局黑白名单、全国校外培训平台
- 隐形变异举报入口、职业培训补贴公示
