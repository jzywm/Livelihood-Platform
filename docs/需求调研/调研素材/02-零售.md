# 第 2 轮访谈 · 零售行业（便利店 / 超市 / 菜市场）

> 状态：桌面调研完成，待访谈

## 痛点初判

### 消费者
- 缺斤少两、标价与结算不符
- 过期/临期食品不标注、生鲜以次充好
- 预付卡（超市/水果店充值）跑路
- 塑料袋收费、价格歧视等细碎纠纷

### 商户
- 小超市/便利店利润薄，被大卖场和电商挤压
- 临期商品处置成本、食安罚款风险
- 进货渠道不透明，被上游坑

### 员工
- 收银/理货多为临时工，社保覆盖低
- 排班不透明、超时工作

### 监管者
- 生鲜快检覆盖面有限、菜市场摊贩台账难
- 过期食品抽查靠人海战术

## 桌面调研要点
- 各地市监局节前/日常检查重点：过期食品、缺斤少两、索证索票（[界首](https://amr.fy.gov.cn/Content/show/1265940.html)、[湘潭县](http://www.xtx.gov.cn/6571/6563/6557/content_1394678.html)）
- 投诉举报受理规范趋严：要求渠道公开、限时处理（[和静县公告](https://www.xjhj.gov.cn/xjhjx/c117346/202511/9ba088b7888f4e2ea71720a01d90c917.shtml)）

## 待用户确认的问题
1. 本地菜市场/超市「缺斤少两」和「过期食品」哪个更常见？
2. 预付卡跑路在本地零售（尤其水果店、洗车店）多不多？
3. 零售环节「种子到餐桌」最有价值的一段是不是「生鲜快检结果公示」？
