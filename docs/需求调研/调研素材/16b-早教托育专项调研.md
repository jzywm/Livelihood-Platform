## 1. 行业框架与监管（与 K12 培训不同体系）

- 主管单位：**卫健委**（托育备案制）vs 教育部（校外培训）—— 跨部门
- 政策依据：《托育机构登记和备案办法（试行）》（国卫办人口发〔2019〕25号）、**《托育机构管理规范（试行）》**（[广汉公开目录](https://www.guanghan.gov.cn/gk/jczwgkbzml/lybl/wsjk/hzcflsx/dtybwjgdhzcf/1693664.htm)）
- 2025 年国家启动**全国托育服务质量提升行动（2025-2027）**：七大重点任务（[国家通知](http://www.nnjn.gov.cn/xxgk/xxgkml/shgysyjslygk/jyly/jyzcygh/xqjywj/t6401157.html)、[河北计生协](https://www.hebfpa.org.cn/bwdt/4077.jhtml)）
- 备案制：县级卫健委负责已登记托育机构备案（[霍邱卫健委](https://www.huoqiu.gov.cn/public/6600561/37215480.html)）

## 2. 石家庄本地现状（重要）

- **备案托育机构 983 家、提供托位 4.9 万个**（2025-11 数据，[石家庄日报](http://sjzrb.sjzdaily.com.cn/sjzrbpaper/pc/content/202511/27/content_226452.html)、[石家庄广电](http://www.sjzntv.cn/app/folder1619/folder1687/2025-11-27/1829095.html)）
- **石家庄市托育服务平台已上线**：预约托位、育儿知识、婴幼儿照护服务（[长城网](http://heb.hebccw.cn/system/2023/03/11/101115892.shtml)、[石家庄政府](https://www.sjz.gov.cn/columns/5021f17e-4f5b-40ad-a417-8a5cfcb88d71/202312/30/cf8f6d5e-8eb6-4f2b-9cb1-a5a2c069f215.html)、[河北计生协](http://www.hebfpa.org.cn/xyxw/1909.jhtml)）
- ⇒ **平台必须对接石家庄托育服务平台/卫健委备案数据，而非重造**（与石监码同理）

## 3. 痛点实证（与 K12 高度相似，且更敏感）

| 角色 | 痛点 | 实证 |

| 家长 | **跑路/卷款** | 成都温江积木宝贝早教老板卷款跑路（[问政四川](https://ly.scol.com.cn/thread/details/3693950)）；泉州早教机构闭店退费难（[泉州网](https://www.qzwb.com/gb/content/2025-01/04/content_9123807.htm)） |

| 员工 | **关停拖欠工资** | 成都暖房子托育中心关停、拖欠员工工资（[光明网](https://m.gmw.cn/2025-11/12/content_1304221788.htm)、[央广网](https://news.cnr.cn/native/gd/20251112/t20251112_527427558.shtml)） |
| 监管 | 备案覆盖不全、无证经营 | 托育机构管理规范执行力度不一 |

## 4. 与 K12 培训的差异点（平台设计注意）

1. **更敏感**：0-3 岁婴幼儿安全 → 视频监控/看护记录是刚需（石家庄已有「婴幼儿托育全程看护」服务）
2. **双头监管**：卫健委（托育）+ 教育局（早教课程）→ 平台需双数据源
3. **价格高、预付多**：早教课包动辄上万 → 预收费监管更迫切（复用 D1/对接监管）
4. **师资**：保育员/育婴师证 vs 教资证 → 一人一档证件类型需扩展

## 5. 平台功能映射（早教/托育 → 模块）

| 需求 | 对应模块 | 说明 |
|---|---|---|
| 托育机构档案（备案状态） | A1 | 对接卫健委备案数据 + 石家庄托育平台 |
| 看护过程透明（视频/记录） | B2（过程透明） | 婴幼儿托育全程看护接入 |
| 预收费监管 | D1 + 对接监管平台 | 早教课包预付风险提示 |
| 员工欠薪保障 | C1（工资专户） | 复用专户托管 |
| 保育员/育婴师资质核验 | A2/C3（一人一档） | 证件类型扩展 |
| 投诉直达 | D2 | 升级卫健委/教育局 |
| 托位查询/预约 | E3 或对接石家庄托育平台 | 复用而非重造 |

## 6. 建议

- 早教/托育并入教育培训行业组，统一走 **P1**
- **对接清单**：石家庄托育服务平台（卫健委）+ 石家庄教育局黑白名单 + 教育部全国校外培训平台
- 平台不重造托位预约，做「信用监督 + 过程透明 + 资金保障」差异化
