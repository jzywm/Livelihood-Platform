# 第 5 轮访谈 · 住宿（酒店 / 民宿）

> 状态：桌面调研完成，待访谈

## 痛点初判

### 消费者
- 偷拍摄像头（隐私安全，近年高发）
- 卫生差：床品不换、清洁不到位
- 图文不符、临时加价、退订难
- 消防/安全设施缺失

### 商户
- 平台佣金高、评价被恶意差评操控
- 合规成本：消防、特种行业许可证

### 员工
- 保洁多为外包/零工，无社保
- 工时弹性大、旺季超负荷

### 监管者
- 民宿备案制落地难、无证经营多
- 偷拍治理需公安+市监+网信协同
- 卫生抽检覆盖低
