# 第 8 轮访谈 · 娱乐（KTV / 网吧 / 影院 / 足疗按摩 / 剧本杀）

> 状态：桌面调研完成，待访谈

## 痛点初判

### 消费者
- 未成年人进入（网吧/KTV/剧本杀血腥内容）
- 隐形消费、低消套路、服务缩水
- 卫生（足疗/按摩器具消毒）
- 安全（消防通道、场所设施）

### 商户
- 消防、公安、文化多部门检查频繁
- 被恶意差评、同行竞争

### 员工
- 多为夜班/兼职，社保覆盖低
- 足疗按摩等场所易被污名化，员工身份难证明

### 监管者
- 未成年人保护：网吧/KTV 违规接纳未成年人高发
- 剧本杀等新业态监管标准滞后
- 多部门协同（公安/文旅/市监）成本高
