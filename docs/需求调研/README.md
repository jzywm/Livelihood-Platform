## 角色（每个行业都按这些角色问）

| 角色 | 核心诉求 | 平台对应模块 |
|---|---|---|
| 消费者 | 安全、透明、不被坑、投诉有用 | 消费端 · 溯源 · 投诉 · 热线 |
| 商户（老板） | 合规成本低、招工易、不被讹、成本结算、**选品采购** | 经营端 · 信用申诉 · 专户结算 · 选品广场 |
| 供应商（农资/食材/材料） | 资质背书、放心交易、货款保障 | 供应商信用 · 透明交易 · 货款托管 |
| 从业人员 / 求职者 | 工资有保障、履历有背书 | 用工保障 · 身份履历 |
| 货运司机 | 自由接单、运费保障、实时位置 | 物流货运平台 |
| 监管者 / 政府 | 看得见、管得动、取证易、数据预警 | 监管端 · 政民互动 · 民生监督 |

1. **定位**：To G + To C 都要，本质是**民生平台**
2. **运营主体**：**政府牵头**
3. **工资监管**：~~专户托管~~ → **2026-09-01 更新：银行专户不可接，改为平台账户系统 I3 工资保障代付（第三方通道代付留痕 + 欠薪预警 + 证据出证）**

5. **试点城市**：**石家庄市**

7. **不做**：网约车 / 出租车（只做货运物流）
8. **定位再升级（2026-09-01 补充）**：**全产业链透明交易平台**——跨行业选品采购（农资/食材/医美材料等）都在平台透明进行，胖东来透明理念贯穿全产业 → 新增模块 T

11. **平台账户系统（2026-09-01）**：实名账户 + 钱包记账 + 劳务信用（工作者↔老板双向），工资与商品购买平台留痕；**资金走第三方持牌通道，平台不沉淀资金（规避二清）**（方案1 轻量合规）→ 新增模块 I，详见 `核心成果/24-平台账户系统需求.md`

## 全产业链调研要点（`核心成果/15-全产业链透明交易调研报告.md`）

- **农资（种子/化肥/农药/饲料）**：假劣重灾区，「两高」发布农资打假案例（普通小麦冒充种子、高岭土当农药）→ T3 一物一码 + 供应商信用
- **医美材料**：百亿灰色流通渠道、11 部门全链条打击 → 材料注册证核验 + 合规采购
- **食材 B2B**：美菜等重资产模式断臂求生 → 平台坚持**轻资产撮合**
- **1688 类平台**：信任缺失（假货、骗局、价格不透明）→ 平台差异化 = 信用背书 + 政府监督 + 溯源
- **胖东来**：中央厨房自营 = 一家店的全链条可控 → 平台将其**普惠化**给每家小店
- **餐厨垃圾**：多地立法防地沟油回流 → T5 反向闭环
